# archor(锚点)

### **1. 锚点（Anchors）的作用**

- **定义**：锚点是预定义的边界框模板，模型基于这些模板预测目标的偏移量和尺寸。
- **影响**：
    - **小目标检测**：较小的锚点更适合检测小目标。
    - **大目标检测**：较大的锚点覆盖大尺寸目标。
    - **宽高比匹配**：锚点与数据集中目标的宽高比越接近，模型收敛越快，精度越高。

---

### **2. YOLOv5 的自动锚点计算**

### **触发条件**

- **默认行为**：YOLOv5 在训练前**自动检查锚点与数据集的匹配度**。
    - 若锚点与目标框的宽高比匹配度低（`best possible recall < 0.98`），则重新计算锚点。
    - 若匹配度高，直接使用预设锚点（如 `yolov5s.yaml` 中的默认锚点）。
- **手动控制**：
    - 强制禁用自动锚点：`-noautoanchor`
    - 强制重新计算锚点：在训练命令中添加 `-anchor-update`（YOLOv5 ≥6.2）。

### **算法原理**

1. **K-means 聚类**：
    - 对数据集中所有目标框的宽高进行聚类，生成 `9` 个初始锚点（对应 YOLO 的 3 个检测层，每层 3 个锚点）。
    - 聚类时使用**宽高比距离度量**（而非欧氏距离），公式为：*d*(*box*,*anchor*)=1−*IoU*(*box*,*anchor*)
2. **进化优化**：
    - 基于遗传算法（GA）对初始聚类结果微调，最大化目标框与锚点的平均 IoU。
    - 优化目标：提高 `best possible recall`（理想最大召回率）。

### **3. 参数配置与调优**

### **关键参数**

- **`-anchor-update`*：在训练过程中更新锚点（适用于动态调整）。
- **`-noautoanchor`*：禁用自动锚点计算，强制使用预设锚点。
- **`-anchors`*：自定义锚点（需修改模型配置文件，如 `yolov5s.yaml`）。

### **调优建议**

1. **何时重新计算锚点**：
    - 数据集目标尺寸分布与 COCO 差异较大（如医学图像、卫星图像）。
    - 默认锚点的 `best possible recall < 0.95`（训练日志中提示）。
    - 更换模型结构（如从 `yolov5s` 切换到 `yolov5m`）。
2. **如何验证锚点效果**：
    - 监控验证集召回率（`metrics/mAP_0.5:0.95` 和 `metrics/recall`）。
    - 可视化锚点与目标框的匹配度（使用 `utils/autoanchor.py` 独立运行）。
3. **自定义锚点**：
    - 手动修改模型配置文件中的 `anchors` 参数（示例）：
        
        ```yaml
        
        anchors:
          - [10,13, 16,30, 33,23]# P3/8 检测层锚点（小目标）- [30,61, 62,45, 59,119]# P4/16 检测层锚点（中目标）- [116,90, 156,198, 373,326]# P5/32 检测层锚点（大目标）
        ```
        
    - 运行以下命令验证自定义锚点的匹配度：
        
        ```bash
        
        python utils/autoanchor.py --data coco.yaml --anchors anchors_custom.txt
        ```
