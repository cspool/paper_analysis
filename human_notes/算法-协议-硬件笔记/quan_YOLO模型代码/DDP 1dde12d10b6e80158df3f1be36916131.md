# DDP

### **1. DDP 的定义与核心原理**

### **基本概念**

- **DDP 是什么**：DDP 是一种分布式训练策略，将**单个训练任务拆解到多个 GPU 或计算节点**，每个 GPU 独立处理部分数据并同步梯度，最终聚合更新模型权重。
- **核心目标**：
    - 加速模型训练（线性扩展训练速度）。
    - 支持更大批次（Batch Size）或更高分辨率输入。
    - 提升硬件资源（多 GPU/多机）利用率。

### **工作流程**

1. **数据分片**：将训练数据均匀分配到各 GPU（通过分布式采样器 `DistributedSampler`）。
2. **模型复制**：将模型副本加载到每个 GPU。
3. **前向传播**：各 GPU 基于本地数据计算损失和梯度。
4. **梯度同步**：通过 `all-reduce` 操作聚合所有 GPU 的梯度，计算全局平均梯度。
5. **权重更新**：各 GPU 同步更新模型参数，确保一致性。

---

### **2. DDP vs DataParallel (DP)**

PyTorch 提供两种多 GPU 训练方案，DDP 相比传统 DP 有明显优势：

| **特性** | **DDP** | **DP** |
| --- | --- | --- |
| **并行机制** | 多进程，无全局解释器锁（GIL）限制 | 单进程多线程，受 GIL 限制 |
| **通信效率** | 基于 NCCL 后端，高速通信 | 基于 Python 线程通信，效率低 |
| **扩展性** | 支持多机多卡训练 | 仅支持单机多卡 |
| **显存占用** | 各 GPU 显存均衡 | 主卡显存易成为瓶颈 |
| **代码复杂度** | 需要显式启动分布式环境 | 简单，一行代码即可启用 |

### **为何选择 DDP**

- **更高性能**：DDP 在多卡场景下训练速度显著快于 DP（尤其当 GPU ≥4）。
- **更大规模训练**：支持跨机器扩展，适合超大规模数据集或模型（如 YOLOv5x）。
- **更少显存瓶颈**：避免 DP 的主卡显存溢出问题。
