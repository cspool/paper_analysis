## 1、parse_opt

[parse_opt](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/parse_opt%201dde12d10b6e803cbf85f67f5ab6514f.md)

此函数用于解析 YOLOv5 训练、验证和测试的命令行参数，返回一个包含配置信息的命名空间对象。

### 参数known

- **已知参数**：当前 `argparse.ArgumentParser` 实例已定义的参数（通过 `add_argument()` 添加）。
- **未知参数**：命令行中未被当前解析器定义的参数。
- **`known=True`*（对应 `parse_known_args()`）：
    - 仅解析已知参数，忽略未知参数，不报错（返回已知参数的命名空间和未知参数的列表）。
- **默认行为（`False`）**：遇到未知参数时直接抛出 `SystemExit` 错误。

### **参数列表**

1. **模型配置**
    - `-weights` (str): 初始权重路径，默认 `ROOT/yolov5s.pt`。
    - `-cfg` (str): 模型配置文件路径（如 `model.yaml`），留空则使用默认模型。
        
        [models/yolov5s_quan.yaml](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/models%20yolov5s_quan%20yaml%201dde12d10b6e8090aac4dca7e181bb77.md)
        
    - `-data` (str): 数据集配置文件路径，默认 `ROOT/data/coco128.yaml`。
        
        [data/coco128.yaml](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/data%20coco128%20yaml%201dde12d10b6e8071a27cf8a55c364cba.md)
        
    - `-hyp` (str): 超参数文件路径，默认 `ROOT/data/hyps/hyp.scratch-low.yaml`。
        
        [data/hyps/hyp.scratch-low.yaml(数据增强)](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/data%20hyps%20hyp%20scratch-low%20yaml(%E6%95%B0%E6%8D%AE%E5%A2%9E%E5%BC%BA)%201dde12d10b6e802fa7d4f57c6a37c5cd.md)
        
2. **训练设置**
    - `-epochs` (int): 总训练轮数，默认 `100`。
        - 完整遍历整个训练数据集的次数。
    - `-batch-size` (int): 总批次大小，多 GPU 时自动分配；设为 `1` 自动计算批次大小。
        - 单次前向/反向传播中输入模型的图像数量。
        - 例如 `--batch-size 64` + 4 GPU → 每个 GPU 处理 16 张
    - `-imgsz` / `-img` / `-img-size` (int): 输入图像尺寸，默认 `640`。
    - `-rect` (flag): 启用矩形训练（提高效率）。
        - 将同一批次的图像调整到统一的矩形尺寸
        
        [rect](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/rect%201dde12d10b6e80979da1de5a41209689.md)
        
    - `-resume` (flag): 从最近一次训练中恢复（支持指定检查点路径）。
        - **检查点（Checkpoint）** 是模型在特定训练轮次（Epoch）保存的中间状态，包含模型权重、优化器状态、当前轮数等信息。
        
        [checkpoint](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/checkpoint%201dde12d10b6e807ab0b3da8b16fbea3d.md)
        
        [优化器状态](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/%E4%BC%98%E5%8C%96%E5%99%A8%E7%8A%B6%E6%80%81%201dde12d10b6e80438a41d0c4689e2096.md)
        
    - `-nosave` (flag): 仅保存最终模型（不保存中间检查点）。
    - `-noval` (flag): 仅在最后一轮验证（节省时间）。
        - 每轮训练后,验证效果.类似启发式算法.
    - `-noautoanchor` (flag): 禁用自动锚点（Anchor）计算。
        - 锚点是预设好的边界框,用宽和高来定义,目标检测就是查找图像中哪里的小框有什么目标.
        
        [archor(锚点)](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/archor(%E9%94%9A%E7%82%B9)%201dde12d10b6e80fc94d9c8691dcee574.md)
        
    - `-optimizer` (str): 优化器选择，可选 `SGD`/`Adam`/`AdamW`，默认 `SGD`。
    - `-sync-bn` (flag): 使用同步批归一化（仅限 DDP 模式）。
        - **DDP（Distributed Data Parallel）多GPU分布式训练**
        
        [DDP](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/DDP%201dde12d10b6e80158df3f1be36916131.md)
        
        [SyncBN](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/SyncBN%201dde12d10b6e80f4b721c845013a0b73.md)
        
    - `-freeze` (list): 冻结指定层（如 `-freeze 0 1 2` 冻结前 3 层）。
        - 冻结,即不更新部分层的参数来加速训练、防止过拟合、优化显存.
3. **设备与分布式**
    - `-device` (str): 指定设备，如 `0`（单 GPU）或 `0,1,2,3`（多 GPU），默认 `cpu`。
    - `-workers` (int): 数据加载器的最大线程数，默认 `8`。
        - **数据加载器（DataLoader）** 是负责高效读取、预处理和批量供给训练数据的核心组件。
    - `-local_rank` (int): **自动设置**，用于 DDP 多 GPU 训练，无需手动修改。
        - `local_rank` 表示当前进程在**单台机器内部**的 GPU 设备编号，取值范围为 `0` 到 `N-1`（`N` 为当前机器的 GPU 数量）。
4. **超参数调优**
    - `-evolve` (int): 超参数进化代数（默认 `300`），用于自动化调优。
        - 超参数进化.即基于遗传算法的超参数自动优化.
        
        [**超参数进化的核心流程**](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/%E8%B6%85%E5%8F%82%E6%95%B0%E8%BF%9B%E5%8C%96%E7%9A%84%E6%A0%B8%E5%BF%83%E6%B5%81%E7%A8%8B%201dde12d10b6e8019ab28f99b57d8c148.md)
        
    - `-evolve_population` (str): 进化种群文件的加载路径，默认 `ROOT/data/hyps`。
    - `-resume_evolve` (str): 从指定代数恢复进化。
5. **数据集与增强**
    - `-cache` (str): 图像缓存方式，可选 `ram`（内存）或 `disk`（磁盘）。
    - `-image-weights` (flag): 使用加权图像选择（增强困难样本训练）。
    - `-multi-scale` (flag): 随机调整图像尺寸（±50% 范围）。
    - `-single-cls` (flag): 将多类数据视为单类训练。
        - 当仅需关注目标的位置检测（而非类别区分）时，减少模型复杂度和训练开销。
        - 或模型训练前期,聚焦于检测性能而非识别.
    - `-quad` (flag): 启用四倍数据加载器（特殊场景使用）。
6. **日志与保存**
    - `-project` (str): 结果保存目录，默认 `ROOT/runs/train`。
    - `-name` (str): 实验名称，默认 `exp`（保存为 `project/name`）。
    - `-exist-ok` (flag): 允许覆盖同名实验目录（否则自动递增名称）。
    - `-bbox_interval` (int): 验证时边界框图像记录间隔（默认不记录）。
        - 指定每隔 `N` 次验证周期（Validation Epoch）保存一次验证集图像的可视化结果（包含预测框和真实框）。
7. **其他功能**
    - `-label-smoothing` (float): 标签平滑系数（默认 `0.0`）。
        - 传统分类标签使用“硬标签”（如 `[1, 0, 0]`），迫使模型对正确类别预测概率接近 `1`，可能导致过拟合和校准误差。将硬标签替换为“软标签”（如 `[0.9, 0.05, 0.05]`），通过平滑系数（ε）控制软化程度。
        - 能提高泛化性能
    - `-patience` (int): 早停机制等待轮数（默认 `100`）。
        - 进化的早停阈值，若连续 `P` 代无提升则终止进化（默认 `100`）。
    - `-seed` (int): 全局随机种子，默认 `0`（可复现性）。
        - **固定全局随机种子（Global Random Seed）** 是保证实验可复现性的关键步骤
        
        [训练中的随机性](quan_YOLO%E6%A8%A1%E5%9E%8B%E4%BB%A3%E7%A0%81/%E8%AE%AD%E7%BB%83%E4%B8%AD%E7%9A%84%E9%9A%8F%E6%9C%BA%E6%80%A7%201dde12d10b6e80158ee3ebcc21f2fe23.md)
        
        通过固定以下所有随机过程的种子，确保每次运行的初始状态一致：
        
        - **模型权重初始化**：卷积层、批归一化层的参数初始化。
        - **数据增强**：随机翻转、裁剪、Mosaic 增强等。
        - **数据加载顺序**：数据集的乱序（Shuffle）和分布式采样。
        - **Dropout 和噪声层**：随机掩码生成。
    - `-upload_dataset` (flag): 上传数据集到云端（如权重与偏差平台）。

---

### **返回值**

- `argparse.Namespace`: 包含所有解析后参数的命名空间对象。
