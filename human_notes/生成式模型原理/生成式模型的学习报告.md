# 扩散生成模型的统一视角：从 DDPM 到 ODE Flow 与 JiT

## 摘要

本文梳理扩散生成模型从 DDPM 到 JiT 的理论演进。以 DDPM 为主线，依次讨论 DDIM、Score-SDE、Flow Matching、Rectified Flow 和 JiT。DDPM 将生成建模为逐步去噪的马尔可夫链。DDIM 和 Score-SDE 揭示了随机过程背后隐藏的确定性 ODE 结构。Flow Matching 将离散步推广为连续流。JiT 将预测目标、损失函数和采样方式三者解耦，发现高维下直接预测干净图像显著优于传统噪声预测。这些方法在数学上同构——均学习从噪声分布到数据分布的采样规则——但训练行为和采样效率因设计选择的不同而差异显著。

---

## 一、引言

生成模型的目标是给定一组样本，学会生成更多类似样本。VAE 单步解码容易丢失细节，GAN 训练存在不稳定性。扩散模型选择了第三条路：不追求一步到位，而是分很多步，每步只做很小的改动，把一件难事拆成一串简单任务。

本文按方法和逻辑两条线索展开。以 DDPM 为基础，ODE 系列方法统一了视角，JiT 完成了预测-损失-采样的解耦。

---

## 二、DDPM：扩散概率模型

### 2.1 问题定义

设有真实图像 x_0 来自未知分布 q(x_0)，任务是学习一个从纯噪声到数据样本的映射。直接建模高维空间中的密度分布十分困难，维数灾难使显式密度估计需要指数级样本量。DDPM 的做法是分两步走：先定义一个固定的前向扩散过程把图像逐步变为噪声，再学习一个反向去噪过程把噪声逐步恢复为图像。

### 2.2 前向扩散过程

前向过程是手工设计的，无需学习。每一步向图像添加少量高斯噪声，方差调度 β_1, …, β_T 控制加噪速率。利用高斯分布的可加性，从 x_0 到任意时刻 t 的状态可直接写出：x_t = √ᾱ_t · x_0 + √(1−ᾱ_t) · ε，其中 ε 是标准高斯噪声，ᾱ_t 是 1−β 的累积乘积。这意味无需逐步模拟前向过程，任意时刻的噪声图像可以直接采样。训练效率的核心保证即在于此。

### 2.3 反向生成过程

反向过程需要学习。联合分布 q(x_{1:T} | x_0) 有两种分解方式：正向乘积 Π_t q(x_t | x_{t-1})，和逆向乘积 q(x_T | x_0)·Π_{t=2}^T q(x_{t-1} | x_t, x_0)。逆向分解中，给定 x_0 时每个条件分布 q(x_{t-1} | x_t, x_0) 具有闭式高斯形式，这是扩散过程数学性质优良的又一体现。

生成时 x_0 未知，用神经网络 f_θ(x_t) 预测 x_0（或等价的噪声 ε），将预测值代入条件分布：p_θ(x_{t-1} | x_t) = q(x_{t-1} | x_t, f_θ(x_t))。

### 2.4 训练目标

采用变分推断框架。将 x_1, …, x_T 视为隐变量，最大化 log p(x_0) 的证据下界（ELBO）。推导后，高斯分布间的 KL 散度退化为均值间的 L2 距离，最终损失函数简化为 L = E[‖ε − ε_θ(x_t, t)‖²]，即对所有数据、噪声和时间步，计算预测噪声与真实噪声的均方误差期望。

这个损失有几个良好的性质：无需 Monte Carlo 估计熵项；每步监督信号直接来自添加的噪声，不依赖模型自身采样；训练等同于在 T 个不同噪声水平上独立训练 T 个去噪自编码器。

## 三、ODE Flow：从随机采样到确定性传输

### 3.1 DDIM 与确定性生成

DDIM 重写了 DDPM 的采样公式，拆为三项：基于当前估计的干净图像项、噪声预测相关项、以及随机扰动项 σ_t·η。当 σ_t = 0 时，随机项消失，整个过程变为完全确定：给定初始噪声 x_T，生成的 x_0 是唯一确定的。

这一观察意义显著。它表明采样可以理解为概率流 ODE 的 Euler 积分，并非必须依赖随机性。映射既然是确定的，就可以跳步，将 T 步压缩为 S 步，无需遍历所有中间状态。

### 3.2 Score-SDE 的统一框架

Score-SDE 将这一直觉严格化。正向扩散写为 Ito SDE：dx = f(x, t)dt + g(t)dw。逆向 SDE 为 dx = [f − g²∇_x log p_t]dt + g dw̄，其中 ∇_x log p_t 为 score function。该逆向 SDE 存在一个对应的概率流 ODE：dx = [f − (1/2)g²∇_x log p_t]dt，它与逆向 SDE 共享完全相同的边际分布 p_t(x)，但没有随机项。这一等价性将扩散模型从随机采样的框架中解放出来：确定性积分可以得到相同的结果。

### 3.3 Flow Matching 和 Rectified Flow

Flow Matching 进一步将时间彻底连续化：学习速度场 v_θ(z_t, t)，状态变化率 dz_t/dt 由该速度场给出，Euler 更新为 z_{t+Δt} = z_t + Δt·v_θ(z_t, t)。

Rectified Flow 选择了最简单的线性路径：z_t = t·x + (1−t)·ε，速度定义为终点减起点 v = x − ε。但首次学出的轨迹通常不是直的，多条轨迹会交叉。为此提出了 Reflow：将学到的轨迹作为新的训练目标重复拟合，几次迭代后轨迹变得近似直线，Euler 步数可以大幅缩减。

## 四、JiT：预测、损失与采样的解耦设计

### 4.1 解耦动机

传统扩散模型将三个选择绑定在一起：预测 ε，用 ε-loss 训练，用 ε 驱动采样。JiT 提出的问题是：这三个选择是否必须一致？

沿用线性 Flow 的设置：z_t = t·x + (1−t)·ε，v = x − ε。网络可以预测 x（干净图像）、ε（噪声）或 v（速度）中的任意一个，三者通过线性关系互转：v_θ = (x_θ − z_t)/(1−t)，x_θ = z_t + (1−t)·v_θ。训练损失可以在 x-、ε-、v- 三个空间中任选，采样时驱动 ODE 的量也可以是三者之一。

以 x-prediction + v-loss 的组合为例：网络预测 x_θ（干净图像），损失用 v-loss = ‖v_θ − v‖² = ‖x_θ − x‖²/(1−t)²，采样用 v_θ。损失分母中的 (1−t)² 使 t 越接近 1（越接近真实图像）时惩罚越重。训练时从时间分布 p(t) 采样 t，从标准高斯采样 ε，构造 z_t = t·x + (1−t)·ε，极小化 ‖v_θ − (x−ε)‖²。生成时从 z_0 ~ N(0, I) 出发，每步计算 v_θ，按 z_{t_{k+1}} = z_{t_k} + (t_{k+1}−t_k)·v_θ 做 Euler 更新至 z_1。

### 4.2 高维下的 x-prediction 优势

JiT 在 ImageNet 高维 patch 上的实验结果值得注意。同样使用 v-loss 训练，预测 x 的 FID 为 8.62，预测 ε 为 372.38，预测 v 为 96.53，差距超过一个数量级。而在低维 patch 上三者表现接近。

分析其原因：x 空间具有强结构性，图像像素之间存在强相关；ε 空间是各向同性的高斯噪声，缺乏内在结构。在高维情形下，网络在有结构的目标空间中更容易学习有效表示。这一结果表明，预测目标的选择对最终效果的影响可能超过网络架构设计。

## 五、实验分析与方法对比

### 5.1 评价指标

FID（Fréchet Inception Distance）将生成图像和真实图像分别送入 Inception 网络提取特征，计算两组特征的均值差平方加上协方差相关的项，值越低越好，衡量的是生成分布与真实分布在特征空间中的距离。

IS（Inception Score）对每张生成图像计算分类器给出的类别分布的尖锐度（可辨识性），同时检查所有图像类别分布的均匀度（多样性），值越高越好。

### 5.2 关键实验结果

DDPM 在 CIFAR-10 上取得 FID 3.17、IS 9.46。渐进生成实验中大尺度结构先出现、细节纹理后补上，与渐进压缩的直觉吻合。

DDIM 复用 DDPM 预训练权重，仅改变采样方式。编码-解码实验表明步数越多重建误差越小，验证了确定性 ODE 的可逆性：图像可以编码为噪声再解码恢复。

Rectified Flow 的 Reflow 实验效果直观。首次学出的轨迹交叉率为 46.39%，Reflow 一次降至 0.76%，再次 Reflow 降至 0.14%，L_2 传输代价同步下降。轨迹越直，所需 Euler 步越少。

JiT 的实验结果已在第 4.2 节详述。值得补充的是：高维生成任务中预测目标的选取比网络架构调整更为关键，这一结论具有很强的实践指导意义。

### 5.3 方法对比

以下从五个维度进行比较。

采样类型。DDPM 是随机的，每步注入噪声。DDIM 将噪声项关闭，变为确定性过程。Score-SDE 从理论上证明了确定性 ODE 与随机 SDE 在边际分布上的等价性。Flow Matching 和 JiT 均在确定性框架下工作。

训练路径。DDPM 定义在 T 个离散步上，典型值为 1000。DDIM 不额外训练，直接复用 DDPM 参数。Flow Matching 将时间推广为连续区间 t ∈ [0, 1]，模型学习连续速度场而非离散转移核。JiT 固定使用直线路径，省去了学习路径形状的环节。

预测目标。DDPM 和 DDIM 预测 ε。Flow Matching 预测 v。JiT 三者均支持，且证明了它们可以线性互转，选择哪一种可按经验决定。

少步采样能力。DDPM 步数大幅削减时质量急剧下降。DDIM 可以跳步，S << T 仍可采样。Flow Matching 通过 Reflow 拉直轨迹后只需极少 Euler 步。JiT 在高维下使用 x-prediction 配合 v-loss，少步效果最优。

核心思路。DDPM 的关键词是扩散-去噪框架；DDIM 和 Score-SDE 是确定性 ODE 等价性；Flow Matching 是连续归一化流；JiT 是预测-损失-采样解耦。

## 六、统一视角：生成式模型的学习本质

上述方法本质上在做同一件事：学习如何从噪声分布中采样出数据分布。

模型并非一次性计算"最可能的图像"。它在每个中间步骤预测下一步的方向——可能是条件高斯分布的均值，可能是 score function 的方向，可能是速度场的方向——然后将所有小步拼成一条完整的生成轨迹。DDPM 的轨迹带有随机性，ODE 类方法是确定性的（初始噪声唯一决定结果），JiT 则进一步表明路径形状、时间权重和求解方式都可以分开优化。

生成模型涉及的数学工具相当广泛，包括贝叶斯推断、流形假设、最优传输和数值积分，扩散模型这条线将它们串联在了一起。

## 七、局限性与展望

本文主要覆盖无条件生成这一分支。score-based 模型在逆问题（inpainting、超分辨率等）上的应用尚未涉及。噪声调度的设计原则及其对生成质量的系统影响有待进一步分析。Consistency Models 和 MDLMs 等更新的工作也值得后续跟进。

多步采样的计算开销仍是扩散生成模型的主要瓶颈。轨迹拉直（Reflow）和蒸馏（Consistency Models）是两条核心加速思路。JiT 的解耦思想能否推广至更一般的噪声调度和网络架构，以及 x-prediction 范式在视频生成、3D 生成等高维输出场景中是否仍能保持优势，都是值得进一步验证的问题。
