## PuDGhost: Experimental Analysis of Computation Result Corruption in Processing-using-DRAM Operations on Real DRAM Chips and Implications for Future Systems

- baseline方法是什么？
  - Baseline 是 PuDGhost-unaware 的 PuD 计算系统：采用 Ambit 及其后继（SIMDRAM/MIMDRAM/Proteus 等）的 compute-row 架构——每 subarray 保留 6 条 compute rows，行解码器修改为允许特定三元组同时激活执行 MAJ3，其余 storage rows 经 RowCopy 把数据搬入 compute rows；可靠性仅依赖 post-manufacturing column screening（随机输入识别并过滤不可靠列，如 PuDTune 方法论）与 PuD ECC（如 Count2Multiply），并假定"每列计算只依赖自身操作数"的理想模型（PuD 模拟框架如 PIM-SUM 也假设列间错误独立）。该 baseline 未考虑：相邻行（含其他 MAJX 的 compute rows）数据在执行期间动态变化、以及并发计算列输入对 SA 采样的电气干扰。
  - 全栈执行例子：GEMV 请求（8-bit、4096×N）→ 系统框架层：矩阵/向量数据经 RowCopy 从 storage rows 搬入 compute rows（6 条，相邻即为其他 compute rows）→ 编译/调度层：把位串行乘加展开为 MAJ3 布尔序列 → kernel 调度层：对 compute rows 发 APA 序列执行 MAJ3（行解码器激活指定三元组，65536 列并行）→ 硬件架构层：每列电荷共享后 SA 采样，输出本列 MAJX → 芯片层：若相邻 compute rows 被其他 MAJX 覆盖了新操作数，或并发列输入不同（含 7/8 列操作数差异），SA 采样被干扰偏置（相邻行最高 ±10%、并发列最高 ±48%）。screening 用固定随机相邻行数据标定"可靠"列，但执行时相邻行数据动态变化 → 被标定的列实际出错（CBR 2.1%、BER 9.2×10⁻⁵、GEMV NMSE 最高 5.8×10⁻²、TRNG 熵损失 93%）。其他层：算法层、软件框架层论文未明确说明（PuD 位串行计算链）。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 论文把"计算隔离"（computation isolation：计算结果不应受未参与计算的数据影响）作为 PuD 的首要正确性约束，基于 96 颗真实芯片的 15 条观察提出跨层缓解，直接针对 baseline 的"相邻行数据在执行期间不可控"与"screening 与执行条件不一致"两个缺陷：(1) CS-1：screening 阶段变化相邻行数据（全 0/全 1 两极端即够），只保留在所有模式下都可靠的列——把 screening 的覆盖从"列间并发干扰"扩展到"相邻行数据模式"，无需运行时支持但可用列数少；(2) CS-2 + isolation-row 布局：screening 与执行使用同一固定相邻行数据，并在 compute rows 之间放置固定数据 isolation rows（7 条/1024-row subarray、+0.68% 行开销、一次初始化）——从结构上把执行期相邻行数据锁定为固定模式，使 screening 结论在执行期保持有效；(3) 残余错误由 PuD ECC（Count2Multiply）或 error-tolerant 应用（EDEN 重训练的 DNN、基因组搜索）兜底，并指出刷新/时间间隔、process variation 降低、既有 read-disturbance 缓解（RowHammer/RowPress/ColumnDisturb 类）均无法消除 PuDGhost（瞬态、数据相关、无 aggressor 激活）。
  - 全栈执行例子：GEMV 请求（8-bit、4096×N）→ 系统框架层：初始化 isolation rows（固定全 1 模式、正常刷新、不参与计算），数据经 RowCopy 写入 compute rows → 编译/调度层：位串行 MAJ3 展开（每操作数冗余两行 + 常量 0/1 行，8 行 SiMRA）→ kernel 调度层：APA 序列执行 MAJ3，相邻行始终为固定 isolation rows → 硬件架构层：screening（CS-2-1，8192 样本全 1 相邻行下零错误）标定可靠列，执行期相邻行数据不变 → 芯片层：SA 采样不再被变化的相邻行/不可控并发列偏置，输出接近理想（GEMV NMSE <10⁻³ 即相对 Base-worst 413× 降，TRNG 仅损失 7% 熵），残余错误由 PuD ECC 兜底。算法层、软件框架层论文未明确说明。
