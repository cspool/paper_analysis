## Don't Surrender to Low QPS/$: Fast and Cost-Efficient ANNS with TridentANN

- baseline方法是什么？
  Baseline 为四类 SSD 单机十亿级 ANNS 系统：(1) 图式 DiskANN/PipeANN——图索引分层放内存/SSD，多跳遍历，每查询 I/O 仅 ~0.2-0.3 MB，单 SSD 下 6.9-16.5K QPS，但多跳串行 I/O 使其 latency-bound，加 CPU 核会加剧 SSD die 级冲突、加 SSD 边际收益递减（DiskANN 8 SSD 仅 9.9K、PipeANN 12.5K QPS），QPS/$ 停在 ~2.2-3.9；(2) 聚类式 SPANN——1B 数据生成 ~160M 质心（16% 数据集规模），定位最近簇耗时占总时间 30-40%，单 SSD 仅 1.8K QPS；8 SSD 时带宽利用率仅 35-40%（~21 GB/s），瓶颈从 SSD 带宽转移到主机内存带宽（质心搜索 2-3 + 写簇 1-2 + 扫描 1-2 GB/s 每 1K QPS，DDR4 上限 ~90-100 GB/s），16 SSD 仅再涨 10%；(3) GPU 聚类式 FusionANNS——PQ 压缩向量常驻高端 GPU HBM（SIFT1B 需 ≥32 GB），每查询 I/O 降至 ~0.1-0.4 MB、达 18-22.5K QPS，但 32 GB HBM + 双路大核 CPU 使整机 ~$8.4-10.3K，QPS/$ 仅 ~2.14-2.18。全栈执行例子（SPANN）：查询 → CPU 在 160M 质心图定位最近簇（算法层）→ CPU-only 单线程/多线程搜索路径（系统框架层）→ NVMe 读簇列表写主机内存 → CPU SIMD 距离计算 + 堆排序 top-k（kernel 调度层）；主机内存带宽先于 SSD 带宽成为短板（硬件架构层，论文未明确说明芯片级细节）。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  TRIDENTANN 三点设计逐一对应三个缺陷：(1) 混合 noise-clusters 索引——三步建簇（分层 KMeans 质心 → 拆分超大簇 + candidate 继承 → 滤小簇分离 noise 并补齐列表）后，小簇噪声向量不再生成冗余质心，质心数从 160M 降至 15M-60M，定位最近簇的搜索空间最多降 85%（头部延迟降至 40-60%），并天然解耦 noise 与 cluster 两条搜索路径；(2) GPU-SSD P2P 直通 + Work Group PCIe 拓扑——4 SSD×4 lanes + 1 GPU×16 lanes 组成 32-lane Work Group，簇列表不落主机内存直进 GPU，自研 (nvme_ns,lba,block_cnt) 三元组轻量 I/O 栈用户态轮询 NVMe 队列，SSD 带宽利用率从 30-40% 提到接近满载，吞吐随 SSD 数量近似线性扩展（bandwidth-centric scaling 架构原则：用廉价 SSD 带宽替代昂贵 HBM/CPU）；(3) measure-then-allocate 异构任务编排——距离计算放 GPU（cuBLAS，并行代数强）、受设备带宽限制的 top-k 排序放 CPU（partial_sort，分支密集 CPU 强），noise 搜索与 cluster 加载/计算并行流水，规避低端 GPU 排序瓶颈与串行流水开销。全栈执行例子（TRIDENTANN）：查询 → CPU 在内存 HNSW 查质心、由哈希映射定位 (nvme_ns,lba) 并算 block_cnt（算法层）→ 用户态 I/O 栈直接提交 NVMe 队列、SSD 经 P2P 直写 GPU query slot 的 Cluster Lists 区（系统框架层）→ Work Group 内 32-lane PCIe 传输（硬件架构层，主板 PCIe 拓扑组织，无 RTL）→ GPU thread-local stream 跑 cuBLAS 距离 kernel 输出 FP32 IP（kernel 调度层）→ cudaMemcpy KB 级 IP 回 CPU，CPU 按 IP+Norm 推导 L2 并 partial_sort，与内存 BKT noise 搜索并行后合并 top-k（调度层）。消融：GDS 直通仅 +5%、自研直通 +30%、排序移 CPU 再 +54-74%、noise/cluster 并行后总 2.17-2.43×；最终 8 SSD + 2×A2000-6GB（整机 ~$4.3K）达 33.5K QPS、1.8-3.4× 吞吐、21-70% 延迟、~7-9 QPS/$（2-4×）、1.5-3.7× QPS/watt。
