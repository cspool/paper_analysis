## Distilling Magic States in the Bicycle Architecture

- baseline方法是什么？
  - Baseline 1 = surface-code lattice-surgery MSD 工厂（Litinski [46]）：在多个 d×d surface code patch 上执行蒸馏协议，块间用 lattice surgery 做逻辑测量/路由，每 patch 需 d²+(d−1)² 物理 qubit 且工厂要多个 patch + 多轮 surgery；(15-to-1)SC(17,7,7) 4620 qubit / τ=256 / 体积 1.2×10⁶，两级 (15-to-1)SC(11,5,5)+(15-to-1)SC(25,11,11) 共 12420+18280 qubit。Baseline 2 = Gidney 魔法态培养 MSC [30]：物理魔法态注入 surface code 后靠多轮 post-selection + 物理非 Clifford 门压低错误，454 qubit 达 2×10⁻⁹，但 post-selection 开销指数扩展、不 asymptotic、够不到大规模 FTQC 需要的 ≤10⁻¹²。缺陷：低目标错误率下 surface-code MSD 需要千~万级物理 qubit 与大量长程块间连接、解码复杂度高；MSC 存在错误率天花板。
  - baseline 全栈执行例子（surface-code 15-to-1 一轮，Litinski 工厂，p_phys=10⁻³）：模型推理算法层 = triorthogonal 15-to-1 协议在多个码距 d 的 surface code 数据块上执行（d_X,d_Z,d_m 三重码距标注）；系统框架层 = lattice surgery 工厂布局：多个 patch 经 surgery ancilla 做块间路由与逻辑测量，输入/输出依赖块间长程连接；编译框架层 = 论文未明确说明（Litinski 采用手工 transpilation 思路，无公开编译器）；kernel调度层 = 论文未明确说明（时序由三重码距决定，τ=256，每步 surgery 轮的深度开销直接由码距支付）；硬件架构层 = (17,7,7) patch 阵列 4620 物理 qubit + 多 patch surgery 连接。整体痛点：qubit 开销是主要瓶颈，块间连接与解码复杂度随工厂规模增长。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 方法 = 把 MSD 工厂整体搬进单个 BB 码块（Bivariate Bicycle QLDPC 码 + LPU），配合四类端到端编译优化：①逻辑 qubit 映射最大化 native 测量覆盖；②masking 用空闲 qubit 的 Z 因子把非 native 旋转 nativize（零深度）；③TSP 门调度最小化相邻测量的 automorphism 重定向开销；④双轨并行（ZX-duality 两 6-qubit 块同跑两个协议副本）。再加协议级压缩（qubit recycling）把大协议塞进单块（49-to-1 13→7、51-to-3CS 18→9、64-to-2CCZ 17→10）。缺陷→设计映射：千级 qubit 开销与多块 surgery → 单块 378/734 qubit 内完成全部蒸馏，省去长程块间连接、降低解码复杂度；MSC 无 asymptotic 扩展 → 以 BB 蒸馏作第二级把 MSC 的 10⁻⁹ 级输入压到 35·(10⁻⁹)³≈3.5×10⁻²⁶ 量级，突破 MSC 天花板；BB 原生测量受限（仅 15×36=540 个 native 多体测量）→ 映射+masking 提升 native 覆盖、TSP 降低 automorphism 轮数，使每个旋转变成 1 次 automorphism 序列 + 1 次 LPU 测量。
  - 论文方法全栈执行例子（Cultivation+(15-to-1)Two-gross 两级工厂产出一个蒸馏 |T⟩，p_phys=10⁻³）：模型推理算法层 = 一级 surface-code MSC 注入物理 |T⟩ 经 post-selection 得 p_in=10⁻⁶ 的 |T⟩ → 经 adapter（universal surgery ancilla，inter-module 测量）注入 two-gross 块；二级为 15-to-1 triorthogonal 协议（m=5 逻辑 qubit，按 [46] 测量基形式实现 15 个 exp(iπ/8·Z^⊗S_c) 旋转 + 4 个 X 基 parity check 测量）；系统框架层 = 单 [[288,12,18]] two-gross 块 + 158-qubit LPU，pivot 注入：|T⟩ teleport 到 pivot L0 → in-module 测量传到目标 qubit，条件 Clifford 校正吸收进 pivot 的 X/Y 测量（概率 3/4 时两轨串行）；编译框架层 = mapper/masking/TSP 编译流水线：5 个协议 qubit 放入 6-qubit 块（枚举 S 选 native 最多、平局按 pivot 距离），非 native 旋转经 masking 全 nativize，TSP 求最小 automorphism 开销旋转序（编译开销 TSP <3 s、mapping ~10 min、压缩 <5 s，Table II）；kernel调度层 = 15 步「shift automorphism 序列（τ=14，错误 10⁻¹⁴·⁵）+ LPU 原生测量（τ=216，错误 10⁻¹¹）」交替执行，两轨 L0–L5/L6–L11 同时测量；硬件架构层 = 454（MSC surface patch）+ 734（two-gross 块+LPU）qubit，τ=11080，二级时空体积 8.1×10⁶，p_out≈4.1×10⁻¹²（λ=0.5，Table III），低于 MSC 单级可达范围；p_phys=10⁻⁴ 时 ≤10⁻¹⁷（对比 SC 两级 7.2×10⁻¹⁴）。
