## Five-Minute Rule 40 Years Later A First-Principles Revisit for Modern Memory Hierarchy

- baseline方法是什么？
  - Baseline 是 Jim Gray & Putzolu 1987 年的五分钟规则及其后续 revisit（1997/2007/2019）：按经济性做页面级数据放置决策——把 DRAM 的"租金"与反复从存储取页的成本平衡，break-even 间隔 τ_break-even = (每 MB 页数 ÷ 存储 IOPS) × (存储成本 ÷ 1MB DRAM 成本)，仅依赖存储设备价格与峰值 IOPS 规格。2019 年最新 revisit 仍把 DRAM↔SSD 阈值定在分钟级（"tape is dead, disk is tape, flash is disk"）。其两大缺陷：(A) 不现实——把主机资源当免费（CPU 核周期、中断、DRAM 带宽），依赖厂商峰值规格，忽视 NAND 物理时序、内部并行与块大小缩放；(B) 缺可行性——只优化设备价格（$/GB、$/IOPS），忽略主机 IOPS 上限、延迟/吞吐 SLO、DRAM 带宽/容量约束，无法给出可部署、可操作的配置与升级指导。
  - baseline 全栈执行例子（经典五分钟规则下的 512B 数据块缓存决策，CPU+DDR 平台）：模型推理算法层 = 论文未明确说明（规则与算法无关，仅做数据放置）；系统框架层 = 应用按两层层次（DRAM+存储）访问数据，规则判定"访问间隔<分钟级则驻留 DRAM，否则留在存储"；编译框架层 = 论文未明确说明；kernel调度层 = 主机 CPU 每 I/O 消耗核周期/中断但被当作免费资源，SSD 按厂商峰值 IOPS（Normal SSD 4KB 平直 IOPS）满负荷假设；硬件架构层 = DRAM 只按容量租金计价、SSD 按峰值 IOPS 平摊成本，忽视主机 IOPS 预算、DRAM 带宽/容量、NAND 通道/plane 物理极限 → 结论：阈值落在分钟级，flash 只配当容量层，无可行性/升级指导。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 方法 = 从第一性原理把五分钟规则重写为可操作、可行性感知的分析与配置框架，四层递进：①校准经济模型（RQ1，对应缺陷A）——把主机成本显式计入 savings（每 I/O 的核成本 $CORE/IOPS_CORE + DRAM 带宽成本 l_blk·$H_DRAM/B_H_DRAM + SSD 访问成本 $SSD/IOPS_SSD），并把 IOPS_SSD 与 $SSD 用第一性原理 NAND 设备模型推导（IOPS_SSD=min(设备 NAND/channel 限、FTL 翻译带宽限、PCIe 带宽/包率限)，$SSD=控制器+全部 NAND+内部 DRAM 成本），替代厂商数据表；②约束感知细化（RQ2，对应缺陷B 的可行性部分）——用 M/D/1 队列 + Kingman 重流量近似把 99 分位尾延迟目标映射为通道利用率上限 ρ_max，再与主机 IOPS 预算截断，得到可用 IOPS_SSD=min(ρ_max·IOPS_SSD^peak, IOPS_proc^peak/N_SSD)；③工作负载感知平台分析（RQ3）——用访问间隔分布 S(T) 与三个阈值 T_B（DRAM 带宽）/T_S（SSD 带宽）/T_C（DRAM 容量）判定平台 viability（max(T_B,T_S)≤T_C）与 economics-optimality（τ_break-even∈[max(T_B,T_S),T_C]），否则诊断瓶颈资源（DRAM 带宽/SSD 吞吐/主机 IOPS/容量）并给出升级路径；④软件重思考（RQ4）——GPU+Storage-Next SSD 把阈值压到秒级（512B SLC 从 CPU+DDR ~34s 降到 GPU+GDDR ~5s），flash 升格为主动层，用 blocked-Cuckoo SSD 原生 KV 与两阶段渐进 SSD ANN 两个案例示范设计空间。
  - 论文方法全栈执行例子（GPU+Storage-Next SSD，512B 数据块缓存决策 + KV 案例）：模型推理算法层 = SSD 原生 blocked-Cuckoo KV（两个候选桶、每桶一 512B SSD 块、负载因子 0.7<临界 0.95、插入位移链 E[L]≪1），完全无 DRAM 驻留索引；系统框架层 = 主机（GPU，~4M IOPS/SM、GDDR6-20 640GB/s）经零拷贝 I/O 路径发起 512B 随机读，DRAM 全部用于缓存热 KV 对，WAL 合并更新后提交回桶块；编译框架层 = 论文未明确说明（无编译框架修改）；kernel调度层 = GPU 以 400M IOPS 主机预算驱动 4 块 Storage-Next SSD（SLC 57M IOPS@512B），SSD 内部 SCA 通道（τ_CMD=150ns）+ 6 平面并发（τ_sense=5μs）+ 扇区级 BCH 解码（跳过 4KB LDPC、无读放大）支撑秒级 break-even；硬件架构层 = MQSim-Next 校准验证 NAND/通道物理极限（N_CH=20、N_NAND=4、B_CH=3.6GB/s），PCIe Gen7 ×8 非瓶颈 → 结果：break-even 从分钟压到 ~5s，KV 吞吐 100+ Mops/s（FASTER 内存级），ANN 达几十 KQPS（DiskANN ~5 KQPS 量级），flash 从容量层升格为 DRAM 的主动扩展层，并给出各瓶颈的量化升级指导。
