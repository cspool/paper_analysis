## Cerberus: Cross-Layer ECC Co-Design for Robust and Efficient Memory Protection

- baseline方法是什么？
  - Baseline 是当代 DRAM 分层独立演进的三层 ECC 栈，重点两种：HBM4（JESD270-4）：每 pseudo-channel 32B 数据配 2B S-ECC + 4B O-ECC + 1B L-ECC（18.8% 开销），O-ECC 用 16-bit 符号 SSC 做最强片上纠错（无 bounded-fault 约束），S-ECC 只剩 2B、只能选 SEC-DED（漏检约 0.4%）或 CRC16，O-ECC 的检测结果仅经 SEV pin 以 CE/UE 级别传递；LPDDR6（JESD209-6）：2B S-ECC + 2B O-ECC + 2B L-ECC（12.5%），O-ECC 为 SEC-DED。核心缺陷：①各层独立编码、冗余分区不可复用——HBM4 把 32b 冗余给了 O-ECC 后 S-ECC 只剩 16b，out-bank（TSV/外围/I/O）错误完全超出 O-ECC 范围而 S-ECC 又太弱，HBM4 对 out-bank DQE 仅约 50% 纠正；②miscorrection 放大——无 bounded-fault 的 SEC O-ECC 把约 45% 的双位错 miscorrect 成三位错，S-ECC 再以约 55% 概率把三位错当单位错 miscorrect → SDC（10^-4 原始错误率下约每 300 万次访问一次 SDC）；LPDDR6 的 O-ECC 可把三位错扩成四位错；③多层重复编码：写路径 S-ECC、L-ECC、O-ECC 连续多个编码级，增加 tWL/tCL 延迟与存储/传输开销。
  - baseline 全栈执行例子（HBM4 上一个 32B 块的写后读）：模型推理算法层 = 论文未明确说明（ECC 为内存可靠性码，无模型推理算法）；系统框架层 = 各层无信息交互，O-ECC 结果只经 SEV pin 给 CE/UE 信号，S-ECC 在不完全信息下译码；编译框架层 = 论文未明确说明（纯硬件数据通路，无软件栈）；kernel 调度层 = 论文未明确说明（无 GPU kernel 改动）；硬件架构层 = 控制器 S-ECC（SEC-DED/CRC）编解码 + 写路径 L-ECC 编码，DRAM bank group 内 O-ECC（16-bit SSC）编解码，链路侧 CRC/parity 校验。写：三次独立编码、多拍冗余传输；读：bank group 内 SSC 纠错（无 bounded-fault，SE+SE 跨符号时 miscorrect 放大），读出后控制器弱 S-ECC 只能检测或单位纠错——out-bank 外围/TSV 错误无人纠正、写路径 L-ECC 与读写数据正交导致端到端追踪断裂。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 方法 = Cerberus 跨层 ECC 协同，核心是 Encode-Once, Decode-Many（EODM）架构 + 矩阵级联合设计。(1) 对应"多层重复编码"：共享生成矩阵 GS-ECC = G1·G2（G1：256b→272b 中间码字 D+R1；G2：272b→288b 最终码字），控制器一次编码产生 32b 冗余 R1+R2，被链路/设备/系统三层按各自角色复用（LL 用 16b 检测、DL 复用同一 16b 做 SEC、SL 用完整 32b 做 SSC+DEC）；(2) 对应"冗余分区不可复用"：H2 同时满足 SEC/DED/bounded-fault/CRC8 四条件，使一份 R2 既做写路径 CRC16 级检测（1−2^-16）、又做片上 SEC-DED；H^S-ECC 用完整 32b 在 12.5% 开销下实现 HBM4 用 48b 都做不到的 SSC+DEC 端到端覆盖；(3) 对应"miscorrection 放大"：bounded-fault 约束（任一 16 列区域列和 ≠ 其他区域列；构造上区域后半 8 列为前半 8 列 XOR 组合），O-ECC 任何 miscorrection 都留在原 16-bit 符号内、不增加 S-ECC 符号错误数；(4) 对应"跨层不可见"：跨层条件 row(H2) ⊆ row(H^S-ECC)（等价于 GS-ECC = G1·G2 存在），把符号化的 H2（GF(2^16)）直接嵌入 H^S-ECC 上部——满足该条件即可接入 Cerberus，支持 vendor 私有 S-ECC 方案、可扩展；(5) 对应"码构造难"：两步构造——先奇数权重列 + 区域 XOR 结构建 H2（bounded-fault + CRC8），映射到 GF(2^16)；再贪心搜索构造 H^S-ECC 下部（随机赋值 GF(2^16) 元素、二值化后检查 SSC/DEC 的 syndrome 无重叠，重叠则重建该符号直至满足）。
