## Shining Light on Silicon Photonic DNN Accelerators

- baseline方法是什么？
  - Baseline 是先前提出的各类 SiPh DNN 加速器（DEAP [6]、Albireo [10]、Lightening-transformer [13]、OC [15]、Mirage [14]、CrossLight [12]、PIXEL [9]、DNNARA [7] 等），它们假设光域模拟计算在理想条件下工作：报告高 MAC 精度（Albireo 7-bit、Lightening 4-bit、Mirage 5-bit，部分工作孤立器件分析声称 10/16-bit），但仅基于孤立光器件特性，忽略全信号链的模拟信号完整性——E/O 与 O/E 非线性（Table I 中仅 [15] 考虑 TX 非线性且未评估精度）、ISI（无人考虑）、光域 MAC 眼高损失（无人考虑）、系统级光损耗（无偏置 3dB/2dB 裕量）、激光 WPE 与波导功率上限（多数设计超限）。多数工作不评估 DNN 精度（Table I 中 [15][10][11][6][16] 的 Accuracy 列为 N/N/R），能耗基于理想线性 TX/RX 与线性调制假设。
  - baseline 全栈执行例子（以 Albireo/MZM 型加速器推理一个 ResNet50 层）：① 算法pipeline 层——权重/激活量化到宣称精度（4~7-bit）直接映射为光域振幅电平；② 系统框架层——论文未明确说明（专用加速器，无 serving 框架）；③ 编译框架层——论文未明确说明（固定 tiling/dataflow 假设）；④ kernel 调度层——输入激活经串行器 → TX 驱动直接驱动 MZM（无线性化补偿）→ 光域加权和 → 光电二极管电流 → 二进制/非线性 TIA 直接判决 → ADC；⑤ 硬件架构层——理想损耗预算（不计调制器偏置 3dB、裕量、ISI、MAC 眼高损失），激光功率按理想通信 SNR 设置（6.99~23 dBm/λ），未核对波导功率上限 → 输出：宣称的低能量/MAC（pJ~fJ 级）与高精度。缺陷：实际 4-bit 量化模型在任一非理想因素未补偿时 ImageNet 精度掉 >10%，3-bit 下 MZM 非线性使 ResNet50 掉 >25%、MobileNetV2 近零；多数设计实际工作在波导非线性区之上、无法正确工作。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 论文方法（分析/评测型工作，不提出新加速器）系统建模并量化 SiPh 加速器的全部模拟信号完整性因素：① 调制器静态非线性（MRM Lorentzian Pout=Pin(1-K_ring/(1+βV²))、MZM raised-cosine Pout=Pin/2(1+cos(πV/Vπ))）→ 用 (n+k)-bit 分段驱动/非线性补偿逻辑线性化 E/O（k=3，比先前 [15][27] 的 k=1、[20][35][39] 的 k=2 更保守），线性 TIA 保证 O/E 线性（4-bit 需噪声 <2^(n+1) 可分辨电平、失真 <(1/2^(n+1))%）；② ISI → 提高驱动带宽（5GHz 时钟需 >12.5GHz、10GHz 4-bit MAC 需 >40GHz）或 1-tap FFE 均衡，并把 ISI 输出分布注入 DNN 精度评估；③ 新识别光域 MAC 眼高损失机制（多输入-权重组合同值压缩判决裕量，3-bit 8.45dB / 4-bit 11.76dB）→ 用 10×/21× 更高激光功率补偿；④ 系统级光损耗预算（含偏置 3dB、裕量 2dB、SiN 波导 200mW 上限）与激光 WPE 约束 → 能量/MAC 在 iso-accuracy/iso-throughput 下与数字加速器对比，得出 SiPh 加速器能量/MAC >5× 于数字的结论。
  - 论文方法全栈执行例子（同一 ResNet50 层在纳入补偿的 16×16 MRM SiPh 加速器）：① 算法pipeline 层——4-bit QAT 模型（QAT 学最优动态范围），LLM 用 AWQ int4 权重 + per-block 激活量化（14 batch × 74 hidden dim，困惑度 6.82@int8 最接近基线 6.79）；② 系统框架层——论文未明确说明；③ 编译框架层——论文未明确说明（输出驻留数据流假设）；④ kernel 调度层——激活经串行器 → 带非线性补偿逻辑（(n+k)-bit 驱动，16nm 综合）的线性 TX（Vswing 2V、Cmod 40fF）→ MRM 调制（ER 20dB 偏置）→ 光域加权和（8-128 λ 在 PD 累加）→ 4-bit 线性 TIA（85.2mW、1.3μA 噪声）→ ADC（5GHz/10GHz 各选 SAR/时域 ADC）；ISI 由高带宽驱动/FFE 抑制；⑤ 硬件架构层——光功率追踪器计入全链损耗（splitter/Y-branch 0.05dB + MRM 1dB + 波导 0.03dB/cm + 偏置 3dB + 裕量 2dB + MAC 眼高损失 11.76dB + ISI），激光功率升至满足 DNN 精度所需 SNR（>35mW/λ），heater 用 undercut+行共享省 >9× → 能量/MAC：16×16 ≈3pJ（4-bit、5GHz）比数字 <150fJ 高 20×；纳入全部因素后相对理想 baseline 能量 >100×，SiPh 加速器失去能量效率优势（>5× 于数字，iso-accuracy/iso-throughput）。对未来的启示：SiPh 只在光域原生输入（如 in-network optical computing 中光接收器直接做 MAC、光传感/成像模拟预处理）或低精度混合数字-SiPh（<4-bit 光域 MAC + 数字 4-16-bit 高精度/纠错管线）场景才可能可行。
