## Coset Ensemble Decoder for Quantum Error Correction with Algorithm-Hardware Co-Design

- baseline方法是什么？
  - baseline = vanilla MWPM（Blossom 求最小权完美匹配，物理 ML：argmax p(E|s)）与 vanilla UF（聚类+生成树+peeling 的近线性近似），及其硬件实现 Micro-Blossom（MWPM）、Helios、QUEKUF（UF，FPGA，per-vertex PE 空间并行）。全栈执行例子（UF 硬件解码器处理一个 d 轮 syndrome 任务）：算法层 UF 在 syndrome graph 上并行增长/合并聚类至各簇偶校验，再建生成树 peeling 出匹配边；系统-框架层为量子控制系统中的实时解码子系统，须在 <1 μs（一次 syndrome 提取轮）内完成；编译框架层论文未明确说明；kernel调度层 Helios/QUEKUF 将顶点/簇映射到分布式 PE 阵列空间并行，以 per-iteration 协调 + convergecast 收敛；硬件架构层资源随码距空间展开（spatial），QUEKUF 在 d=8 即 309k LUT / 548 BRAM，Helios 存在 per-iteration 延迟地板。
  - baseline 缺陷：① 算法上只做物理 ML，忽略 degeneracy——高简并 stabilizer 码中同一 syndrome 的多个物理错误链分属不同逻辑陪集，最可能单链未必对应最可能逻辑错误，而系统可靠性由 LER 决定，故"最优物理解码"未直接优化目标量（coset ML 精确求解又指数复杂/NP-hard）；② 硬件上 spatial 架构资源随码距快速增长、可扩展性差；Von Neumann 式流水 baseline 的 profiling 显示 clustering pipeline stall 独占 48–58% 总延迟。

- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 方法：coset ensemble decoding = UF 式聚类 + K 次随机优先级森林探索（同一聚类图，不同 seed 的 keyed priority φ(v,e)=HashToUnit(seed,i,v,e)）+ ROE 逆序单趟 peeling + 逻辑结果多数投票，以多项式时间近似陪集级 ML（argmax p(L|s)），同 L 候选互为退化错误（Lemma 1）、采样频率 n_L/K 估计陪集概率（Lemma 2 证明聚类把全局问题松弛为局部最优）；lossless graph compression 仅保留根-根/根-边界边降低 K 次探索代价；硬件上以时间复用架构（单条 7 级深度流水 clustering engine + K=24 复制 EFE 实例）替代空间展开，配合 22-bank 冲突无关哈希、层级 ID 映射（VID→RID→CID）与 forwarding bypass 消 stall。全栈执行例子（同一 d 轮 syndrome 任务）：算法层聚类后对 K 个 seed 采样优先级，每个候选建一棵优先级森林，ROE 按发现序逆序单趟 peeling 得 E_i/L_i，对最小 |E_i| 子集投票选最频逻辑陪集——候选对陪集"隐式投票"；系统-框架层论文自定义系统 infidelity Ĉ(R)=1−(1−2E(d))^{max(1,R)/d}（R=L/l 解码延迟折算为提取轮数），量化反馈解码中 B patch 延迟对 A patch 保真度的损耗；编译框架层论文未明确说明；kernel调度层 clustering 每周期流式处理一个 VID，S4 增长判定经 bypass 回喂前级解 RAW，顶点/边并发访问经线性同余哈希散到 22 bank（中心+6 邻居 pairwise 冲突无关，d≤15 单周期），merge 的 CID 重映射收敛到 RID→CID 小表（写扇出从触及 VID 数降到 RID 数）；硬件架构层单 RTL 覆盖全部码距（时间复用），163 MHz、108k LUT（d=15，较 QUEKUF 归一化少 4.3× LUT/14.7× FF），K 个 EFE 分支不占关键路径、每分支仅 ~50 mW。
  - 效果对照（缺陷→设计→结果）：物理 ML 忽视简并 → 陪集投票 → LER 从 d=3 与 MWPM 持平（1.0×）到 d=19 仅 2.1×（K=24，p=0.002），远优于 UF（UF 落后 2.7–5.7×，biased 下落后 6.2×）；流水 stall 48–58% → 哈希+层级 ID+bypass → stall 1–7%、整体 2.2–3.6×，d=9 时 p99 3.09→0.90 μs（较 Micro-Blossom 低 3.5–4×、略低于 Helios）；spatial 资源膨胀 → 时间复用 → 较 UF 类硬件最多省 8.2× LUT、频率 3.7× Micro-Blossom；延迟-精度耦合 → 自定义 Ĉ(R) 指标 → d=11 系统 infidelity 较 Micro-Blossom 低 74.3%、较 Helios 低 51.7%。可调 knob：候选数 K 按 LER(K)=LER_∞+A·K^{−α} 幂律收敛，K*=2^{⌊(d+1)/2⌋} 取 70% 收益，形成精度-面积 Pareto 供不同 FTQC 负载定制。
