## Leveraging Phase Polynomials for Quantum Circuit Optimization

- baseline方法是什么？
  - Baseline 是 phase polynomial 优化（Rotation Merging [11]、Single-block Greedy Optimization [10,15]、Gray-Synth [10]）与通用 subcircuit rewriting（Quartz [17]、QUESO [18]）。共性痛点：① phase-parity 与 output-parity 分开优化——phase 网络单独贪心合成，output 网络事后高斯消元，但同一 phase 实现可诱导不同 output 代价（Fig.3：两个同样 2 CNOT 的 phase 最小实现分别引出 2 与 3 CNOT 的 output 代价）；② 单 block 限制——H 等 basis-changing gate 把线路切成独立 phase polynomial block，Gray-Synth 等只能做 block-local 优化，不能跨 block 复用 parity（MCX 中跨 block 的 q0⊕q2 parity 重复计算无法消除）；③ 局部重写窗口小——Quartz/QUESO 的 ECC 只覆盖 3 qubit/6 门窗口（构造更大等价类计算不可行），大电路下重写性能随规模迅速退化（19→100 qubit MCX 上明显下滑，最大实例直接失败/饱和）；④ 跨 block rotation merging 用 anchors/terminal points 实现复杂、正确性保证弱。
  - Baseline 全栈执行例子（一次 MCX 线路的 Toffoli 链优化）：算法层：phase polynomial sum-over-paths 表示 U|x⟩=e^{ip(x)}|g(x)⟩ 只适用于单个 {CNOT,Rz} block，H barrier 把优化范围锁在 block 内；系统框架层：phase 优化仅作为 Quartz/QUESO 重写前的预处理（rotation merging / polynomial identity filter），不是独立编译阶段；编译框架层：Quartz 用预生成 ECC（3-qubit/6-gate 窗口）匹配局部子电路替换，QUESO 用 phase 信息扩充 ECC 后同样局部重写——每个 Toffoli block 单独优化到 ~4 CNOT（原始 6），跨 block 的长期奇偶性无法复用；kernel调度层：论文未明确说明（量子编译为经典侧，无 GPU kernel）；硬件架构层：优化后线路仍含较多 CNOT，映射到 2D grid 时 SWAP 路由开销大，FT 下 magic-state distillation 主导时 T 昂贵、cultivation 进步后 CNOT 与 T 成本可比（CNOT 不能继续被忽视）。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 方法：PhasePoly 编译器 pass，三方面对应解决：
    1. **耦合 parity 矩阵联合优化**（对应解决 phase/output 分离缺陷）：把 phase 项与 output parity 统一为列式 parity 向量，构成 [phase-parity | output-parity] 耦合矩阵，一次 CNOT 行操作同时更新两 block（Fig.7），用 space-bounded A* 搜索（f=g+h1+h2，priority queue + 多解池 k）直接最小化总 CNOT——找到 Fig.3 中整体最优的 (a)（2 CNOT phase + 2 CNOT output 而非 3），把两个子问题合成一个 NP-hard 合成问题的联合启发式求解。
    2. **SSA + cross-block IR**（对应解决单 block 限制）：H 后状态分配 fresh SSA ID，Rz 按 SSA ID 全局合并（整线路 rotation merging，正确性判据简化为"同 SSA ID 即合并"）；cross-block parity 矩阵中 post-H 行 inactive，pre-H 行满足"phase 全零 + 行/列隔离（单位向量）"时用 rank(M∪{v})=rank(M) 检验可消除性（等价于 v∈span(候选行)），消除后插 H 激活——把 H barrier 两侧 block 合并，跨 block 复用 q0⊕q2 parity，MCX 中约一半 Toffoli 结构从 ~4 CNOT 降到 3 CNOT。
    3. **Incremental Block Merging + 结构化矩阵推理**（对应解决局部重写规模退化）：不依赖固定窗口 ECC，直接操作 parity 矩阵，规模随电路自然扩展（矩阵行/列数随 qubit/phase 项数线性增长），渐进扩大合并组、只保留改善步骤避免过合并回归；大电路（hwb8_113 104k 门）仍在 <5,500 s 内完成并持续线性增长，而 Quartz/QUESO 饱和或失败。
  - 论文方法全栈执行例子（同一次 MCX 线路优化）：算法层：跨 block sum-over-paths 表示——SSA ID 扩展的 phase 函数跨 H barrier 合并 rotation，cross-block parity 矩阵表达长期奇偶性（q0⊕q2 在 block 1 生成、block 3 复用）；系统框架层：PhasePoly 作为独立一等编译阶段，可与 Quartz/QUESO 正交组合——PhasePoly 在前收益最大（重写后接 PhasePoly 再增 ≈6–13%，反序仅 0.75–1.25%），"先全局 phase 后局部重写"构成推荐流水线；编译框架层：输入 OpenQASM 2.0 → 预处理（X 前推、H 对消、H-bracketed CNOT 化简）→ block 划分 → 耦合矩阵 + SSA rotation merging → cross-block 合并（rank check + incremental）→ A* 搜索合成 CNOT 序列 → 高斯消元合成剩余 output 网络 → 输出等价线路（MCX 示例：8 CNOT+4 Rz 区域 → 消除 2 个冗余 CNOT，一半 Toffoli 结构 3 CNOT）；kernel调度层：论文未明确说明（无 GPU kernel，编译为经典侧 A* 搜索）；硬件架构层：减少的 CNOT/两比特门经 Qiskit SABRE 映射到 2D grid 后 SWAP 减少、物理深度平均减 28.35%（大电路族 40.84%），Azure Resource Estimator 下 FT wall-clock 运行时减 44.62%，GridSynth 之前应用 PhasePoly 使 Clifford+T 合成引入的额外 H barrier 更少、最终深度更低（结构化 parity/HWPA ansatz 电路平均 ~10% 深度减）。
