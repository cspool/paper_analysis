## ConBin: A Performance-Convergence Framework for Wafer-Scale Chip Binning

- baseline方法是什么？
  - Baseline = Cerebras 专利 [39] 拓扑保持冗余 + 修复（CB*：每 core 六条 2-hop 短程冗余链、抽取缺陷无关的子 mesh 作为可用阵列；为控制规模影响叠加本文修复）+ 两种调度：CUPOKer（NFT，非容错负载分配器，ISPD 2020 CS-1 WSE 冠军）与 Si-Kintsugi（SK，SOTA 容错调度，以 hop 数/通信距离为代价函数），以及传统按频率/核数分级的产品 binning（Intel/AMD 式）。缺陷：(1) 短程冗余只能局部绕过空间分离故障，无法桥接聚簇故障（相同故障数下聚簇时可用 mesh 从 79% 掉到 63% 健康核；128×136 下激活核平均 5122 = 全健康修复的 38%、方差近 3×），拓扑优先于利用率；(2) hop 数最小化调度忽略 contention——故障下 contention 才是主要延迟源（Fig.9：hop 延迟 5–6 跳后饱和，任务间 contention 近线性增长），且"越难恢复的芯片越难优化"，调度放大芯片间性能方差（强者更强、弱者更弱，Fig.5）；(3) 传统 binning 以频率/核数分级，与 WSC 实际性能（计算+通信共同决定）脱节，性能方差大迫使保守阈值，premium-bin yield 与总可售有效算力 SECC 双低。
  - baseline 全栈执行例子（128×136 WSC 上 GPT-2.7B 推理）：算法层：GPT-2.7B（32 层、d=2560）逐层 GEMM/attention 前向；系统框架层：论文未明确说明（无 serving 框架，负载由 CUPOKer/Si-Kintsugi 静态映射调度）；编译框架层：论文未明确说明（无编译器，负载以 WG 依赖图直接映射）；kernel 调度层：CUPOKer 按核数贪心放置 DNN 层 / Si-Kintsugi 以 hop 数代价函数映射并调度通信（忽略 contention）；硬件架构层：Cerebras 式 mesh + 每 core 六条短程 2-hop 冗余链，聚簇故障处长绕行路径与集中流量形成瓶颈 router/链路。结果：故障下通信非线性退化、芯片间性能发散（raw perf 分布宽、高 bin 芯片稀少，Fig.2）。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 方法 = 三层收敛的 ConBIN 框架 + Performance Binning 范式。硬件层：自动化故障相关感知冗余互连设计（EGA 搜索 R_max=6、L_max=4 的 R-R/P-R 混合冗余模板，适应度 F=λ·D̃+(1-λ)·R̃ 取 bottom 30% lower-tail 均值、λ=0.9 优先连通性下界）——以"短程保局部 mesh + 长程桥接聚簇区"直接对应短程冗余无法桥接聚簇故障的缺陷（F_norm >88% vs Cerebras <46%）；制造后修复（P-R 链 BFS 重绑定抢救 router-only 故障核的 PE + 端口择优近 mesh 互连）对应"拓扑优先牺牲利用率"。软件层：pre-binning（按 F 分位分组 + top 5–15% 采样定 bin 目标）→ bin 感知映射（SEGA 最小化 MLCC_exp）→ 通信序列调度（NSGA-III 最小化 CAP contention、μ 历史传播）——把优化目标从"最大化单 chip 加速"改为"收敛到 bin 目标、达标后升级"，对应 SK 放大方差与忽略 contention 的缺陷（Ours-ALL* 方差降幅 79.21%、speedup 2.39×）。分 bin 层：以实测负载性能分级 + DP 求 SECC 最优阈值，对应传统核数/频率 binning 与 WSC 性能脱节的缺陷（premium-bin yield 2.80×、阈值收紧 2.09×、SECC 2.64×、最高 3.85×）。
  - 论文方法全栈执行例子（同一 128×136 WSC、GPT-2.7B）：算法层：GPT-2.7B 转为 WG（节点=GEMM/attention 计算任务，边=带 p_{i→j} 权重的数据依赖）；系统框架层：论文未明确说明（静态产线式流程：设计期冗余模板 → 制造后修复 → 产线 pre-binning → 每 chip 映射调度 → 分 bin 出货，无在线 serving 框架）；编译框架层：论文未明确说明（无编译器）；kernel 调度层：pre-binning 给该 chip 定 MLCC_exp^target/Φ^target → SEGA 把 WG 映射到修复拓扑最小化最大链路 contention（达标后升级 bin 目标，最多 2 次）→ NSGA-III 按 CAP 切分传输时间线优化通信序列（三粒度批处理 + μ 历史传播）；硬件架构层：每 router 2 P-R + 2 短 R-R + 2 长 R-R 冗余链（MUX 选择、修复后每端口激活一条）、turn-prohibition 路由，ScaleSim+BookSim 联合仿真输出 latency。结果：性能分布收敛 → DP 分 bin 阈值更激进 → premium-bin yield 2.80×、总 SECC 2.64×（vs CB*+SK*，8 bins）。
