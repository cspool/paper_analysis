## DejaVu: Why You Should Write to Your DRAM Rows Twice, Carefully

- baseline方法是什么？
  - Baseline = 读干扰测试与缓解中"victim row 只写一次"的初始化方式（Listing 1：write_row(R, victim_data) 只执行一次），也是此前所有 RowHammer/RowPress 表征工作的隐含做法——完全不考虑写入历史对器件行为的影响；PUD 操作（MAJ-3）同样以"输入行只写一次"为基线。
  - baseline 全栈执行例子（一次双面 RowHammer ACmin 测量）：模型推理算法层 = 论文未明确说明（本工作非推理加速算法）；系统框架层 = 论文未明确说明（无 OS/软件栈参与，FPGA 测试程序直控 DRAM 命令）；编译框架层 = 论文未明确说明；kernel 调度层 = DRAM Bender 测试程序在 FPGA 上以 1.5ns 粒度发 write_row 命令序列（ACT → 128×WR → PRE，遵守 tRCD/tCCD_L/tWR/tRP）初始化 victim 行一次，随后交替 ACT/PRE hammer 两 aggressor 行（tAggON=36ns），二分法扫描激活次数测 ACmin；硬件架构层 = Xilinx Alveo U200 FPGA + DRAM Bender 直连被测 DDR4 DIMM（禁 rank ECC、停 auto-refresh、heater 控温 50/80 °C），读回 victim 行比对 bitflip。缺陷：① 测得 ACmin 不保守——真实系统中数据更新普遍发生，victim 行常处 OverWrite（先反码后目标数据）状态，其 ACmin 比 baseline 平均低 2.8%–3.5%（最大 28.1%），缓解阈值按 baseline 配置会欠防护；② 数据模式研究易被污染——按 Listing 2 的 for 循环初始化连续行会意外触发 SameWrite/OverWrite，数据模式差异会被误读为 DejaVu 差异；③ retention 测试与 PUD 可靠性同样对写历史敏感，baseline 单写未触及最坏/最优情况。
- 论文方法是什么？如何对应解决Baseline的缺陷？
  - 方法 = DejaVu 现象的首个实验表征 + 双假设归因 + 三层应用。① 表征：三种 victim 初始化（Baseline/OverWrite/SameWrite）在 112 颗 COTS DDR4 芯片上对比 RowHammer/RowPress ACmin、retention bitflip、附加写恢复时间敏感性、首 bitflip cache line 空间分布（双面 hammer、50/80/95 °C、0x00/0xFF/0xAA/0x55、1792 行 × 50 次）；② 归因假设：charge under-restoration（覆写反码使电容欠恢复，0xFF 因 NMOS 更难恢复而效应更大）与 charge trap state change（写不同值改变 active region 电荷陷阱占据态，影响陷阱辅助漏电与存取晶体管导通能力），用写恢复时间扫描与 PUD 灵敏度实验交叉验证——证明单靠前者不足以解释（OverWrite 需 >400× JEDEC 标准 tWR 才追平 SameWrite 的 ACmin），后者经 PUD MAJ-3 可靠性提升（bitline failure 降 32.7%）得到支撑；③ 应用与建议：测试方法学（测最坏读干扰阈值用 OverWrite 初始化 victim、按 cache block 粒度测试、多次重复覆盖 outlier；研究数据模式影响时用 SameWrite 防 DejaVu 污染）+ 缓解系统代价评估（Ramulator 2.0 上 PARA/PRAC 的 NRH guardband ±20% 扫描）。
  - 论文方法全栈执行例子（同一次双面 RowHammer ACmin 测量，OverWrite 模式）：模型推理算法层 = 论文未明确说明；系统框架层 = 论文未明确说明；编译框架层 = 论文未明确说明；kernel 调度层 = FPGA 测试程序先 write_row(R, ~victim_data) 再 write_row(R, victim_data)（可插附加写恢复等待），aggressor 行写反码后交替 hammer，二分法测 ACmin（每轮 <64ms、禁 auto-refresh 排除 retention 干扰）；硬件架构层 = 同一 DRAM Bender + Alveo U200 平台，双写序列改变 victim 行电容电荷与 active region 陷阱占据态后再承受读干扰，测得 ACmin 系统性低于 baseline——把"数据更新历史"这一真实系统固有行为纳入读干扰安全边界。对 PUD：同平台用 ACT-PRE-ACT 违规时序同激活 16/32 行做 MAJ-3（输入操作数复制 ⌊N/3⌋ 份、余数行用 Frac 操作），输入行以 OverWrite/SameWrite 初始化后 1K 次重复统计 bitline failure rate，较单写 baseline 降 32.7%/30.6%（32 行）——"写两次"成为免费的 PUD 可靠性提升手段。对缓解系统：Ramulator 2.0 中把 PARA/PRAC 的 NRH 降 20% 作为 DejaVu guardband，量化出 PARA 平均 6.3% 性能开销，为阈值安全裕量定价。效果总账：OverWrite 平均降 ACmin 2.8%–3.5%（RowHammer，最大 28.1%）、SameWrite 平均升 3.0%–3.6%（最大 46.1%）；RowPress 可诱导 baseline 诱导不出的 bitflip；retention bitflip OverWrite 比 SameWrite 多 10.4%（最高 36.7%）；PUD bitline failure 降 10.7%/32.7%（OverWrite，16/32 行）与 5.8%/30.6%（SameWrite）；NRH −20% guardband 使 PARA 性能开销 6.3%、PRAC 较小（+20% 时 PARA 提升 7.8%、PRAC 2.1%）。局限：两个物理假设均因芯片级可观测性受限无法完全证实（论文明确说明）；DDR5/LPDDR5 未测（无同等精度测试平台）。
