# Export Conversation Notes

## Overview

将当前会话中可用的用户输入和 Claude 最终回复保存到指定目标位置。默认目录为 `/data3/paper_analysis/human_notes/`，默认使用中文作为标题和状态文本。**不保存**过程性内容：工具调用、Shell 命令与输出、文件编辑日志、工具错误、状态更新、planning 对话、隐藏的系统/开发者/策略/运行时指令、中间推理步骤。

## Workflow

### 1. 确定目标路径

- 默认保存到 `/data3/paper_analysis/human_notes/`。
- 优先使用对话中明确提及的论文标题或路径作为文件名。若 IDE 上下文中有活跃的论文文件，取其去除扩展名的 basename（如 `/data3/paper_analysis/papers/paper_2026/71-TokenFlow.md` → `71-TokenFlow`）。
- 如果多个论文标签可见但没有明显当前论文，简要询问用户确认。
- 若无法识别任何文件名，使用当前 session 名称作为文件名（如 `session-20260603.md`）。不要自行编造标题。
- 工作路径使用绝对路径；未明确指定目录时，目标目录为 `/data3/paper_analysis/human_notes/`。

### 2. 准备目标文件

- 确保目标目录存在。
- 清理文件名：将 `/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|` 替换为安全分隔符，去除首尾空白。
- 解析出完整目标路径。

### 3. 提取对话记录

- 仅提取用户输入与 Claude 最终输出，按时间顺序排列，附带发言者标签。
- 用户消息原文保留，不做概括或改写。
- Claude 侧仅保留对用户的最终回复，排除工具调用、Shell 命令、命令输出、文件编辑日志、工具错误、状态更新、planning 对话、隐藏指令及中间推理。
- 不对保存的用户输入和最终输出做摘要、压缩、改写、规范化或重排。
- 如果早期轮次因上下文压缩而不可用，在保存的对话记录前简要说明此限制。

### 4. 写入 Markdown 文件

分三种情况：

- **文件不存在**：使用新文件模板创建。
- **文件存在但为空**：使用新文件模板写入。
- **文件存在且非空（增量模式）**：仅在文件末尾追加新的带日期段落。**绝不**修改、删除、重排、摘要、规范化、重新格式化或替换任何已有内容，即便已有笔记存在笔误、重复标题、过期元数据或格式不一致。
- 增量模式下使用仅追加方式编辑，在已有内容的最后一行之后添加新行。
- 如果本次记录过长无法一次写入，分多个连续块追加，直到所有当前可用的用户输入和最终输出全部写入。

## Markdown Template

### 新文件模板

```md
# <论文标题或 session 名称>

- 导出时间：<YYYY-MM-DD HH:MM TZ>
- 来源：当前 Claude Code session 可用对话上下文
- 保存路径：<解析后的目标路径>
- 范围：仅用户输入与 Claude 最终输出

## 对话记录

### 001 User
<用户消息原文>

### 002 Claude
<Claude 最终回复原文>
```

### 增量追加模板

在文件末尾追加（不修改已有内容）：

```md
---

## 对话记录补充：<YYYY-MM-DD HH:MM TZ>

<继续相同的时间顺序格式，仅保存用户输入与 Claude 最终输出>
```

## Completion Response

保存后简要回复输出路径以及是创建还是追加。如有标题推断不确定性或对话上下文不完整，一并说明。
