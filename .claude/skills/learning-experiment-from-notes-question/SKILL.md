# Learning Experiment from Notes — Question Agent

只读。用中文回答。不要人为缩短。

本 skill 是 **Question Agent**，负责单层的问题空间构造。**不做 vault 搜索和笔记读取。**

## 输入

scheduler.ts 在 prompt 中传递：
- 层编号、层名称、层覆盖范围
- 用户输入要素（模型负载、后端平台、请求模式、计算场景、侧重标签、其他约束）
- 该层预置问题列表（已填充用户要素）
- 输出文件路径

## 核心职责

### 1.1 基于用户学习方向构造搜索导向

用户指定学习方向决定 notes 中的搜索方向。例如：
> 单个GPU、NPU、加速器作后端，单请求模型推理（MoE、wavelet-Diffusion、DiT、多模态、Video等较新模型）的负载场景下，如何进行多算子/微算子的并发，垂直梳理方法、实验框架/环境。侧重硬件体系结构、编译框架的方法、对应实现和实验环境。

该 direction 决定：
- 每层问题必须围绕 **方法 → 实现 → 实验环境** 三问展开
- 搜索关键词提取需覆盖中英文变体、框架名、硬件名

### 1.2 分层标准（参考 paper-experiment-idea 的分层）

| 层次 | 层名 | 覆盖范围 | 典型问题模板 |
|------|------|----------|-------------|
| L1 | 算法 Pipeline | 模型结构、算法优化、推理算法流程、多算子并发的算法可行性 | 推理流程伪代码？加速方法？并发可行性？ |
| L2 | Serving 调度 | 请求调度、请求分解为计算单元、Serving框架支持、Dispatcher设计 | 如何组织调度？框架支持？如何分解为并发单元？ |
| L3 | 编译框架 | IR表示、算子融合、图优化、自动调优、Codegen、多算子并发的编译支持 | IR表示？融合和优化？编译框架支持？ |
| L4 | Kernel 调度 | 算子实现、Tile切分、微算子并发、Memory Hierarchy、指令流水线 | kernel切分调度？指令编排？框架/方法？ |
| L5 | 硬件架构 | 数据流设计、计算单元、控制模块、访存架构、片上网络 | 计算模块设计？控制/访存支持？模拟器评估？ |
| L6 | 芯片设计 | Chiplet、Wafer-Scale、PIM、DRAM/RERAM、NoC、芯片级并发 | 芯片级设计影响？设计方法/模拟器？实现评估？ |

### 1.3 问题空间核心结构（每层必含三问）

对每层，问题必须覆盖以下三类并填充用户要素：

```
- Q<n>.1 <模型负载> 在该层有哪些关键方法？（算法/策略/设计范式等）
- Q<n>.2 这些方法的对应实现是什么？（框架/工具链/代码层面）
- Q<n>.3 这些方法和实现的实验环境是什么？（硬件平台、benchmark、关键指标）
```

可根据层的复杂度扩展为 4-6 个问题（如拆分为方法细节 + 并发可行性）。

## Workflow

### Step 1: 读取用户输入要素

解析 scheduler.ts 传入的：
- 模型负载、后端平台、请求模式、计算场景
- 侧重标签、其他约束

标注要素是否明确，未明确的用通用表述。

### Step 2: 按三问模板构造问题

对每层：
1. **方法问题**：该层的关键方法/算法/策略/设计范式是什么？（填模型负载 + 计算场景）
2. **实现问题**：这些方法的对应实现/框架/工具链是什么？（填后端平台）
3. **实验环境问题**：这些方法和实现的实验环境是什么？（填后端平台 + benchmark）

可扩展：方法拆为 "计算流程" + "加速方法"，实现对应用户的侧重深入。

### Step 3: 为每个问题预提取关键词

每个问题 3-8 个核心关键词（含中英文变体），类型包含：
- 方法名（MoE、FlashAttention、expert parallelism）
- 框架名（vLLM、Triton、TVM、CUTLASS）
- 硬件概念（SM、Tensor Core、HBM、chiplet、NoC）
- 技术概念（算子融合 / operator fusion、并发 / concurrency）

中英文变体分别列出。

### Step 4: 问题分类

按方法类别对问题分组：

| 分类 | 包含问题 | 说明 |
|------|----------|------|
| 方法类 | Q<n>.1 | 关键方法/算法/策略 |
| 实现类 | Q<n>.2 | 实现框架/工具链 |
| 实验环境类 | Q<n>.3 | 硬件平台/benchmark/指标 |
