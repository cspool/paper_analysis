## 混合整数规划图划分（MIP Graph Partitioning，Gurobi）

混合整数规划（Mixed-Integer Programming, MIP）是数学优化问题的一类：目标函数与部分/全部约束中的变量被限制为整数（或 0-1 二元变量）。本论文用两个 MIP 模型解决图态生成的两个子问题，由 Gurobi 求解器求解。(1) MIP-1 目标图态划分：把程序图态 g_prog 划分为最小融合次数的线性子图集合——每条 CZ 边定义二元变量 x_e∈{0,1}（1=边保留在子图内、0=边被切断用于融合），约束每个顶点度 deg(v)≤2（保证子图是线性图，可被 caterpillar 态生成），目标函数 K=|E|-Σx_e 最小化总切割边数（=总融合数）；后处理切断循环线性图中的一条边使其无环，并按硬件最大 caterpillar 长度（30 qubit）把过长的子图再细分。(2) MIP-2 BBT 节点二分：把 G^l_i 划分为 G^l_j、G^l_k——变量 y_g^l∈{0,1} 表示线性子图分到左/右子树，平衡约束 |G^l_j|,|G^l_k|≥2^⌊log2|G^l_i|⌋，目标 L=Σ_{(v1,v2)∈E}|y_{g1}-y_{g2}| 最小化跨分组切割边数。两模型复杂度 O(|E|) 与 O(|G^l_i|) 二元变量数，编译时间相对 OneAdapt 平均 0.14×。

MIP 图划分在编译框架中的具体计算（MIP-1，3 个 4-qubit 线性子图的划分例子）：
```
# 决策变量
x_{e,v1,v2} = 1 若边 e 保留在子图中; 0 若切断用于融合
# 约束（每个顶点度 ≤ 2, 保证线性子图）
Σ_{e incident to v} x_e ≤ 2,  ∀ v ∈ V
# 目标（最小化融合数）
min  K = |E| - Σ_{e∈E} x_e
# Gurobi 求解 -> 最优切割集合 C*；K* = 融合总数
# 后处理：
#   - 对循环线性子图: 切断一条边使其无环
#   - 对超长线性子图: 按 caterpillar 30-qubit 上限再细分
```
张量/图论视角：图态 g_prog 的边 = CZ 纠缠（每边一次融合操作可重建），"保留的边"构成内部纠缠（由 caterpillar 直接生成），"切割的边"构成需要融合重建的连接——最小化切割 = 最小化融合次数 = 最小化错误暴露。MIP-2 递归执行到叶子单图，最终输出 BBT 及每层切割边数（每时间步融合数）。

实现方式：MIP 用商业求解器 Gurobi 求解（论文明确使用 Gurobi）；模型规模为二元变量 O(|E|) 与 O(|G^l_i|)，在经典 CPU 上编译期求解。使用场景：MBQC 编译器中"把任意目标图态分解为硬件可生成结构"的通用问题——约束由硬件决定（caterpillar 是线性结构 → deg≤2；caterpillar 长度上限 → 30 qubit），目标由成本决定（融合次数/临界路径）。在编译框架层面，MIP 是 MemTree 的"离线算子优化"核心，属于离线/编译期优化（对比 kernel 调度的运行时决策）。论文未开源。
