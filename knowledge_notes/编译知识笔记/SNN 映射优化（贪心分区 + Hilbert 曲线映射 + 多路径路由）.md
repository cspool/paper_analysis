## SNN 映射优化（贪心分区 + Hilbert 曲线映射 + 多路径路由）

- SNN 映射（mapping）是把 SNN 计算图（层/算子）分配到多核加速器（神经核 + NoC）的离线优化流程，目标是同时最小化 NoC 流量、最小化所需峰值带宽（RPB，required peak bandwidth）、最大化 PE 利用率。ELSA 的三阶段映射算法（Fig.14）：① 分区（partition）——决定哪些层合并进同一个神经核；② 映射（mapping）——把分区放置到物理核；③ 路由（routing）——确定核间 flit 的传输路径与概率。
- 三个子算法：① 贪心分区（Algorithm 2）：按层间通信量 c_ij 从大到小排序，若合并后内存 a_i+a_j<A 且神经元电路数 d_i+d_j<D（A/D 为核容量）则合并两相邻层进同一分区——层内划分可省掉 tiling 策略的 spike 广播与 PE 间 spike 归约；② Hilbert 曲线映射：借用 [26] 的算法，先按 Hilbert 空间填充曲线（分形、连续、把一维区间递归映射到二维）生成初始放置，再把核间通信建模为"力势"，用贪心最小化总势能迭代精化；③ 多路径路由：X-Y 路由只走单一路径（如 P3→P4）易拥塞、抬高 RPB；ELSA 探索最短路径之外的两条替代路径绕过热点，再用遗传算法优化各路径的传输概率以平衡流量。

- 映射流程（一次 ResNet50 部署到 6×6 核）：
```
输入: 各层内存需求 a、神经元电路数 d、层间流量 c_ij、核容量 (A,D)、核数 N、层数 L
1) 分区: sort(c, reverse)          # 流量大者优先合并
   for c_ij in sorted:
     if d_i+d_j<D and a_i+a_j<A: 合并层 i,j 进分区 s_i
2) 映射: Hilbert 曲线初始放置 → 核间通信建模为力势 →
   贪心迭代最小化总势能得到放置
3) 路由: 对每对邻接核生成最短路径 + 2 条替代路径 →
   遗传算法优化各路径传输概率（存储于路由引擎各端口概率表）
输出: 各层→核 的放置表 + 各 (src,dst) 的路径概率表
```
- 例（ELSA 论文 Sec.VI）：ResNet50 中流量大的层对（如 conv 层到下一层）被优先合并进同分区，避免跨核 spike 广播；多路径路由把 ResNet50 的峰值带宽从 X-Y 的 17.9 GB/s 降到 11.9 GB/s（ViT-S 从 11.9→11.6 GB/s，Fig.27），且 flit 分布比 Valiant/X-Y 更集中、通信更均衡。运行期路由引擎据此概率表为每个 flit 选出口端口（静态路由，无运行时决策）。
- Annotations：A/D 是核资源容量（内存、神经元电路数）；力势 = 把核间通信量当作核间吸引力/排斥力势能；遗传算法优化的是多路径间的概率分配（离散概率向量），目标是最小化最大链路流量/RPB。
