## Wafer 级故障容错（制造缺陷与运行期退化，通信路径级容错）

Wafer 级故障容错指 wafer-scale 芯片上针对两类故障源的可靠性保障：其一为制造缺陷（fabrication-induced defects）——光刻不精确、颗粒污染、晶格缺陷等导致部分计算节点或互连从出厂起就失效或潜伏失效（H100 与 Cerebras WSE-3 缺陷率约 0.001/mm² [35]）；其二为运行期退化（runtime degradation）——电迁移（金属互连中原子迁移）、热载流子注入（晶体管随持续电热应力退化）等老化现象渐进损害电路可靠性。常见容错路线：(1) 冗余硬件（Cerebras WSE 备用 core 与备用互连）——直接但硬件开销大；(2) 通信路径级容错（Google TPUv4 流量重路由）——以最小额外制造开销让缺陷芯片逼近标称性能。BusyBarn 采用后者：BALD 通信算法与层次化映射在故障存在下重优化路由与算子放置，只需存活图连通即可容忍任意节点/链路故障。

在芯片设计中的运转流程（BusyBarn 故障模型 + 故障注入）：故障节点 = 节点及其所有邻接链路失效；故障链路 = 双向链路失效。评估覆盖 5×5 mesh 单故障链路 (12,13)、6×6 mesh 上 7 类故障场景（1 节点/1 链路/2 节点/2 链路，节点 0,1,2,7,8,14、链路 (0,1)(1,2)(2,3)(7,8)(1,7)(2,8)(8,9)(8,14)(14,15) 等，覆盖不等价故障类 modulo mesh 对称性），以及 20×20 core mesh 上 10%/15%/20% 随机/聚集缺陷率。容错实现：主机在每次推理任务前把 BALD 算出的路由配置加载进路由器 LUT、执行中按需更新（LUT 可重配置→同时适配制造缺陷与运行期故障）；映射侧 SA 在含故障约束的拓扑上重建 Hamiltonian Loop 与负载均衡布局。结果：All-Gather 有效带宽 1–1.94×、All-to-All 1.56–2.55×（vs XY routing）；1 个故障 core 时映射 1.24–1.30×、缺陷率 10–20% 时 1.24–1.53×（vs Gemini）。

实现与使用：硬件侧依赖可重配置路由器 LUT（类似 TPUv4 [83] 的 LUT 机制）与拓扑无关的容错路由算法；软件侧在部署前运行映射/路由优化（BusyBarn 的 SA 映射 + BALD 调度），把故障拓扑当作约束重算。评估经事件驱动模拟器注入故障并测有效带宽/端到端延迟。对比工程实践：Cerebras WSE 用 1×1 网格冗余路由绕过缺陷核（硬件冗余路线）；ConBin 对单片 WSE 提出按实测性能 binning + 故障相关感知冗余互连（制造后性能收敛）；BusyBarn 的通信路径级容错与二者互补——不增加冗余硬件、不做 binning，而是让优化算法在故障图上自适应。
