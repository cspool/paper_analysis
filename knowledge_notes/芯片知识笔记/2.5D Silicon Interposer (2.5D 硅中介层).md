## 2.5D Silicon Interposer (2.5D 硅中介层)

2.5D silicon interposer 是一种封装集成技术，在 package substrate 和多个 dies（如 GPU + HBM stacks）之间插入一层硅中介层，通过硅基板上的微凸点（microbump）和硅通孔（TSV）实现 dies 之间的高速互联。相比传统 PCB 走线（毫米级线宽），silicon interposer 使用硅工艺的亚微米线宽金属层，实现更高的布线密度和信号完整性。Stratum 的 xPU die 和多个 Mono3D DRAM chips 通过 silicon interposer 互联，采用与 HBM3 兼容的 interposer I/O 标准（1024-bit data I/O, 6.4 Gbps/pin）。

在 Stratum 系统配置中：
- Stratum-S：1× RTX A6000 + 1× Mono3D DRAM chip
- Stratum-L：1× H100 + 6× Mono3D DRAM chips
- Stratum-XL：2× Stratum-L modules（通过 NVLink cross-chip interconnect）
Interposer 承载 xPU-to-Mono3D DRAM 的数据通路（external bandwidth ~819 GB/s per 6-chip configuration），而 Mono3D DRAM 内部通过 hybrid bonding 的逻辑-NMP 通路带宽为 19-34 TB/s。Interposer 是 external bandwidth 的瓶颈所在，这也是 Stratum 将大量计算 offload 到 NMP logic die 的原因——尽量减少穿越 interposer 的数据量。

2.5D silicon interposer 已广泛用于高性能计算产品：NVIDIA A100/H100/H200（GPU + HBM via CoWoS-S）、AMD MI300X、Intel Ponte Vecchio 等。Interposer 通常使用成熟工艺节点（65nm）制造，面积可达 3× reticle（~2500 mm²）。TSMC 的 CoWoS（Chip-on-Wafer-on-Substrate）是最成熟的 2.5D 封装方案系列。主要局限：(1) interposer 面积和 reticle 限制 multiple chips 的集成规模；(2) interposer I/O 带宽受限于 PHY 和物理布线，通常远低于片上带宽；(3) thermal dissipation 在 interposer 上堆叠多 chips 时成为挑战。
