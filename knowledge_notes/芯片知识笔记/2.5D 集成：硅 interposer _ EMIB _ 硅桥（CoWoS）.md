## 2.5D 集成：硅 interposer / EMIB / 硅桥（CoWoS）

术语是什么？回答尽量完整，回答逻辑链中每一步都解释出来。通过联网搜索让回答具体和精准。
2.5D 集成把多个裸片并列放置，经高密度中介层互连：(a) passive 硅 interposer——大尺寸硅片承载全包高密度布线，适合带宽密集场景（如集成多个 HBM）；(b) 硅桥/EMIB（Intel 的 embedded multi-die interconnect bridge）——小硅片只做局部 die-to-die 连接，硅用量小、成本与良率优。代表性产品：TSMC CoWoS-S（第 5 代达 2500mm²，ECTC 2021）。CAPA 建模：interposer 视为"blank silicon + 5 层 D2D 金属"（EMIB 为 4 层金属），C_Si = CPW_Si/(N_Si×Y_Si)（Eqn. 15），Y_Si 用总金属面积 A_D2D,total 代入负二项公式（Eqn. 1）；因无公开碳数据，CPW_Si 给高低两档估计（低档不含 Scope 1、用 Garcia Bardon 能耗数据作 Scope 2 + Boakes 裸硅晶圆碳作 Scope 3；高档用 65nm 全 Scope 数据、D0=0.06、α=6）。

整包 2.5D 组装碳 C_2.5D = (C_Si + Σ_i(C_i + C_bond_i)) / Π_j Y_bond_j（Eqn. 18）：interposer 碳 + 各 die 碳与键合碳之和，再除以全部键合良率之积。具体案例：A100 用 ~1575mm² interposer、H100 ~1623mm²、MI300X ~3000mm²、TPUv4 ~1119mm²；SPR 用 10 个 EMIB（3 种尺寸）连接 4 个 CPU die。D2D 金属面积按 Eqn. 14 由带宽需求折算（MI300X：10.8TBps / 4.38 Tbps/mm² = 19.7mm²/chiplet）。替代性试验：把 H100 与 MI300X 的 interposer 换成匹配同等 D2D 带宽的 EMIB，整包碳均降约 14%——代价是更多组件、装配复杂化与不同物理设计。

术语一般如何实现？如何使用？通过联网搜索让回答具体和精准。
实现：CoWoS（TSMC）、EMIB/Foveros（Intel）等；interposer 制造本质是一块大尺寸硅 + 多层金属（论文取 5 层，源自 CoWoS-S 的 5 代 2500mm² 报道）。碳建模上 interposer/EMIB 的难点是缺乏公开碳表征（论文只能给区间），而面积与金属层数决定 CPW_Si 与 Y_Si——CAPA 敏感性分析显示 interposer 的 D0 扫 ±0.03 对 H100 整包影响约 1%（interposer 碳占比仅 ~10.4%）。

DIAMoND 的用法（ISCA'26）：2.5D 封装把 in-NAND 计算模块与 near-DRAM 计算模块经各自独立 SSD 通道集成于同一封装，提供充足通道带宽（ONFI 6.0/JESD230G，每通道 4.8GB/s、两通道共 9.6GB/s）。in-NAND 模块沿用标准 SSD 形态：16 dies / 2 通道，每通道 8 die 垂直堆叠为一个 SSD 包，Control Die（I/O 接口 + 加法树）经 TSV 连 8 个 NAND die（类 SanDisk/SK-Hynix HBF 的 die 间堆叠）。这种"存储侧异构集成"使 FFN 专家矩阵在 NAND 侧算、attention/KV cache 在 DRAM 侧算的分工可行，是边缘 MoE 整机（总面积 149.02mm²）的封装基础。

MTIA 300 补充视角（ISCA'26）：MTIA 300 以 2.5D CoWoS 集成 compute chiplet + 2 个网络 chiplet + 6 个 HBM3E stack（interposer 50.3×51.9 mm、3.2× 放大、封装 77.5×77.5 mm），chiplet 间经 die-to-die 接口 + 112G SerDes 互联。网络 chiplet 与 compute die 同封装使 RDMA NIC 无需 PCIe 即可与 PE 网格以 >1 TB/s 直连（scale-up 800 GB/s、scale-out 200 GB/s），体现 2.5D 集成把"网络功能"也纳入封装级集成（相较 A100/H100 的 GPU+HBM CoWoS-S 用途）的最新趋势；同时 compute die 因 reticle 限制加入冗余 PE 行（良率修复，每列容忍 1 个坏 PE）。

Omelet 补充视角（ISCA'26，2.5D/3D chiplet 分层互连模拟器）：Omelet 把 interposer 材料（silicon 0.5µm L/S vs organic 2µm L/S）建模为技术查找表条目，量化其对系统级延迟/拥塞/能耗的影响。硅 interposer：高布线密度（可放更多并行链路、path diversity 高）、细 pitch（0.5µm 起）但 intrinsic link delay 更大、per-bit 能量更高（lossy 电学特性），且 hybrid bonding 只能配硅（受控氧化物界面）；高注入率下（如 shuffle 流量）硅因链路并行度优势反而低于有机。有机 interposer：intrinsic link delay 更低（零负载延迟好）但布线密度低、可布链路数受限 → 瓶颈是共享 fabric 上的拥塞而非单链路延迟，DoubleButterfly/Kite 这类少 hop 高 reach 拓扑更有利（Fig.13 的 2.5D/3D × 硅/有机 Pareto 分析）。Omelet 还执行物理可行性检查：interposer 最大 span（如 silicon 不可 span 20mm）、beach-front 共享周长限制每 die 对链路数、TSV 密度 per mm²、keepout zone；RDL 参数复现 TSMC CoWoS 系列（CoWoS-S 0.8µm L/S、CoWoS-L/R 2.0µm L/S、前向 0.5/1.4µm），RC scaling 验证与 TSMC 数据平均差 3.5%。

RHODES 的 HBM 使用视角（ISCA'26）：RHODES 在全系统分析（§V-B）中把 HBM3 建模为"8 个 DRAM die 的 HBM stack 共 16GB、面积 107.09 mm²、平均访问能耗 7 pJ/bit"（数据源 [19][55][73]），并把 HBM 的 tC（embodied 制造碳 + memory transfer 运营碳）显式纳入鲁棒 MILP 的碳约束。作用：证明计入内存 tC 会显著改变鲁棒最优配置——忽略 HBM tC 会低估总 tC 2.28× 并导致过度配置（同 tC 约束下 c1g53 需降到 c1g19）；且为满足含 HBM 的 tC 约束需接受更高的 tC 上限（c1g53 满足的约束从 tC≤20 升到 tC≤45 kg CO2e）。设计启示：早期设计阶段内存碳信息缺失时，RHODES 配置会低估碳，设计后期必须把 HBM 计入。
