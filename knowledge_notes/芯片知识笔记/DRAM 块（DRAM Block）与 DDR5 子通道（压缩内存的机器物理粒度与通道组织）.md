## DRAM 块（DRAM Block）与 DDR5 子通道（压缩内存的机器物理粒度与通道组织）

- DRAM block（本论文术语）指 DRAM 芯片上机器物理层 64B 对齐的块；硬件内存压缩中，额外的地址翻译层把 OS 物理页映射到压缩 DRAM 的机器物理位置，压缩后原本 64B 对齐的块变成变长、变对齐，"物理块"一词有歧义（可指 OS 物理或机器物理粒度），DRAM block 明确表示 64B 对齐的机器物理粒度。DDR5 子通道（sub-channel）是 DDR5 内存通道内部的独立数据通路组织：一个 DDR5 通道通常分两个 32-bit 子通道，独立刷新与调度；DDR5-6400 指 6400 MT/s 的数据速率。
- 从芯片设计角度拆解术语：RST 把块内定位信息（6-bit 偏移，记录 DRAM 块内首个逻辑块的起始位置）嵌入每个 DRAM 块头部，随压缩数据存储；页级位置元数据因此可放宽为量化到 DRAM 块的 64-bit 向量（8B）。压缩引擎的物理布置（§VII）：DDR5-6400 系统每个子通道布置 3 个 RST 压缩器实例、16 个子通道共 48 个实例，占 4.32mm²（服务器级芯片总 die 面积可超 1000mm²），提供 ~12.3GB/s/子通道（高于观测的 ~5GB/s 平均、~12GB/s 最坏压缩需求）；压缩需求瞬时超吞吐时，控制器可推迟可选页扩展/压缩而非阻塞已压缩数据的读。压缩器空闲时钟门控降功耗。RST 也适用于 CXL 内存扩展场景——访问为 cache-line（64B）粒度而数据仍按页压缩。

- DRAM 物理组织：64B DRAM block 由多个 DRAM burst（DDR5 BL=8/16、多 bank/channel 交织）构成；压缩后的变长块经 zsmalloc 式分配器打包。RST 解压流程：位置元数据 64-bit 向量前缀和（~1ns）确定目标逻辑块所在 DRAM 块 → 取该 DRAM 块 → 块头 6-bit 偏移定位块内目标逻辑块 → 静态符号解码+LIFO 展开。设计动机：每访问压缩块都要取字典（128B 字典已是 192B per-access 取数的 2/3），故把块内精确定位嵌入块自身、页级元数据只保留 DRAM 块粒度，减少每页元数据开销（48B→8B）与 DRAM 打包碎片风险。
