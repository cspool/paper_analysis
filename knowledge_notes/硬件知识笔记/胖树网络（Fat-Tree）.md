## 胖树网络（Fat-Tree）

术语解释
数据中心经典多级 CLOS 拓扑，用普通交换机构造无阻塞（bisection 带宽近似满）网络；R2D2 的 fat-tree baseline 为 NDP（Neural/Network Dataplane，SIGCOMM'17，达最优 fat-tree 吞吐 95%+），代表现代生产实践。

- fat-tree 由叶（ToR/leaf）、聚集（aggregation）与核心（core/spine）三层组成，每层交换机端口数决定上行带宽比例；k 端口交换机可支撑 k²/4 台服务器、全带宽 bisection。等价带宽通过多路径（ECMP）与逐包/逐流负载均衡实现。
- 论文配置（附录）：512 节点用 FS N8610-32D 32×400Gb 交换机（$18.8K/1000W，48 台），2048 节点用 N9510-64D 64×400Gb（$37.3K/2524W，96 台），8192 节点 3-tier 用 N8610-32D（1280 台）；NIC 为 Broadcom P1400GD 400Gb（$2198）；服务器侧铜缆接 ToR、交换机间光缆。
- 规模成本：512→2048 节点 fat-tree 成本 $2.89M→$11.5M；8192 节点 3-tier $55.8M/1.46MW。交换机占网络成本 31.3%、功率 80.8%（512 节点）。

- 一次远端内存访问在 fat-tree 上的数据通路：compute NIC → 铜缆 → ToR 交换机（逐包查表、500ns/跳）→ 上行光缆 → 聚集层 → core 层 → 下行 → 目标 memory 节点，多跳转发共享链路带宽、incast 时碰撞拥塞、有效吞吐下降。这是 R2D2 单跳直连对比的核心痛点（FCT 平均改善 43.3%、吞吐 70.2%）。
- 逐跳 500ns×多跳 + 共享瓶颈 vs R2D2 单跳被动光纤（省 ToR 455ns、端到端省 ~42% 延迟，全线路速率 400G）。

- 实现：标准三层 CLOS + ECMP 多路径 + RDMA（RoCEv2）承载；NDP 提出新型网络数据平面（主动队列管理、capped 多路径、快速重传）达到最优吞吐 95%+。使用：作为 disaggregation 网络的专用 fat-tree（独立于应用网络），评估中与 R2D2 比较成本（R2D2 -23~-38%）、功耗（-80~-84%）、FCT/吞吐。
