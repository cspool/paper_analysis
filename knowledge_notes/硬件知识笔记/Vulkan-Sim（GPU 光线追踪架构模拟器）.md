## Vulkan-Sim（GPU 光线追踪架构模拟器）

术语是什么？回答尽量完整，回答逻辑链中每一步都解释出来。通过联网搜索让回答具体和精准。
- Vulkan-Sim 是 UBC Aamodt 组开发的 cycle-accurate GPU 架构模拟器，支持跨厂商 Vulkan API 的光线追踪（MICRO 2022 [44]），基于 GPGPU-Sim + Mesa 构建，显式映射 Vulkan ray tracing pipeline 到现代 GPU（RTA + SM），提供可配置的 RTA 模型（warp buffer、遍历栈、运算单元 RBIU/RTIU/TRAN、延迟调度等），广泛用于 RTA 架构研究（[54]-[56] 等）。开源：https://github.com/ubc-aamodt-group/vulkan-sim（v2.0 用 Lavapipe 驱动）。GauTracer 用它作为评估平台（配置匹配 RTX2060：30 SM、32 warps/SM、65536 regs/SM、128KB I-cache、64KB L1+SMEM、3MB L2、core 1365MHz、mem 3500MHz、1 RT unit/SM、RT warp buffer 4），并外推 RTX3090 级参数（82 SM、L1/L2 加倍）做扩展性分析。
- 从硬件架构角度拆解术语，给出运转流程具体例子：GauTracer 在 Vulkan-Sim 中修改：①遍历逻辑集成 treelet-based stack loop（counter table 调度）；②BVH 节点打包/解码（叶 descriptor 类型 1→2 bit，新增 Gaussian 类型路由）；③实现 RGIU/AGHU/far-node pruning 全套 ray-Gauss 功能（运算单元延迟 Table III：RBIU 13、RTIU 37、TRAN 5、RGIU 27、AGHU+PRUNE 2~12 cycles，从 Agner Fog 指令表推导）；④Ray buffer 扩展 Hit Gauss Buffer（16 项/射线寄存器）+ hit counter。模拟流程 = Vulkan ray tracing 程序（Gaussian procedural 原语 + Embree 建的 BVH）+ RTX2060 配置 → 逐周期推进 SM 调度/warp 遍历/运算单元/cache/内存 → 输出每射线延迟分解、shader 指令数、访问节点数、内存流量、warp 活跃率、命中数；功率用 AccelWattch（https://github.com/accel-sim/accelwattch）trace-driven 模型估算能耗（6.6×/7.5× 能量效率提升）；功能测试全分辨率、性能评估采样中央有效渲染区域射线子集以减仿真时间。
- 术语一般如何实现？如何使用？：Vulkan-Sim 需要 Mesa（驱动）+ 应用 trace；v2.0 基于 Lavapipe、v1.0 基于 Intel 驱动 + trace runner（配套 LumiBench 基准集 https://zenodo.org/records/8267898）。GauTracer 使用方式：扩展其 RTA 模型 + 运行自定义 Gaussian ray tracing Vulkan 应用 + 收集架构统计；论文未提供 GauTracer 的 Vulkan-Sim 修改源码（开源情况：论文未明确说明）。

TTP 补充视角（ISCA'26，TTP 的 Vulkan-sim 用法）：配置见表 III——8 SM、16 TB/SM、warp 32、I$ 128KB/20cyc、L1D 32KB 全相联 LRU 20cyc/256 MSHR、L2 512KB 16-way 160cyc/768 MSHR、core 1365MHz/mem 3500MHz、每 SM 1 RT unit、RT warp buffer 4、sector 32B。修改点：RT unit warp buffer 加每线程 2-bit FSM/预取指针/比较器 + 预取仲裁（demand 优先，可选 prefetch 优先）。功率用内置 GPUWattch；面积用 FreePDK45 综合 FSM（128 状态机/SM 共 1117 cells，每状态机 8.7 cells）。artifact：Docker 镜像 ttp-isca2026-ae:1.0（Zenodo DOI 10.5281/zenodo.19394324），ttp_simulations.sh 跑仿真、python3 figure*.py 读 ttp_raw_simulation_logs 出图；启动命令 ./RayTracer --scene 20 --width 32 --height 32 --samples 1 > ship_pt.log。结果：DFS 平均 1.48x（峰值 1.89x）、能量 -8.70%；30SM/64KB L1/3MB L2 配置 1.50x；256x256 分辨率 1.44x。TTP 修改版开源于 github.com/yavuz650/vulkansim（论文声明）。
