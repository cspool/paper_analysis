## GPU 功率模型（GPU Power Model，P_G(f_G, u_G) 频率-利用率功率模型）

术语是什么？回答尽量完整，回答逻辑链中每一步都解释出来。通过联网搜索让回答具体和精准。
- GPU 功率模型是用数学关系近似 GPU 在给定工作状态下的功率消耗的模型，用于把软件可控变量（频率 f_G、利用率 u_G）映射为功率估计。论文（Power Sloshing）的功率模型 P_G(f_G, u_G) 从自己的功率-频率-利用率特征化实验中推导：实测 GPU 功率随频率（动态功耗近似 P ≈ α·V²·f，随频率超线性缩放）与利用率（与 QPS 线性相关，R² 0.84-0.94）单调增长，功率受限时频率降到 55% f_GM 而利用率非线性陡升。模型用途：GPU 功率不瞬时跟踪频率变化，且生产平台不直接暴露 per-interval GPU 功率可用性，故控制器用该模型估算选定 f_G 下的 GPU 稳态功率 ΣP_Gi，再反推 CPU 预算 P_C = P_M - ΣP_Gi（Algorithm 1 第 10-11 行）。
- 相关参照：PowerGrad（ISCA'26，层次化集群电源管理）用线性性能模型 + 多项式功率模型，系数由硬件计数器与运行时电压/频率动态生成（数据驱动、免领域知识）；Lit Silicon 简化主动功耗为 P_active = M·f（M=αV²）。本文模型特征为"频率 + 利用率"双变量、由实测标定。

- 在功率控制环中的运转（一次控制区间）：
```
1. 采样: u_G（NVML 100ms 窗口），当前 f_G
2. 若 u_G < u_min: f_G ← Lower(F_G, f_G)   # 降频决策
3. 估算: P̂_G ← P_G(f_G, u_G)              # 用功率模型查表/函数
4. 分配: P_C ← max{0, P_M - Σ_i P̂_Gi(f_G, u_G)}   # CPU 取残差
5. 执行: SetCpuPowerLimit(P_C)            # 保证模块 ≤ P_M
```
- 物理依据：GPU 动态功耗随频率超线性增长（Fig.11 的理论下界实验：半载+降频只需 0.37×P_MQ，即 sub-linear 总功率缩放），因此模型必须显式含 f_G；同时功率随利用率增长（负载相关动态部分），故含 u_G。模型让控制器"预知"频率改变后的稳态功率，避免在过渡期内违反 P_M（GPU 功率滞后于频率变化）。
