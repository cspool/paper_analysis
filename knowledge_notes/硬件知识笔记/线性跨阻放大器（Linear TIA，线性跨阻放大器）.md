## 线性跨阻放大器（Linear TIA，线性跨阻放大器）

- 跨阻放大器（TIA）把光电二极管电流线性转换为电压。1-bit 检测可用逆变器型 TIA（低能量，如 75fJ/b），但多比特检测需要线性 TIA：在有限线性输入电流范围内电流→电压必须保持线性（非线性引入失真），且要满足两个条件——噪声-free 条件（线性范围内可分辨电平数 >2^n）与失真-free 条件（失真 < 半个 LSB，即 <(1/2^(n+1))%）。论文指出多比特检测能量显著更高（4-bit 1.52pJ vs 二值 75fJ），且 SiGe 工艺线性 TIA 可达 5-bit。

- 线性 TIA 在 RX 链路的流程（论文 Sec-II-C1）：光电二极管把跨 λ 累加的光功率变电流 Ipd=R·P → 线性 TIA 在噪声 1.3μA（论文所用 [58] 4-bit 线性 TIA，85.2mW）与线性范围内把电流映射为电压 → ADC 量化。设计约束：输入噪声 In,rms 决定最小可检测光功率（Pmin=2·SNR·In,rms/R），如 2μA 噪声 + 1 A/W 响应度 + SNR=7 → '1' 光功率需 >28μW（-15.5dBm）；线性范围决定可支持比特数（例：2.7μA 噪声 + 330μA 线性范围 + <5% 失真 → 8.73 个无噪声电平 = 3-bit）。论文指出先前工作的 TIA 都是二进制 TIA，无法解码多比特。
