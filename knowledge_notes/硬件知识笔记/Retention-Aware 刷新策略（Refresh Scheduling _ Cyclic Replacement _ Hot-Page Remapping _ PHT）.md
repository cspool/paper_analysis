## Retention-Aware 刷新策略（Refresh Scheduling / Cyclic Replacement / Hot-Page Remapping / PHT）

- Retention-aware 刷新策略是 TDMSim 论文提出的 cache 管理机制，针对 2D-material DRAM 阵列的固有非均匀性——实测显示 2D 阵列存在径向 retention 梯度：边缘 cell 因光刻邻近效应、接触电阻变化与局部互连寄生而 retention 短（10s 量级），内部 cell 长（可达 700s），绝大多数 cell 超 30s。若按最弱 cell 保守统一刷新（0.5s、约 20× 裕量）会浪费长 retention 空间、引入不必要刷新开销。策略由三个互补机制组成：(1) Refresh Scheduling——按位置分级刷新：边缘行 0.5s、中心行延至 1.5s；row 内按"物理 retention tier"（相邻 cell 组）划分，边缘弱 tier 构成的 cache ways 被限定为 clean ways（只放指令/预取数据，与主存一致、无需 snoop/写回），每行用递增计数器（写/刷新时清零、达阈值判违例）检测 retention 违例并从 backing store 重填，保证不破坏架构状态（用 Murphi 模型检查器形式化验证）；(2) Cyclic Replacement——把行最左/最右弱 tier 环接（逻辑上连接 row 两端）合并成单一 cyclic way 结构，减少 clean ways 的空间开销，tag 严格映射到非循环 way 保证标准刷新周期内 tag 有效；(3) Hot-Page Remapping——阵列被分为 HighRef（高刷新）与 LowRef（低刷新）区，用 Index Location Judge + Page Hotness Table（PHT）+ Range Scalar 把热页动态重映射到 LowRef 区：访问落入 HighRef 时查 PHT（16-bit page ID + 8-bit counter，约 4K 项共 13KB），热则 Range Scalar 按比例因子重算 set index 移到 LowRef；访问遇刷新停顿则记入 PHT 并递增计数、饱和则提升为 hot；计数器每 10K 次访问减半实现时间老化；热状态变化时失效旧映射保一致性。额外开销：PHT 约 13KB + 每行 validity indicator 共约 46KB，set mapping 单元为四阶段流水线 RTL、延迟相对数十周期的 DRAM cache 访问可忽略。

- 运转流程例子（128MB 2D-1T1C DRAM cache 上的一个内存访问）：① 请求按地址映射到 bank/row → ② Index Location Judge 判断访问是否落在 HighRef sets；若是 → ③ 查 PHT 判断该页 hot/cold；④ hot 页经 Range Scalar（低刷新区下界 + 页内偏移 + PageID 移位起始位置）重映射到 LowRef set；cold 保持原 index；⑤ 若访问因刷新停顿，PHT 对应项计数 +1，饱和即升 hot；⑥ 周期（每 10K 访问）把 PHT 计数减半实现老化，热状态翻转时失效旧映射。刷新侧：边缘行按 0.5s、中心行按 1.5s 周期刷新，clean ways 违例时按计数器触发重填。消融结果（Fig.14）：refresh scheduling +8.7% 性能/refresh energy -65.4%；cyclic replacement 再 +0.9%；hot-page remapping 再 +3.7%；合计 +13.3% 性能、访问干扰率 -75.6%、refresh energy -65.4%，最终相对 Si SRAM baseline 性能 +42.1%、总能耗 -79.4%。策略与 TDRAM 正交，结合再 +5% 性能、-15.6% 能耗。

- 实现：DRAM cache 控制器内增加刷新分级调度逻辑（按行/按 tier）、clean-ways 分配约束与 per-row validity counter、set mapping 单元（四阶段流水线 RTL，含 Index Location Judge、Range Scalar）与 PHT（SRAM 表，26-bit/项）。评估用 gem5 全系统模拟（MI300X 单 XCD）统计访问/刷新事件并用 TDMSim 参数折算能耗；正确性用 Murphi 模型检查器验证。使用要点：2D 材料 retention 分布必须实测（径向梯度是论文关键实测输入）；与硅 DRAM 的 retention-aware 研究（RAIDR 等假设弱 cell 随机分布、按行处理）不同，2D 的径向梯度要求 tier/way 级处理与热页放置联合优化。
