## Adaptive Spin Merging（自适应自旋合并，Ising 硬件 embedding）

Adaptive Spin Merging 是 SATIC++ 的硬件 embedding 技巧：动态地把"未使用"的物理自旋合并（merging）成逻辑自旋，把单个自旋上过大的 QUBO 系数分摊到多个物理自旋上，从而扩大机器的有效系数范围，减小因系数取整/缩放（超出 [−14,+14]）导致的精度损失。前人工作（文献[46]）证明多个物理自旋可合并以扩大系数范围，但只能静态暴力式地做；SATIC++ 扩展为动态合并未用自旋，且按每个问题实例的系数分布 on-demand 地平衡（未用自旋数 vs 系数范围）。评估：SATIC++ 生成子问题未能充分利用物理自旋时，Adaptive Spin Merging 把 Batch-4-100-1000 的 successful repeats 从 6,475 提到 6,621（尤其帮助更难实例），并最终使"标准 ILP + Chancellor's"（ILP 大系数被合并吸收）成为最佳配置（repeats 6,816）。

硬件 embedding 运转流程（子问题 → 芯片下发前）：
```
# 输入：45 变量 QUBO 子问题（系数可能超 [-14,+14]）
1. 统计系数分布：max|coeff|、次大|coeff|、空闲 spin 数
2. 对每个超范围/高权系数项：
     逻辑自旋 ← 合并 k 个物理自旋（k 按系数幅度分配，如系数 28 → 2 个 spin 各 14）
     # 物理自旋间强耦合绑定同步翻转 → 等效放大系数范围
3. 未用物理自旋不足时：优先合并最大系数项（on-demand，考虑实例系数分布）
# 效果：子问题仍占 ≤45 物理自旋，但逻辑系数范围显著扩大 → 精度损失最小化
```
与 Dynamic Upscaling（系数缩放）互补：Upscaling 处理整体缩放，Spin Merging 处理个别超大系数。

实现：编译/embedding 例程按系数分布做"物理自旋 → 逻辑自旋"的合并决策（静态暴力合并是其前身[46]）；芯片侧需要支持多物理自旋强耦合（全互连结构天然支持）。使用：QUBO 系数大（4SAT/ILP 天然大系数）且 spin 有富余时的标准处理；是 SATIC++ 硬件无关性验证（换 D-Wave Tabu 后端）之外、针对具体 Ising 芯片的硬件相关技巧（Machine Embedding 块）。
