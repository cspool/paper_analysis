- Lattice surgery 是在二维最近邻（2DNN）器件上实现容错通用量子计算的关键技术：通过合并（merge）与分裂（split）平面表面码 patch 实现逻辑多量子比特门（Horsman, Fowler, Devitt, Van Meter, NJP 14 123011, 2012, arXiv:1111.4022；Litinski "A Game of Surface Codes", Quantum 3 128, 2019, arXiv:1808.02892）。逻辑链：①表面码平面 patch 用 d² 个物理数据 qubit 编码 1 个逻辑 qubit，四边分别是 X 型或 Z 型边界（patch 抽象，X/Z 算子可表示成 patch 上的边缘）；②执行双逻辑 qubit 门时把相邻 patch 之间经 ancilla 中间区域合并（沿共享边界做稳定子测量），再分裂回各自 patch——合并/分裂测量实现逻辑 CNOT、parity 测量等，不需要 braiding 拓扑操作；③保持 2DNN 连通性、与平面工艺布线兼容，是超导平台（Google Willow 等）的主流 FTQC 方案；④可配合 magic state 注入实现 T 门（非 Clifford），达成通用计算。O3LS 论文中 lattice surgery 是目标执行模型：逻辑线路被编译成 patch 操作序列（初始化/变形/旋转/测量），每操作有固定时间成本（初始化 0、measurement 1、movement 1、rotation 3 时间步）。

- 在表面码晶格（patch board，N×M tile 网格）上：每个逻辑 qubit 占一个 patch（tile），ancilla patch 提供路由空间（bus）。多 patch Pauli 乘积测量（PPM）流程 = 在路由空间初始化 ancilla patch A → 把 A 依次合并到目标数据 patch 群（共享边界稳定子测量，1 时间步）→ 测量 → 分离。patch rotation（3 时间步，拆成变形+角移动+移动三片）用于把 patch 的 X/Z 边缘暴露到路由空间。O3LS 的硬件侧优化：①自动布局搜索生成 squeezed 布局——小布局缩短 ancilla 路由距离（idle 记忆错误少）但旋转频繁，大布局并行度高但路径长，评分函数找"时间步-移动距离"的 sweet spot；②松散调度动态重指派 patch 功能、用 Dijkstra 求最小 bus patch 路径，消除冗余移动与不必要旋转；③边感知初始映射把旋转需求高的 qubit 放到 X/Z 双边缘 patch，减少 3 时间步的旋转。

- 实现方式分两层：①逻辑层（编译）——Litinski 的 tile-based 模型把编译目标定为 Pauli Product Rotation（PPR）/ Pauli Product Measurement（PPM），规则如"四边标记 X/Z 型边界、patch 合并/分裂"；②物理层——实际硬件上通过每轮 syndrome extraction 电路实现稳定子测量（如 Google Willow 的表面码演示）。O3LS 在逻辑层做编译器优化（布局/合成/调度/映射四模块），评估用 STIM 仿真 d=9 表面码、p=10⁻³ 电路级去极化噪声，PyMatching 2 解码，LER 按分层模型累加。工具链：Qiskit 的 LitinskiTransformation pass（GitHub Qiskit/qiskit PR #15217）、PennyLane 的 Pauli Product Rotations 编译插件均实现 Litinski 式 PPR/PPM 编译。
- 补充（TACO 论文）：TACO 以 lattice surgery 为硬件执行模型并给出每个逻辑门的 QEC-cycle 成本（基于 [7] 资源估计）：Pauli 0 cost、CNOT 用 lattice surgery 3d+4 cycles、Hadamard 用 patch deformation 3d+4 cycles、S 门（制备+注入 |Y⟩）1.5d+3 cycles、T 门消费已备好的 magic state 2.5d+4 cycles（d=code distance）。架构上 TACO 把 surgery 原语组织进 compute/memory 双区域：compute block 的 π/4 site 同时暴露 X 与 Z 边（经 ancilla tile 连 state distillation block），使 T 门（Z 边）与 Rx(π/4)（X 边）都能单 cycle 与 magic state 做 surgery；memory block 用三行布局 + 共享 ancilla 行实现任意两比特 CNOT；patch rotation 3 cycles、qubit 在 memory↔compute 间转移 1 cycle。cycle-accurate 模拟器逐层路由非本地门（CNOT/state-injection）到 compute block（greedy 或 LSQECC 路由），TACO 电路的 locality 使 LSQECC lattice-surgery slices 从 123,139 降到 62,503（近 2×）。
