## Tensor Computing Unit（TCU，张量计算单元）

- TCU 是 TPB 内负责最计算密集张量缩并（卷积、矩阵乘）的功能单元：8×64 MAC 阵列，每个 MAC 每 cycle 执行 4 元素点积；激活数据按行复用、权重按列复用（数据复用降低带宽需求）；后接非线性激活流水线；部分和存 output buffer 写回 HBSM；含外层循环控制逻辑对大张量分块迭代、保持流水活跃。例子：32×32×32×64 矩阵乘 32 cycle 完成，匹配激活 32B/cycle、权重 64B/cycle 的输入带宽（1-byte 元素）；双缓冲维持矩阵乘与卷积的峰值吞吐。

- 运转流程：TWU 流式喂入激活/权重 → 输入缓冲 → 8×64 MAC 阵列计算（行复用激活、列复用权重）→ 部分和进 output buffer → 非线性激活流水 → 写 HBSM；双缓冲让下一 block 输入加载与当前计算重叠。张量缩并沿大轴归约，输出数据较小，写带宽很少成为瓶颈；计算完成后更新 SU 计数，下游消费者据此启动。

- 实现：MAC 阵列 + 输入/输出缓冲 + 非线性流水 + 外层循环控制（类似脉动阵列的数据复用，但以 HBSM 流式为中心而非局部寄存器驻留）。使用：由 TPB 指令配置（tensor shape、通信需求），编译器调度；是 M100 prefill（W8A8）1.95× 加速的核心计算单元。未开源。
