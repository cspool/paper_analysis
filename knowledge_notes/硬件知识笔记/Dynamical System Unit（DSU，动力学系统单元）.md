## Dynamical System Unit（DSU，动力学系统单元）

DSU 是后摩尔时代的一种新型计算单元：用 CMOS 兼容电子器件在室温下实现，让物理系统在嵌入目标问题的能量景观（energy landscape）中自发向低能态演化，到达的平衡态即"自然给出的解"，无需特殊材料或极端工作条件。一个 DSU 由 N 个节点（变量，状态为电压、存储于电容）+ N² 个可编程耦合（两两交互强度，参数 (J_ij, h_i) 实现为可编程电导）构成，系统能量用实值扩展哈密顿量 $$H_{DS} = -\sum_{i \neq j} J_{ij}\sigma_i\sigma_j + \frac{1}{2}\sum_i h_i\sigma_i^2$$ 描述（二次自耦合项 h_iσ_i²/2 是能量调节器，防止能量发散、让节点值稳定在实值平衡点而非饱和在边界）。节点动力学按能量负梯度设定：$$d\sigma_i/dt \propto \sum_{j \neq i}(J_{ij}+J_{ji})\sigma_j - h_i\sigma_i$$，右侧正是电流形式：耦合电导中流过的电流对节点电容充放电驱动电压演化，演化速度由电容/电导等电路参数决定。文献宣称相对 CPU/GPU 有 10³× 加速、10⁵× 能效提升（ML、优化、DE 求解等领域）。与 Ising 机的区别：Ising 模型自旋是二值的（σ∈{−1,+1}），DSU 用二次自耦合项扩展到实值连续变量，从而能承载图学习/训练/DE 求解/LLM 加速等现代负载。

DSU 有两大类运行模式，构成完整硬件运转流程：(1) 节点演化（推断/计算）——耦合参数 (J_ij, h_i) 保持恒定，锁定输入节点为边界条件，其余节点按式 (3) 集体演化至平衡：输入节点电压经电导耦合产生电流信号 I_in^i = Σ J_ij σ_j，与节点内部电流 I_R^i = h_i σ_i 在平衡处抵消（I_in^i 抵消 I_R^i 即节点稳定），演化结果即层输出；(2) 耦合演化（片上训练/参数自适应）——反向操作：节点被钳制到真值数据，输出节点 I_R^i 保持恒定，产生误差电流 I_loss^i = I_in^i − I_R^i（Electric-Current Loss），反馈回路据此调节可编程电导使 |I_loss| 最小化。底层控制靠 selector 逻辑（BRIM 式 pull-down 网络按列激活 + 共享 programming bus 广播配置数据，只有被寻址的组件接收总线数据），DS-ISA 把它当作默认基础组件并抽象成标准化指令接口。演化时长由外部控制器给出（本论文用 Time Registers 倒计时机制），而非片上收敛检测。
具体例子（一次 ML 推理，A1 单向节点演化）：输入特征经 DAC 写入输入节点电压 → 权重写入耦合电导 → 输入节点锁定、输出节点自由 → 电流经电导流入输出节点电容、电压按梯度连续演化（如 100ns）→ 平衡时输出节点电压即计算结果 → ADC 读回。训练则反过来：输出节点钳真值、耦合电导在 I_loss 反馈下演化。

实现：遵循 BRIM 约定（HPCA'21）——节点状态=电容上的电压，耦合参数=可编程电导，selector 逻辑按列激活 + 编程总线广播；扩展工作有 DS-GL（图学习，ISCA'24）、DS-TPU（片上终身学习 + Chebyshev 非线性节点交互，ISCA'25）、DS-TIDE（时不变微分方程求解，MICRO'25）、DS-LLM（LLM 训练/推断映射到 DS 能量函数，ICLR'24）、InstaTrain（ICLR'25）。使用方式：算法变量映射到节点、交互强度编码进耦合矩阵（行 i 列 j = 节点 i→j 的耦合），计算 = 配置边界条件 + 触发同步集体演化 + 读回平衡态；支持分区并行多任务、级联多层（A2 模式）、部分耦合演化做微调（C2 模式）。本论文的贡献即给出其上首个标准 ISA（DS-ISA）与数字控制微架构。
