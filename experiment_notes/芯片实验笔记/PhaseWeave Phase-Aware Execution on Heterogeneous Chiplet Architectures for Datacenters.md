## PhaseWeave Phase-Aware Execution on Heterogeneous Chiplet Architectures for Datacenters

- 属于芯片设计的实现是什么？实验比较什么？
  - 实现：chiplet-based 异构服务器物理架构（芯片级结构优化）。服务器集成四类异构 chiplet（high-compute / fast-memory / near-network / low-power），chiplet 内核心以 2D mesh 组织，chiplet 间 high-bandwidth all-to-all 互联；所有 chiplet 共享同 x86 ISA（iso-ISA），仅微架构配置按 phase 类别调优（高频率+宽发射+大 ROB/LSQ+SIMD 的 compute；窄流水+低频率+更多高带宽内存通道/stacked DRAM 的 fast-memory；die 内集成 NIC 减 PCIe 开销的 near-network；低频率+小私有缓存+慢速低功耗 DRAM、无 NIC/向量单元的 low-power）。内存子系统：统一物理地址空间、单一 OS 实例，但物理异构——每个 chiplet 挂专属 DRAM 分区（memory channel/DIMM 粒度，延迟与带宽按 phase 需求选择），新分配内存落在执行请求的 chiplet 本地分区，热页按 NUMA 式页迁移策略（周期性访问计数、提升热页）跟随主导 chiplet；两级 MESI 缓存一致性（每缓存行有 global home core/LLC slice + 每 chiplet 内 local home，intra-chiplet directory + inter-chiplet directory，invalidation 经 global home→远端 local home→core 传播）。实验比较：Baseline 28 核同构单晶片 EMR（iso-area）vs PhaseWeave 异构 chiplet（99% 面积、82% 功耗）；对照 big.LITTLE 类单片异构（bigL / bigL-OoO / bigL-Opt，核比 1:1/1:2/1:4，iso-area 且功耗略高）；扫不同 chiplet 配比配置（Table IV：Compute-Opt 16/8/8/6、Memory-Opt、Network-Opt、LowPower-Opt、Memory+Network-Opt 6/13/13/6、Compute+Memory-Opt 6/8/8/16 等）的面积/功耗/吞吐/Perf-Watt。
  - 结果：per-core 面积降 27%/11%/34%/39%、功耗降 34%/33%/35%/56%（compute/fast-mem/near-net/low-power），面积是核数扩展的主约束 → iso-area 下容纳 38 核 vs baseline 28 核；整体 Perf/Watt 1.92×；优于最优 big.LITTLE（bigL-Opt-1:4）1.3× 吞吐；配置扫描中 PhaseWeave 默认配比（10/9/9/10）Perf-Watt 平衡最佳（850 QPS、0.98 面积、0.82 功耗、1.89 Perf/Watt vs Memory+Network-Opt 900 QPS/1.01 面积/0.85 功耗/1.93 Perf/Watt）。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 与硬件架构层共用：QEMU（https://www.qemu.org/）+ SST Ariel core（https://sst-simulator.org/，modified for high-accuracy）+ DRAMSim3（https://github.com/UMD-MEMS/DRAMsim3）+ McPAT（https://github.com/HewlettPackard/mcpat，32nm 缩放至 7nm）。PhaseWeave 修改版未开源（论文未给链接，联网检索无公开仓库，截至 2026-08）；公开材料为微软研究院 PDF（https://www.microsoft.com/en-us/research/wp-content/uploads/2026/04/phaseweave.pdf）。
- 模拟器模拟什么的性能，修改了什么。
  - 模拟异构 chiplet 拓扑与物理特性：chiplet 内 2D mesh（3 cycles/hop）、chiplet 间 all-to-all（60 cycles 延迟、1Gbps/link）；异构内存子系统（每 chiplet 专属 DRAM 分区，Mem Lat 15/22/15/15 cycles、Mem BW 17.06/25.60/17.06/17.06 GB/s，见表 III）；两级 MESI 目录一致性（global home 经 inter-chiplet directory 转发 invalidation 到远端 chiplets 的 local homes 再广播给本地 core）；NUMA 式页迁移。修改：SST 加入多 chiplet 拓扑、跨 chiplet 目录一致性、异构内存控制器参数；DRAMSim3 建模各 chiplet 专属 DRAM 分区；McPAT 按 Table III 逐核配置估面积/功耗并缩放至 7nm，按 iso-area 约束缩放各 chiplet 核数。
- 开源情况。基于开源文档和论文，使用例子解释模拟器如何使用？作用是什么？
  - 开源：PhaseWeave 未开源；底层工具（QEMU、SST、DRAMSim3、McPAT）均开源。模拟器使用例子（chiplet 物理层输入到性能输出全过程）：输入 = 各 chiplet 类型/核数/微架构参数（Table III）+ 拓扑参数（2D mesh 每跳 3 cycles、跨 chiplet 60 cycles、1Gbps/link）+ 每 chiplet 内存分区参数（带宽/延迟）+ 负载请求流 → SST 为每个 chiplet 建模核流水线、缓存层次、内存控制器与芯片间链路 → 缓存行分配 global home（core+LLC slice）与 chiplet 内 local home，写失效沿 intra-chiplet 目录（本地 core）+ inter-chiplet 目录（远端 local home）两级传播保证一致性 → 页分配落在执行请求的 chiplet 本地 DRAM 分区，热页经 NUMA 式访问计数迁移到主导 chiplet 分区 → McPAT 对各类型核面积/功耗求和并按 iso-area 调整核数 → 输出各 chiplet 配置的面积/功耗/吞吐/Perf-Watt（Table IV），量化 chiplet 异构相对同构单晶片的收益（-65% P99、1.56× 吞吐、1.92× Perf/Watt）。
