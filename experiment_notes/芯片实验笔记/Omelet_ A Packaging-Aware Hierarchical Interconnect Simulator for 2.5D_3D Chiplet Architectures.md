## Omelet: A Packaging-Aware Hierarchical Interconnect Simulator for 2.5D/3D Chiplet Architectures

- 属于芯片设计的实现是什么？实验比较什么？
  - 属于芯片设计：chiplet 2.5D/3D 先进封装的物理-架构联合设计空间探索（封装感知模拟器，Georgia Tech，ISCA 2026）。Omelet 把 die-to-die 链路建模为物理组件链（I/O driver → RDL/interposer 走线 → TSV/µvia → bonding 界面）而非单一抽象链路：(1) 组件级 RC 寄生提取——Ansys HFSS 3D 电磁仿真，0.1–7GHz 数字工作范围，按 pitch 重复提取（保持 realistic aspect ratio 与 design rules），bonding tier/via 单信号线+双相邻地、wiring 层单信号线+双同面地+上下地平面，结果编入按 interconnect type/material/pitch/frequency 索引的技术表；(2) 覆盖的封装技术范围（Table II）：2.5D（silicon / organic interposer、silicon bridge 变体——在 2.5D 链中插入被有机材料包围的 µvia 模拟下沉到嵌入式 bridge）、3D（F2F/F2B 堆叠，区别在于 TSV 在 bonding 界面前/后穿过 die）、bonding tiers（solder balls / µbump / Cu-Cu TCB / hybrid bonding，I/O pitch 约 1–50µm）、RDL 材料（Cu/oxide、Cu/polyimide）、vias（TSV、µvia）；RDL 尺寸覆盖 TSMC CoWoS-S 5th Gen（0.8µm L/S，2021）到 CoWoS-L/R（2.0µm L/S，NVIDIA Blackwell B200 2024-2025），前向 0.5/1.4µm；bonding 覆盖 solder/µbump(>30µm) 到 <10µm Cu-Cu hybrid bonding（Intel Foveros Direct 3D / Panther Lake）; (3) 物理约束检查：placement feasibility（TSV 密度 per mm²、interposer 最大 span 如 silicon 不可 span 20mm）、beach-front 共享周长限制每 die 对可布链路数、垂直堆叠重叠区限制 TSV/hybrid bond 数量，约束传入 link modeler 调整带宽与 router 尺寸；(4) 45nm FreePDK45 I/O driver/ESD 电路模型（1V super-buffer，最小 inverter 电扇出，NMOS/PMOS W=50/97nm、L=50nm）；(5) Elmore delay 模型 + SPICE 链式仿真 → latency、BW_link=6/τ、EPB（I×V 积分 over 1 clock cycle）；(6) 新封装技术扩展方式：在 per-link 参数表加条目 + 配置文件引用，即可把被动 2.5D interposer 扩展为 silicon-bridge 或 3D 垂直路径。
  - 实验比较什么：①interposer 材料（silicon 0.5µm L/S vs organic 2µm L/S）× 7 拓扑：硅零负载延迟更高（intrinsic link delay 大）但高布线密度带来更高链路并行度 → 高注入率 shuffle 下硅反而低于有机（Fig.9，平均差 40.9K cycles）；能量：intrinsic EPB（硅单链路更高，lossy 电学特性）vs traffic-activated energy（拓扑-流量驱动激活不同）——mesh 激活大量短链路致总能耗高、Kite 家族少而长的路径总能耗低（Takeaway 3）；②bonding 技术 4 档（30/10/5/1µm pitch，Fig.11）：更高密度 bonding → 更宽 NoI 链路与 router datapath，但增大与 NoC 注入宽度失配 → 低负载下固定打包/适配开销占主导（零负载延迟反而更高），深饱和下由拥塞边界端口 service rate 决定（Takeaway 4）；③3D stacking（2/3 层，Fig.12）：垂直链路快但跨 stack 流量仍共享 interposer → interposer 成全局吞吐限制器（Takeaway 5）；④DSE（Fig.13）：7 拓扑 × 2.5D/3D × 硅/有机的 Pareto 分析——硅下 mesh 优（高密度短路径多），有机下 DoubleButterfly/Kite 优（少 hop 高 reach 直连），拓扑最优性随封装技术改变；⑤保真度验证（Section VIII）：有机 RDL 复现 TSMC CoWoS RC scaling（平均差 3.5%、最大 5.7% @7mm 2µm L/S）；Jangam et al. SuperCHIPS 两条硅互连——100µm/2µm pitch：54.36ps(-2.49%)、0.287 pJ/bit(-4.33%)；500µm/10µm pitch：60.07ps(+2.16%)、0.35 pJ/bit(+11.75%)；灵敏度分析（±20% latency 扰动下拓扑排序稳定、DoubleButterfly 瓶颈归因不变、394 设计点 Pareto 前沿近均匀平移）。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 物理级：Ansys HFSS（3D 电磁仿真，RC 寄生提取）+ SPICE（链路延迟/带宽/能量评估）；架构级：gem5 Garnet NoC（Omelet 集成修改，https://github.com/gem5/gem5）；Omelet 本体：https://github.com/sharc-lab/Omelet（论文脚注 1；联网确认 SHARC Lab/Georgia Tech 背景及其 "Agile Hardware Kitchen" 工具套件存在）。FreePDK45：https://eda.ncsu.edu/freepdk/freepdk45/（I/O driver/ESD 45nm 工艺）。HFSS/SPICE 为商业 EDA 工具，无公开链接。
- 模拟器模拟什么的性能，修改了什么。
  - HFSS 模拟 RDL/interposer 走线、vias、bonding tier 参数化 3D 结构的 RC 寄生（单信号+双地 GSG、上下地平面），0.1–7GHz、按 pitch 重复提取 → 技术表。SPICE 把各物理元件级联为完整链路（查表：长度相关条目作分布式元素缩放、lumped 元素固定），super-buffer 驱动（VDD=1V，最小 inverter 电扇出确定级数与 sizing，equal rise/fall <1ps）→ latency（rise/fall 平均、VDD/2）、BW_link=6·τ、EPB（I×V 积分 1 周期）。gem5 Garnet 执行架构级 flit-level cycle-level 仿真（详见硬件架构层条目）。修改了什么：Omelet 把封装物理参数（bonding pitch、interposer 材料与 L/S、TSV/µVia 几何、RDL 材料、线长）通过技术表映射为每链路 ⟨W, t_cyc, E_bit⟩，并在 NoX 引擎实现放置感知链路构建、物理约束（beach-front 共享周长、垂直重叠区、interposer span、TSV 密度、keepout zone）参与链路/带宽核算、边界 adapter（PHY/SerDes/CDC）插入。
- 开源情况。基于开源文档和论文，使用例子解释模拟器如何使用？作用是什么？
  - 开源：Omelet GitHub https://github.com/sharc-lab/Omelet（with documentation and examples）；gem5/FreePDK45 开源；HFSS/SPICE 商业工具。使用例子（一次封装技术配置→系统性能输出的芯片级数据路径）：配置 CoWoS 风格系统——4 chiplet × 16 core 置于 silicon interposer（0.5µm L/S RDL、hybrid bond 1µm pitch、TSV AR=15）、3GHz 时钟、mesh NoI、shuffle 流量 → Omelet 查技术表得每链路 lane 数 λ=可用 bonding perimeter/bump pitch、数据率 R_lane(ℓ)（按长度 ℓ 的 RC 衰减）、计算 W=floor(λ·R_lane(ℓ)/(f_clk·F_bits)) flits/cycle 与 t_cyc → Placement Engine 检查 interposer span/TSV 密度/beach-front 可行性并输出逻辑+物理坐标 place map → NoX 构建三层网络、边界插入 PHY/SerDes/CDC adapter → 周期级仿真输出 load-latency、饱和点、per-link EPB/traffic-activated energy、瓶颈归因；DSE 模式可同时扫描 topology×placement×packaging 得 Pareto 最优集。作用：让架构师无需手工调 latency/bandwidth 常数即可评估具体封装技术（interposer 材料、bonding 类型/间距、TSV 几何）对系统级延迟/拥塞/能耗的影响，支撑 architecture–packaging co-design 与新兴封装技术的前瞻性探索。
