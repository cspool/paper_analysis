## PuDGhost: Experimental Analysis of Computation Result Corruption in Processing-using-DRAM Operations on Real DRAM Chips and Implications for Future Systems

- 属于芯片设计的实现是什么？实验比较什么？
  - 实现是 DRAM 芯片阵列/结构层面的 PuD 可靠性研究：首次在真实 DDR4 芯片上刻画 PuDGhost 干扰现象——PuD/SiMRA 计算列的输出被 (1) 未激活的相邻行数据 与 (2) 同一 SiMRA 操作下并发执行计算的其他列数据所干扰，并提出芯片/阵列级缓解：(a) compute row layout（隔离行布局）：在 compute rows 之间放置固定数据模式的 isolation rows（初始化一次、正常刷新），保证 compute rows 的相邻行数据在 PuD 执行期间固定不变；按 Ambit 的 6 条 compute rows 需 7 条 isolation rows，1024-row subarray 仅 +0.68% 行数开销、无额外延迟；(b) 细胞阵列级修改方向（仅讨论、未实现）：isolation transistors（compute 与 storage rows 间插入隔离晶体管）、staged activation（按小组顺序激活、仅最后一批后传感，减小同时激活行数）、reference voltage adjustment（按 PuDGhost 偏置方向运行时调节 precharge/参考电压）。实验比较：96 颗真实 DDR4 芯片（12 模块：TimeTec 3 模块/24 颗 4Gb die A、TeamGroup 7 模块/56 颗 4Gb die M、SK Hynix 2 模块/16 颗 8Gb die A，全部 SK Hynix x8）在六种条件（Base/S-all/S-tar/S-adj/R-adj/R-far）下刻画相邻行干扰（Norm. p_o1 偏置最高 10%，Obsv. 1-3），并在默认 setup 下刻画并发计算列干扰（最高 48%，Obsv. 10-12）；共 15 条新观察；评估 6 个 column screening 配置（Base/CS-1-01/CS-1-sweep/CS-2-0/CS-2-1/CS-2-check）的 CPR/CBR/BER 与 GEMV NMSE、TRNG 熵。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 非模拟器，而是真实芯片 + FPGA 测试基础设施：DRAM Bender（FPGA 版 DDR4 测试基础设施，https://github.com/CMU-SAFARI/DRAM-Bender，TCAD'23，基于 SoftMC https://github.com/CMU-SAFARI/softmc），FPGA 板为 Xilinx Alveo U200（https://www.amd.com/en/products/accelerators/alveo/u200/a-u200-a64g-pq-g.html）；主机生成测试程序并收集结果，热电偶温度传感器 + 加热垫 + 温度控制器维持目标温度（默认 50°C，最高 80°C）。PuDGhost 自身无专门开源仓库（arXiv:2606.19119，联网检索截至 2026-08 未发现 GitHub 仓库）。
- 模拟器模拟什么的性能，修改了什么。
  - DRAM Bender 提供对 DDR4 命令的精细控制：通过 ACT-PRE-ACT（APA）命令序列（间隔 ≤3ns）在 COTS 芯片上执行 2/4/8/16/32 行同时激活（SiMRA）；执行"写模式→SiMRA→读出"流程刻画输出。为 PuD 实验做了芯片逆向：逻辑-物理行映射（RowHammer bitflip 模式）、subarray 边界识别（RowCopy 跨行对尝试）、true/anti cell 与 even/odd 列识别（open-bitline 布局）、SiMRA 激活行数验证（APA+WRITE+PRE 后读回、把 WRITE 后到 PRE 的延迟延长到 tWR 以上）。修改/新增：基于 DRAM Bender 的 PuD 测试程序（沿袭 PULSAR/FC-DRAM 方法论），非芯片 RTL 或模拟器修改。
- 开源情况。基于开源文档和论文，使用例子解释模拟器如何使用？作用是什么？
  - 开源：DRAM Bender（https://github.com/CMU-SAFARI/DRAM-Bender）、SoftMC（https://github.com/CMU-SAFARI/softmc）、PiDRAM（https://github.com/CMU-SAFARI/PiDRAM）均开源；PuDGhost 实验代码未开源（无法确认）。使用例子（实验输入到性能输出全过程）：用 DRAM Bender 编写/调用测试程序——①初始化目标 subarray 的相邻行（controlled rows）为指定模式（全 0/全 1/随机 p_c∈{0,0.25,0.5,0.75,1}）；②对 SiMRA rows 写入随机输入（128 样本）；③发 APA 序列（ACT-PRE-ACT，3ns 间隔）同时激活 2–32 行执行 SiMRA；④读回 SiMRA rows 记录输出 → 对每列计算 p_o1（输出为逻辑-1 的占比）与 Norm. p_o1（相对基线 p_c=0.5 的比值，>1 偏逻辑-1、<1 偏逻辑-0）量化干扰。作用：在真实芯片上精确验证 PuDGhost（相邻行最高 ±10%、并发列最高 ±48%、并发列干扰与行数正相关且非单调），为芯片结构级缓解（isolation-row 布局、isolation transistors、staged activation、参考电压调节）提供实证基础。
