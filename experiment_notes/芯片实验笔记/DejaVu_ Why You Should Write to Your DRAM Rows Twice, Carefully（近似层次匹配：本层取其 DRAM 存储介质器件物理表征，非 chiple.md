## DejaVu: Why You Should Write to Your DRAM Rows Twice, Carefully（近似层次匹配：本层取其 DRAM 存储介质器件物理表征，非 chiplet/堆叠结构优化）

- 属于芯片设计的实现是什么？实验比较什么？
  - 实现：在 DRAM 存储介质/器件物理层面，用 FPGA 驱动的测试基础设施 DRAM Bender 对 112 颗 COTS DDR4 DRAM 芯片（14 条 DIMM，S/H/M 三大厂商，8/16 Gb、A–F 多个 die revision、x8 组织）做"写入历史影响器件行为（DejaVu）"的精细表征：三种 victim row 初始化方式（Baseline=只写一次 / OverWrite=先写反码再覆写目标数据 / SameWrite=相同数据写两次，见 Listing 1 伪代码）下测量读干扰（read disturbance）与保持性（retention）指标，并用 PUD（Processing-Using-DRAM）MAJ-3 操作表征写历史对存取晶体管电流导通能力的影响；温度控制 50/80/95 °C（heater pads + 温控器），反向工程行地址映射与 true-/anti-cell 布局。
  - 实验比较：① 双面 RowHammer ACmin（50/80 °C、victim 数据 0x00/0xFF/0xAA/0x55、每模块 128 行 × 50 次重复、共 1792 行）：OverWrite 平均降 ACmin 2.8%–3.5%（最大 28.1%），SameWrite 平均升 3.0%–3.6%（最大 46.1%）；② 双面 RowPress ACmin（80 °C、附加 tAggON）：DejaVu 可诱导 baseline 诱导不出的 bitflip；③ retention failure bitflip（95 °C、停刷新 4 s）：OverWrite 比 SameWrite 平均多 10.4%（最高 36.7%，0xAA/0x55 下最高 123.2%）bitflip；④ 附加写恢复时间（write recovery time）敏感性：OverWrite 第二次写需 >400× JEDEC 标准 tWR（>6100ns）才接近 SameWrite 的 ACmin，SameWrite 基本不变；⑤ 首 bitflip 的 cache line 空间分布；⑥ PUD 可靠性（16/32 行激活 MAJ-3、随机数据、1K 次重复、bitline failure rate 指标）：OverWrite 降 bitline failure 10.7%（16 行）/32.7%（32 行），SameWrite 降 5.8%/30.6%；⑦ 系统级（Ramulator 2.0，见硬件架构层条目）：PARA/PRAC 的 NRH 阈值 ±20% 扫描对性能的影响（NRH=64 时 −20% 使 PARA 平均性能开销 6.3%）。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 本层无仿真器——直接对真实 DRAM 芯片做表征：测试平台为 DRAM Bender（FPGA-based DRAM testing infrastructure，开源 https://github.com/CMU-SAFARI/DRAM-Bender，论文 ref [88][89]），运行于 Xilinx Alveo U200 FPGA 板（1.5ns 粒度精确控制 DRAM 命令与时序，可禁用 rank ECC 直接观察电路级 bitflip），配套温控器 + heater pads；系统级性能部分用 Ramulator 2.0（https://github.com/CMU-SAFARI/ramulator2）。
- 模拟器模拟什么的性能，修改了什么。
  - DRAM Bender 按测试程序在 FPGA 上直接向被测 DDR4 DIMM 发 ACT/WR/PRE 命令序列（write_row = ACT → 128 个 WR 覆盖整行 128 个 cache line → PRE），精确控制 tRCD/tCCD_L/tWR/tRP 与温度；DejaVu 专有修改：victim row 初始化插入 OverWrite/SameWrite 双写序列、第二次写后插入附加写恢复等待扫描（0→6100ns）；测量 ACmin（二分法迭代、收敛条件 <10、每轮严格 <64ms 避免 retention 干扰、测试期间不发 auto-refresh）、retention failure bitflip 数（95 °C 停刷 4s）与 MAJ-3 bitline failure rate（RowClone 反推 subarray 边界、ACT-PRE-ACT 违规时序反推同激活行、Frac 操作处理余数行）。输出：ACmin 分布/归一化比值、bitflip 数、bitline failure rate。

  - 开源：artifact 公开（Zenodo DOI 10.5281/zenodo.19444878，MIT license，约 50GB，预计准备 1 天 + 完整实验 20 天）；DRAM Bender 开源（链接如上）；仿真用 Docker 镜像 richardluo831/ramulator2（Dockerhub）。真实芯片表征脚本：解压 artifact → cd dejavu_ae → run_rd_characterization.sh（读干扰 + retention 表征）→ 跑 dejavu_rd_plots.ipynb 出图（Fig.1、6–11、13–21）；cd dejavu_pud → run_pud_reliability.sh（PUD 可靠性表征）→ analysis/plot_pud.ipynb 出 Fig.22。注意：温控器/heater 控制代码因内部基础设施专有未公开，脚本中留注释说明接入方式。
  - 使用例子（一次双面 RowHammer ACmin 测量的芯片级数据路径）：FPGA 按 Listing 1 初始化 victim 行（OverWrite：write_row(R, ~victim_data) → write_row(R, victim_data)）与两 aggressor 行（写反码）→ 交替 ACT/PRE hammer 双 aggressor（tAggON=36ns 即 RowHammer）→ 读 victim 行比对 bitflip → 二分法调激活次数直至收敛 → 输出该行 ACmin（50 次重复取分布）。作用：发现并量化"写历史改变器件读干扰/保持性/PUD 可靠性"的 DejaVu 现象，为 DRAM 测试方法学（测最坏 ACmin 用 OverWrite 初始化、数据模式实验用 SameWrite 防污染）与缓解方案阈值 guardband 提供依据。
