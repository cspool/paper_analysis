## ConBin: A Performance-Convergence Framework for Wafer-Scale Chip Binning

- 属于芯片设计的实现是什么？实验比较什么？
  - 实现为晶圆级芯片（WSC）的制造缺陷容错与分 bin 结构优化：多个 reticle 级 die 经 stitching 拼成 2D mesh WSC（die 间跨 scribe line 直连、与 die 内同延迟，核心 = PE + router）：(1) 自动化故障相关感知冗余互连设计——在 R_max=6（每 router 冗余链预算）与 L_max=min(4,6)=4 跳（链路 >50mm 显著增大误码率、保守限 25mm 等效线长；工艺布线支持 ≤6 跳 [7]，Stapper 缺陷空间相关 ~4 跳 [49]）约束下，枚举 δx²+δy²≤L_max² 的候选 R-R / P-R 冗余链，以精英保留遗传算法（EGA，种群 50，10 代无改进终止）最大化 F=λ·D̃+(1-λ)·R̃（λ=0.9，D̃/R̃ 取 bottom α=0.3 的 lower-tail 均值，防止最弱芯片掉队）；收敛结构：每 router 2 条 P-R 冗余链（一近一远）+ 2 短程 + 2 长程 R-R 链；(2) 制造后修复——core 配置（healthy PE 沿 P-R 链 BFS 最短 replacement chain 重绑定到健康 router、链止于 PE-only 故障 core）+ 互连配置（每端口优先原 mesh 链，否则选最短冗余链）近似恢复 mesh 拓扑，路由用 turn-prohibition [50] 最短路径保证无环全局连通；(3) Performance Binning 范式 + 动态规划分 bin——按目标负载实测性能（平均 latency）而非核数/频率分级，DP[b][i]=max_{j<i}{DP[b-1][j]+τ_{j+1}·(i-j)}（N=100 百分位离散）求最大化总可售有效算力 SECC=Σ P_k·Y_k 的最优阈值。实验比较：Cerebras 专利 [39] 冗余架构 + 本文修复（CB*）、CB*+Si-Kintsugi（SK）、CB*+CUPOKer（NFT）及组合 CB*+SK*/CB*+Ours-SW/Ours-WM/Ours-ALL；结果：mesh 相似度 F_norm 四种故障模式下 >88% vs Cerebras <46%（2.4×/2.0×/2.8×/2.2×）；premium-bin（前 1/3）yield 2.80×、阈值收紧 2.09×、总 SECC 2.64×（128×136、8 bins，vs CB*+SK*），Ours-ALL 最高 3.85× SECC。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 自研系统级仿真，集成 ScaleSim（https://github.com/ARM-software/SCALE-Sim，Tab.III：32×32 阵列、8MB SRAM、Output Stationary，核级周期模拟）与 BookSim 2.0（https://github.com/booksim/booksim2，8 VC、buffer 8、flit 32b、packet 16 flits、router 4 级流水、每 mesh hop 1 cycle，周期精确 NoC 模拟）；面积用 McPAT [36] 估计（冗余互连面积开销 <8%@128×136）。
- 模拟器模拟什么的性能，修改了什么。
  - 模拟默认 128×136 核 WSC 上 LLM/线性代数负载的端到端执行 latency：ScaleSim 按 Output Stationary 数据流模拟核内计算周期，BookSim 模拟故障修复后非规则拓扑上的 NoC 通信（跨 die 边界直连同延迟、冗余 R-R 链延迟按跨越 hop 数成比例）；修改：向 BookSim 拓扑注入故障核/链、多跳冗余互连与 turn-prohibition 路由，向 ScaleSim 输入经映射后的负载；输入 = 故障图 + 冗余设计 + workload 映射，输出 = 每 chip 执行 latency → 归一化 slowdown/speedup、性能分布方差、bin yield 与 SECC。

  - 开源情况：ConBIN 代码论文未明确说明开源（原文无链接，联网搜索未发现官方仓库，无法确认）；所用开源件 ScaleSim、BookSim（链接如上）、Geatpy（https://github.com/geatpy-dev/geatpy，实现 EGA/SEGA/NSGA-III）、McPAT。使用例子：按 Sec.V-E 生成故障图（Gaussian 簇 + 随机噪声 [48]，Local/Scratch/Edge-Local/Donut 模式、故障率 0.05–0.4、相关距离 4 跳，每规模 128 实例）→ 跑 EGA 冗余设计（适应度 F）→ 对每故障实例跑 core/互连修复得修复拓扑 → ScaleSim+BookSim 联合仿真 GPT/LLaMA/GEMM 负载执行 latency → 汇总 512 实例性能分布 → DP 分 bin 得阈值与 SECC。作用：无真实 WSC 硬件条件下，量化"冗余设计 + 修复 + bin 感知调度 + 分 bin"全流程对 premium-bin yield 与总 SECC 的影响。
