## WaferBRAIN: Whole-Brain Scale Neuromorphic Architecture Based on Wafer-Scale Integration

- 属于芯片设计的实现是什么？实验比较什么？
  - 实现是 WaferBRAIN 的 3D-WSI 晶圆级芯片物理架构（ISCA 2026，澳门大学 + 广东省智能科学与技术研究院）：
    - **晶圆架构**：215mm×215mm 晶圆集成 6×8=48 个计算 die（2D mesh 拓扑），每个 die 垂直键合（hybrid bonding）专用 3D-stacked DRAM die（40GB/die，共 ~1.92TB/wafer，支撑 1B 神经元/256B 突触）。mesh 因仅最近邻连接、简化互连模式、兼容封装集成与信号完整性而入选；3D-WSI 提供低时延 D2D（~1ns 级、>1Tbps）与高效 compute-to-memory 传输，缓解大 mesh 的时延惩罚。
    - **芯粒（chiplet）架构**：每 die 面积 23mm×32mm，集成 4×4=16 个 BPU 节点；D2D 接口支持芯粒级 scale-out；3D-stacked DRAM 提供高容量突触存储；BPU 节点含轻量 NoC 路由器（unicast+broadcast）与 axon-in/dendrite/soma/axon-out 四模块。
    - **封装（Package View）**：compute die 与 stacked DRAM die 集成在硅中介层（3D-WSI/CoWoS 风格 [14]）；DRAM die 经 through-silicon vias（TSV）连接到底层 redistribution layer（RDL），RDL 提供 fine-pitch 信号/供电路由并重分配到 package substrate，substrate 键合 PCB。消除多芯片系统中的长 PCB 走线，降低互连时延、提升 D2D 带宽与信号完整性。
    - **存储组织**：热状态（膜电位、refractory、事件队列）在片上 SRAM；突触/连接元数据在 3D-DRAM，以 compact pointer/length 头 + 连续邻接表的双布局（本地 neuron-driven / 全局 axon-driven）支撑 coalesced DMA 与紧凑 ID（LNid 27bit + GAid 33bit）。
    - **Scale-out 互连（switchless dragonfly）**：三通道层次——die 级 node channel（NC）、由晶圆周边相邻边界 die 对聚合 8 个 NC 成的 wafer channel（WC）、WaferPOD 间用的 POD channel（PC）；每 wafer 提供 14 个双向 WC（索引 0-13）作为 scale-out 接口；一个 WaferPOD 用 WC 全互连 14 个 wafer（WC_j(i)↔WC_i(j)，任意两 wafer 1 hop，每 wafer 用 13 个 WC、对角 WC_i(i) 留作外向接口）；7 个 WaferPOD 用成对外向 WC 形成 PC（PC_i(k) 由 WC_i(i)+WC_i+7(i+7) 键合而成）互连成 14×7=98-wafer cluster，端到端距离 POD 内 1 hop、跨 cluster 3 hops（vs 10×10 mesh 的 18 hops）。无交换机，晶圆边界 die 直连充当通信通道（承袭前作 [9] "Switch-Less Dragonfly on Wafers" SC24）。
    - **Unicast 确定性路由**：5 阶段——① 源节点沿预规划 on-wafer 确定性路由上升到所选 egress WC；② 跨 POD 选路（目标 POD M → 本 POD 的 PC_M(A)，bonded WC 对 (WC_M(M), WC_M+7(M+7))，wafer 0-6 用 WC_M(M)、7-13 用 WC_M+7(M+7) 平衡负载）；③ 跨 POD hop（PC_M(A)→PC_A(M)）；④ POD 内跨 wafer hop（经目标 wafer 的 K-th WC）；⑤ 目标 wafer 内 mesh-XY 递送。WC 选定后按 WC-to-NC sharding 把注入节点划分为 8 个 disjoint shard、每 shard 绑定一个 NC，预规划路径写入 router-local SRAM 的 WC 索引确定性路由表（离线生成）。
    - **原型 Lyra X**：UMC 40nm、12 英寸晶圆 228×211mm、11×16 mesh die（~1mm bump pitch）、SRAM-only 存储支持 202M 神经元/2B 突触、全晶圆执行；实测 intra-die 1ns、inter-die 8ns、inter-wafer 493ns 跳时延（Table I）。
  - 实验比较：集成维度——WSI vs PCB 级集成（PCB 按 Loihi：D2D 100ns、router 100Gbps）在 mesh 与 dragonfly 两种拓扑下对比每步时延与可持续 firing rate；拓扑维度——switchless dragonfly vs 2D mesh 的 inter-wafer 流量均衡与峰值节点负载（均用 NAHP 作一致 baseline）。结果：WSI 比 PCB 可持续 firing rate 高 13×（PCB 因板级传播时延与带宽限制连 0.5% firing rate 都撑不住）；dragonfly 比 mesh 峰值 inter-wafer 流量降 3.4–3.7×、峰值节点负载降 1.3–2.8×；100B 下 WSI+dragonfly 可持续 3.8% firing rate vs WSI+mesh 1.3%（2.9× 提升）。

  - 开源情况：WaferBRAIN 未开源（论文无链接、联网搜索 2026-08 未找到仓库，无法确认）；Lyra X/LYRA·X 为珠海天琴芯智能科技（广东省智能科学与技术研究院）的商业芯片（2023-12 发布、>200mm×200mm、2 亿神经元、LYRArc 架构/BPU 核、液冷 PUE<1.1，百度百科 https://baike.baidu.com/item/LYRA%20eXtreme%EF%BC%88%E5%A4%A9%E7%90%B4%E8%8A%AF%E6%B5%B7%EF%BC%89），无公开 RTL/模拟器。相关前作 [9] switchless dragonfly（SC24）有 IEEE 页面 https://ieeexplore.ieee.org/document/10793167；CoWoS [14]、HBM [19] 为工业封装/内存技术。
  - 使用例子（一次跨 wafer spike 的芯片级数据路径）：神经元在 wafer A 源 BPU 放电 → 源节点发 mode=0 区域广播（LNid）→ 区域路由表（even/odd 源列/行扩展）送达区域内全部节点 → 边界 owner（Algorithm 1 按到锚点曼哈顿距离选出）查 axon-out 元数据得 <DstNode, GAid> → 发 mode=1 单播：egress-WC 选择（跨 POD 走 PC_M、同 POD 走 K-th WC）→ 查 WC 索引确定性路由表沿预规划路径到 egress WC（WC-to-NC sharding 绑定 8 个 NC 之一）→ 经边界 die 对的 WC 离开 wafer → dragonfly 通道（同 POD 1 hop / 跨 POD 3 hops，wafer 0-6 vs 7-13 平衡负载）→ 目标 wafer 上 mesh-XY 到 DstNode → 接收端按 GAid 索引 3D-DRAM 全局突触邻接块（coalesced DMA 取 <DstNeuron, Weight> 列表）→ dendrite FIFO 累加 → soma 更新膜电位。作用：在真实多晶圆系统不可得时，用 Lyra X 实测跳时延标定的分析模型量化 3D-WSI + switchless dragonfly 相对 PCB/mesh 的流量均衡与时延优势，指导 12 英寸 wafer 上 1B 神经元、98-wafer cluster 上 100B 神经元系统的可制造配置。
