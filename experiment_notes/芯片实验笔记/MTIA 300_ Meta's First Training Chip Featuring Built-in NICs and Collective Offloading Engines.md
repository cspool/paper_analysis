## MTIA 300: Meta's First Training Chip Featuring Built-in NICs and Collective Offloading Engines

- 属于芯片设计的实现是什么？实验比较什么？
  - 属于芯片设计的实现：MTIA 300 的 chiplet/物理封装级设计（真实流片，ISCA 2026）。(1) **chiplet 架构**——单 reticle 尺寸 compute die（25.6×31.4 mm）+ 2 个网络 chiplet（25.6×9.3 mm，各集成 6 个定制 800 Gbps RDMA NIC IP），2.5D CoWoS 封装（50.3×51.9 mm 3.2× interposer、77.5×77.5 mm 封装），die-to-die 接口 + 112G SerDes 实现高带宽密度（每网络 chiplet 600 GB/s）；(2) **HBM3E 存储组织**——东西侧各 3 个十二高 HBM3E stack（共 6 stack、216 GB、6.1 TB/s），SRAM bank（LLC/LLS 共 192 MB）贴近 PE 网格；(3) **良率冗余**——reticle 受限 die 上 PE 冗余行：每 PE 列容忍 1 个坏 PE（boot 时配置、软件透明、不影响 NoC 性能）；因 PE 占最大面积与分布式内存、且存储东西向组织 + NoC 路由路径，加冗余行是最简方案；(4) **热/功耗设计**——TDP 912W（典型 667W）、液冷（对比 MTIA-2i 85W 风冷，compute/network blade 均液冷）；(5) **网络 chiplet 的 NIC 定制优化**——express doorbells（WR 本身即 doorbell 写，省 800 ns HBM ring-buffer 读，每 IP 24576 outstanding WR / 1024 QP）、移除 QP caching（省面积，限制每 NIC 1100 active QP，远超实际需求）、简化包处理流水线（去掉 virtual switching/TC offload 等）、AXI steering tag（不同流量类型走 compute chiplet 独立 cache partition）；(6) **机架系统设计**——compute blade（单 CPU 512 GB RAM + 单 MTIA 300，1:1 映射避免 PCIe 争用、容纳不可预测 CPU 需求）与 network blade（scale-up blade 用低延迟低功耗 ASIC、可多 rack 组合成更大域；scale-out blade 支持 disaggregated scheduled fabric：packet spray 避免 hot link + 保序投递 + fabric 级端到端 credit 可靠性）分离，chassis 16 compute + 6 network 槽位、cable backplane（compute blade 垂直放置缩小背板），200 GB/s I/O per compute blade。
  - 实验比较什么：芯片设计层主要是规格/架构对比而非仿真：(a) 与自家 MTIA-2i（推理芯片）对比（Table I）——≈3× 面积、≈10× TDP、HBM3E vs LPDDR5、FP8 vs INT8、>3× BF16 FLOPS、2.5D CoWoS vs 单 die、网络 chiplet 支持 RoCE vs 无、SIMD 增加 >6× FP32 使 GEMM:SIMD 16:1 vs 32:1（训练非 GEMM 计算需求上升）、FP32 SIMD 21.3 vs 1.4 TOPS；(b) 与 H100 差异化（Table II）——HBM bytes-to-FLOPS 比 >2×、网络 bytes-to-FLOPS >5×、全局 SRAM >3× 容量、NIC 可切分 scale-up/scale-out（扁平网络最高 1.2 TB/s）、硬件 collective + 片上数据移动、DLRM 优化（embedding cache/索引 DMA/radix sort）、WQE 快速 job dispatch、冗余行 + SRAM/HBM ECC 可靠性；(c) 与 H100/H200 规格与 Perf/TCO（Table III/IV：912W/1500W 加速器/主机 vs 500W/6500W、700W/8850W；216 vs 96/141 GB、6.1 vs 2.4/4.8 TB/s、1 vs 8 加速器/host、scale-up 16 节点 800 GB/s vs 8 节点 450 GB/s、scale-out 200 vs 50 GB/s）——大 HBM 支撑更大 local batch（10240）与 8 卡 LLM 推理，1:1 host 支撑 CPU offload（Shampoo 特征分解，1:8 会损失 7.8%）。

- 开源情况。基于开源文档和论文，使用例子解释模拟器如何使用？作用是什么？
  - 未开源：MTIA 300 为 Meta 专有商用芯片（ISCA 2026），无 RTL/模拟器/仓库（联网无法确认任何公开实现）；NIC 第三方 IP 为商业授权；HCCL 配套论文（arXiv:2608.00358）亦未开源。复现需 Meta 内部硬件。相关公开规范参照：JEDEC HBM3E、RoCE/RDMA verbs。
  - 使用例子（基于论文描述，一次芯片级数据路径）：主机经 16× PCIe Gen5 提交工作到 compute chiplet host interface（含 DMA、secure boot、debug）→ CPU-C 派发 → PE 网格经 2D mesh NoC（L-routing、cluster router）访问东西侧 SRAM/LLC 与 HBM3E；collective 数据路径：PE 的 RE 归约结果或待发送张量经 NoC 到北/南边 chiplet interface → die-to-die（112G SerDes）→ 网络 chiplet → 12 个 RoCE NIC 之一（express doorbell 收 WR、按 AXI steering tag 分流到独立 cache partition）→ scale-up（800 GB/s、16 节点域）或 scale-out（200 GB/s、4096 节点）网络。作用：把网络功能封装进 chiplet 消除 PCIe 开销、以 chiplet 化 + 冗余行提升良率与扩展性、以 1:1 host 架构支撑 CPU offload，最终体现为 1.42× Perf/TCO（vs H100）与高并发 LLM 推理优势。
