## Intermittence-aware Speculative Page Coloring for Secure NVM

- 属于kernel调度/运行时计算的实现是什么？实验比较什么？
  - 近似匹配（论文本体为编译器/运行时协同内存管理，此处覆盖其运行时页管理组件 page manager）：在 MCU 上执行页级调度与安全数据传输——每条 load/store 执行前按编译器 hint（页号 P + 颜色 C）直接索引 Buffer Table（BT，软件页表，条目数 = SPM frame 数）判定 P 是否驻留 frame C；命中则按运行时计算的页内偏移访问；未命中（misspeculation：实际功率周期长于预期、两页争用同一 frame）则把 frame C 中的旧页 AES-XTS 加密写回 NVM、从 NVM 取新页解密载入并更新 BT；Write Tracking Queue（WTQ，1,028B）记录脏页（脏页号 + frame 号）供断电时只持久化脏页。加密用 MSP430FR5994 的 AES 加速器/库实现 AES-XTS（16B 块，SPM 内部缓冲 4 块凑成 64B 页后原子 flush）。崩溃一致性：V_backup 阈值调高保证每次 page manager 调用 failure-atomic；JIT checkpoint 按 WTQ 持久化脏页 + 保存寄存器/heap/stack + 翻转 NVM 完成标志位；恢复时按标志位判定 checkpoint 完整性（0 则 abort）。page manager 代码 491B、WTQ 1,028B。
  - 实验比较：同一真实硬件上比较 MANATEE runtime vs Mapi-Pro [9]（ILP 静态 hot/cold 映射 + 整 SPM checkpoint，4.9×）、NVSRAM [56]（整 SPM checkpoint，4.5–4.6×）、Memory Coloring [63]（无滑动窗口着色 + 永久 spill，1.93×）、Unsecure（无安全基线）；指标：归一化执行开销（MANATEE thermal 1.71×/RFHome 1.71×/solar 1.72×）、页 miss rate（MANATEE ~0.99% vs 无滑动窗口 2.05%，降 ~50%）、性能分解（CRC32 加解密占 ~74%；平均执行 ~58%/页管理 ~25%/加解密 ~16%）、误估敏感性（100% 误估最多 +16% 开销）、wear-leveling 开销（+15%）。
- 后端平台是什么，配置是什么。
  - MSP430FR5994 MCU（16 位低功耗 MCU，1mF 电容，默认 512B SPM，片内 AES 加速器/库），power generator board 注入 thermal/RFHome/solar 三条真实功率 trace [17,19,42,69]；工作负载变化实验在 STM32（ARM Cortex-M33 + 4MB 片外 MRAM，512KB–4MB 数据集）。
- 评估性能的软件/脚本是什么。修改了什么。
  - 评估基于真实硬件 + 功率发生器板（产生电源失效），无公开脚本；12 个 benchmark 来自先前工作 [9,57,81]（含 6 个 intermittent learning 的 ML 负载、不同稀疏度 [10,48,50]，以及 Matmult、CRC32 等内存密集负载）；benchmark 用 LLVM 插桩 + TI MSP430 GCC 链接成二进制刷入 MCU，在功率 trace 下测总执行时间。修改的是 MANATEE 编译器与 page manager runtime（自研），未修改 MCU 硬件。
- 开源情况。基于开源文档和论文，使用例子解释评估软件/脚本如何使用？至少具体到评估软件的评估原理和kernel输入到性能输出的全过程。
  - 开源：论文未给出代码/artifact 链接，联网搜索未找到公开仓库，无法确认。评估原理（page manager 一次 store 输入到性能输出全过程）：输入 = 插桩二进制中的 store 指令（编译器 hint：NVM 页号 P + 颜色 C）+ SPM（512B，若干 page frame）+ BT + WTQ + NVM 中加密页 → ①按 hint 直接索引 BT 的 C 条目查 P 是否驻留 frame C；②命中：在 frame C 内按运行时页内偏移写入，store 后 WTQ 记录 (P, C)；③未命中：frame C 若被其他页占用，先把旧页 64B 数据 AES-XTS 加密（4×16B 块在 SPM 内部缓冲、凑齐原子 flush NVM）写回，再从 NVM 取 P 解密载入 frame C，更新 BT（与 WTQ）；④功率失效（V_backup 触发）时 JIT checkpoint：按 WTQ 持久化脏页 + 保存寄存器/heap/stack + 翻转完成标志位；恢复时读标志位从最近 checkpoint 继续或 abort。输出 = 每次访问的页命中/未命中判定、页交换与加解密延迟、断电前脏页持久化开销，累加为总执行时间；页 miss rate ≈1%（thermal）使 MANATEE 相对 Unsecure 仅 1.71× 开销、相对 Mapi-Pro 快 2–3×、相对 Memory Coloring 平均快 12%、STM32 4MB 数据集场景比 Mapi-Pro 快 5.7×。
