## Accelerator Polymorphism: Transcending Domain-Specific Architectures with Robotics（近似层次匹配：queue-centric SIMD 运行时计算与片上/片外数据调度）

- 属于kernel调度/运行时计算的实现是什么？实验比较什么？
  - 实现为 Morphatron 的 queue-centric SIMD 运行时执行与数据调度机制（论文为硬件架构论文，本层次取其中"动态尺寸数据结构上的运行时计算与数据搬运调度"部分，属近似匹配）。(1) 动态队列的运行时并行计算：FIFO 队列按 interleave 方式划分成 N 个 sub-queue 映射到 N 个执行 stage，每 stage 的 Queue Manager（组合逻辑）独立维护 head/tail/empty，空 sub-queue 由硬件自动 skip，指令（POP_Q/PEEK_Q/PUSH_Q）直接以 sub-queue 为操作数在 scratchpad sub-bank 上执行；(2) in-pipeline 动态内存分配与调度：队列增长时第三流水级的 buddy-tree 分配器按 256 B slice 单周期分配、slice 末字指针链式扩展，队列超出片上容量时按 FIFO 顺序 spill 到 off-chip（保留 head slice 片上），利用队列严格 FIFO 特性做自动 prefetch 与 double-buffering，无需 cache 层次；(3) 数据搬运引擎调度：DMA 在 vector/systolic morpha 由编译器静态编程（prefetch、double-buffering），在 queue-centric 执行时用 Queue Manager 内队列统计动态填充小指令模板编程；(4) 队列即控制流：Q_LOOP_UNTIL_EMPTY 由前端硬件循环（程序计数器仅在所有 sub-queue 空后前进）、Q_CONDITIONAL_PUSH 选择性入队，以"数据可用性"取代 predication 掩码。
  - 实验比较（消融）：vector morpha vs 同硬件上模拟的传统向量处理器（YOLO/EKF/OSQP/CCCD 四 kernel：传统方案地址计算 28%、寄存器文件 load/store 15%、软件循环管理 19% 的平均运行时开销，Morphatron 单次配置开销最多 0.29%、平均 0.01%）；queue 谓词 vs 传统 predication（SLAM 点云过滤，pass rate 0–100% 扫描、1.6× sub-queue 不均衡：30% pass rate 时传统方案 70% 周期被 masked lane 浪费，Morphatron 2.4× 加速）；off-chip queue spill vs 理想 cache+prefetch（数据量 1.5–20× 片上容量、算术强度 5/10/20 FLOP/B 扫描：最坏 1.5× 容量+AI=5 时 12.7% 开销，3× 容量降到 6.6%）。
- 后端平台是什么，配置是什么。
  - Morphatron（自研 cycle-level 模拟器）：7 nm ASAP7、625 MHz、10 W；32×4 Morpha Core 网格、每核 8 执行 stage（ALU + 8 KB sub-bank）、16 MB 片上、32 B 宽 circuit-switched 互连、DRAM 68 GB/s。对照 baseline：ARM A78AE（NEON）、Xeon 6226R（AVX512）、Jetson Orin Nano、RTX 3090（CUDA 12.1）。
- 评估性能的软件/脚本是什么。修改了什么。
  - 自研 cycle-level 模拟器（无名称、未开源）+ Synopsys Design Compiler 综合 + CACTI 能量模型；消融变体为在模拟器内把对应机制替换为传统向量处理器机制（地址计算/寄存器文件/软件循环）或 predication 执行模型后重新测同一 workload。修改点：无开源基座，全部自研。

  - 模拟器与 RTL 是否开源论文未明确说明，联网搜索未找到公开仓库；benchmark RoWild 开源（https://github.com/cmu-roboarch/rowild ）。
  - 评估原理与全过程：输入 = RoWild 应用的 queue 语义指令流（例：`Q_LOOP_UNTIL_EMPTY, Q.ID[#0], 1: ADD, Q.ID[#1].PUSH, Q.ID[#0].POP, 0x01`，及 SLAM 过滤用 Q_CONDITIONAL_PUSH 选择性入队）。每个执行 stage 的 Queue Manager 按 queue ID 查队表取 head/tail 指针，从 scratchpad sub-bank 取操作数直接喂 ALU、结果写 tail 并推进（无寄存器文件、无地址计算指令），空 lane 由硬件 skip；队列扩容触发 buddy-tree 分配 256 B slice（slice 末字链下一 slice），超出片上份额时 FIFO spill 到 off-chip 并自动 prefetch；跨核/片外数据经 DMA 与 BROADCAST/COLUMN_REDUCE collectives 搬运（queue-centric 阶段 DMA 参数由队列统计动态填充）。输出 = 逐周期统计的执行时间与能耗 → 消融加速比（vector morpha 相对传统向量处理器 YOLO 18×、EKF 8.4×、OSQP 1.74×、CCCD 1.27×；queue 谓词 30% pass rate 2.4×；spill 相对理想 cache 最坏 12.7% 开销）与 morpha 级加速贡献（Systolic/Vector 单独 0.7×、+Queue 5.2×、+Graph 3.3×、+Tree 2.2×，均归一化 ARM）。
