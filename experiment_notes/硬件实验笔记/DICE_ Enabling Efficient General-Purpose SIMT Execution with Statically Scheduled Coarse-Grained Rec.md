## DICE: Enabling Efficient General-Purpose SIMT Execution with Statically Scheduled Coarse-Grained Reconfigurable Arrays

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现：DICE（Dataflow Intelligent Compute Engine）——用静态调度、spatial-only 的 CGRA 替换 GPGPU 的 SIMD 后端，保留 SIMT 编程模型。硬件实现三线：(1) DICE 专用组件 RTL 实现（CP 控制流水、Dispatcher、PDOM Stack、BRT、TMCU 等），FreePDK45 + Cadence 工具链综合，结果按 Stillmaker & Baas 缩放公式折算到 12nm FinFET 与 Turing 基线对比；(2) 扩展 Accel-sim 周期精确模拟器建模 DICE CP/CC 微架构；(3) 扩展 AccelWattch 功耗框架构建 DICE 动态功耗模型（DICE 新增 SRAM 用 CACTI 建模、控制逻辑用 Cadence Joules 对 RTL 做活动 trace 分析）。核心微架构：每 CP 为 4×5 CGRA（16 个 ALU PE + 4 个 SFU），wire-switched 静态互连（类 AHA [23]），1-bit 谓词信号支持 predicated execution；CP 四阶段控制流水 CS（CTA Schedule）→ FDR（Fetch/Decode/Reconfig：p-graph cache、BTFNT 分支预测、double-buffered 配置存储 CM0/CM1）→ DE（Dispatcher = Active Thread Selection Logic + Scoreboard + Operand Collector + 32-bank RF + LDST Unit，线程 II=1 流水进入 CGRA）→ RE（Block Retire Table 非阻塞跟踪未归访存）；TMCU（coalesce buffer + max_interval 定时器）对流水线程做时序访存合并。
  - 实验比较：对 NVIDIA Turing 建模基线 RTX2060S（34 SMs、4 subcores/SM、16 CUDA cores/subcore 共 2176 核、1024 threads/SM、256KB RF/SM 共 8.5MB、96KB L1/SM 共 3.2MB、4096KB L2、GDDR6 8ch、core 1470 MHz / DRAM 1750 MHz）vs DICE（34 CCs、4 CPs/CC、16 PEs/CP 共 2176 PEs、2048 threads/CC、32 banks/CP 共 256KB RF/CC、96KB L1/CC、L2/DRAM 与基线相同）；内部消融变体 DICE-naïve（unroll/TMCU 全关）、DICE-naïve+unroll（2×/4×）、DICE-naïve+TMCU（max_interval=8）、DICE（双开）；规模扩展 DICE-U（32 PEs/CP、2 CPs/CC）、DICE-O48/O72（48/72 CCs 对 Quadro RTX5000/RTX6000）、DICE-UO（46 CCs、32 PEs/CP 对 RTX3070）。指标：speedup、RF 访问数、stall/FU 利用率分解、CP 动态功耗与能效、面积（Fig.14 分解）。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 修改的模拟器：Accel-sim 周期精确 GPGPU 模拟框架（ISCA 2020，官方仓库 https://github.com/accel-sim/accel-sim-framework ，性能模型为 GPGPU-Sim 4.x）。功耗：AccelWattch（MICRO 2021，随 accel-sim-framework 发布）扩展出 DICE 功耗模型；Cadence Joules（https://www.cadence.com/en_US/home/tools/digital-design-and-signoff/power-analysis/joules-rtl-power-solution.html ）；CACTI（HP Labs，https://github.com/HewlettPackard/cacti ）；综合 PDK FreePDK45（https://eda.ncsu.edu/freepdk/freepdk45/ ）。
- 模拟器模拟什么的性能，修改了什么。
  - 模拟 DICE 与 Turing/Ampere 基线在 Rodinia 负载上的周期级性能、RF 访问计数与动态功耗。修改：(1) Accel-sim 新增 DICE 机模型——CC/CP 层级、p-graph 粒度的 e-block 调度（CS/FDR/DE/RE）、CGRA 位流装载与双缓冲切换、逐线程 II=1 流水 dispatch、LDST Unit 与 BRT 非阻塞 retire；(2) AccelWattch 新增/替换 DICE 组件功耗条目：RF 按 per-access 能量、控制逻辑用 Joules 从 RTL 活动 trace 得、CGRA 开关与配置存储等新增 SRAM 用 CACTI 建模；两侧共享组件（L1、共享内存、计算）沿用 AccelWattch per-access 能量保证公平。关键建模参数：N_r=32 bank/CP、N_Tmax=4、K=8（4× unroll）/K=16（2× unroll，3× 不支持）、TMCU max_interval=8（=32B L1 sector/4B 访问）、p-graph 执行 t 线程 × p 级流水需 t+p 周期。

  - 模拟原理与全过程：输入 = Rodinia CUDA kernel（NN euclid、BFS kernel/kernel2、BPNN layerforward/adjust_weights、SC compute_cost、GE Fan1/Fan2、HS calculate_temp、PF dynproc_kernel 共 10 kernel，Table III 给 p-graph 数与 CTA/grid/线程数）+ 目标配置（RTX2060S/DICE/DICE-U/O48/O72/UO 等）→ nvcc 编译 PTX → DICE 编译器产 p-graph IR+位流 → Accel-sim 逐周期仿真：DICE 侧 CP 流水取 metadata/位流、活跃线程按 tid 升序以 II=1 流入 CGRA、访存经 LDST Unit/TMCU 合并进 L1→L2→GDDR6 通道模型、BTFNT+PDOM stack 处理发散、BRT 非阻塞 retire；基线侧走标准 warp 调度 SIMD 数据路径 → 输出每 kernel 周期/IPC、RF 访问计数、cycle breakdown 与 FU 利用率（Fig.11）→ AccelWattch 按事件计数 × per-access 能量 + Joules RTL 活动 trace 功率求和得 SM/CP 动态功耗 → 归一化绘图。作用：验证"空间流水不牺牲性能大幅降功耗"——DICE 对 RTX2060S geomean 1.16× speedup、RF 访问 −68%、CP 动态能效 1.90×、平均功耗 −42.0%；消融 unroll 至多 1.35×（BPNN-1/GE-1/HS）、TMCU 至多 2.45×（NN/BFS-2/BPNN-1/BPNN-2）、双开合计 1.54× vs naïve；scale-up DICE-U 0.97×（RF −3.8%）；scale-out O48/O72 1.04–1.05× 且能效 1.77–1.83×、功耗 −43.0%–45.9%；DICE-UO 对 RTX3070 性能持平、RF −68%。面积：DICE cluster 16.21 mm²（FreePDK45），12nm 折算 2.92 mm²，对 RTX2060S SM 估算 5.44 mm² / GTX1660Ti SM 4.46 mm² 同量级或更小；CGRA 开关+配置存储占 CP 面积 9.7%、改造控制组件（PDOM stack/scoreboard/operand collector/TMCU 等）12.1%，相对 SM 面积开销上界 10.7%。
