## UniCore: A Bit-Width Scalable GEMM Unit for Unified LLM Inference

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现是 UNICORE：一个位宽可扩展的统一 GEMM 加速器架构（ISCA 2026，HKUST-GZ），核心是 S-FPMA（Scalable Floating-Point Multiplication Approximation）可组合近似乘法原语。FPMA 基于 Mitchell 对数近似（log2(1+M)≈M）把浮点乘法变成对拼接 exponent-mantissa 域的整数加法（R≈X+Y−B），从而消除乘法器、硬件成本随位宽线性 O(n) 扩展，规避 bit-composable 乘法器架构（Bit-Fusion 风格）的 O(n²) 二次资源开销。S-FPMA 由统一 4-bit 加法 slice 组成：W4A4 时每个 slice 独立做两个低比特 MAC；W8A8 时两个 slice 经内部进位链动态融合成单个宽操作数；W16A16 时四个 slice 级联，面积/时延严格线性增长。围绕 S-FPMA 的 PE 阵列配套：Unified Format Converter（把低比特输入无损扩展到内部 E3M2 格式以消除 subnormal、并解码 DynFP 格式）、PreAdd 单元（激活做指数偏置校正 T=A−B）、双链部分和累加数据通路（W4A4 模式两链求和、W8A8 模式两链拼接，无需 mux）、Rescale 反量化与全局 Accumulator。整个 GEMM Unit 为可扩展 2D Tile 阵列，Tile 组成 Group（PE 列数=量化 group size，支持逐 group 低比特量化），配套 Weight Buffer、Unified Buffer、Vector Unit（layer-wise 运算）与 Control Unit。精度保持管线：subnormal 归一化（位宽扩展）+ 双路径误差补偿（细粒度 FG 补偿经 LUT 把缺失低位 bit-pattern 拼接到 FPMA 结果 LSB 侧，粗粒度 CG 补偿 1-bit 进位注入），使 FP4 下 FPMA 可达到与全精度乘法完全一致的结果。
  - 实验比较：与五个代表性 LLM GEMM 加速器对比——bit-parallel 可组合乘法器设计 OliVe、Tender、M-ANT，以及定宽混合精度设计 BitMoD、AxCore；均在相同面积约束下、相同 512KB activation buffer + 512KB weight buffer（CACTI 建模）、相同 TSMC 28nm/1GHz 综合流程下评估。指标：PE 面积分解、GEMM 面积、计算密度（TOPS/mm²）、prefill/decode 端到端加速比、能耗（TOPS/W），覆盖 W4A4/W4A8/W8A8/W16A16 与 4–16 bit 扩展。结果：PE 面积降 13.6%–43%，GEMM 面积降 19%–49%（归一化 0.51）；W4A4/W4A8/W8A8 面积效率高 1.24×–3.95×，W16A16 高 5.26×；GEMM 计算密度 W8A8 达 3.95 TOPS/mm²（2.47×–3.95× 优势）；prefill 相对 OliVe/Tender/M-ANT 平均 3.21×/2.91×/2.51× 加速，decode（batch=128）DDR4 下 2.96×/1.04×/1.08×、HBM2 下 2.00×/1.35×/1.60×；归一化 TOPS/W 平均高 1.86×（最高 2.73×）。与定宽对比（图 21）：固定精度 UNICORE GEMM 在 W4A4/W8A8/W16A16 计算密度 6.46/3.42/2.05，分别超 Synopsys DesignWare IP 2.78×/1.94×/2.05×、超无组合能力的修改版 Tender 1.32×/1.19×/1.90×。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 论文扩展 BitMoD cycle-accurate 模拟器（论文 ref [7]，BitMoD: HPCA 2025；开源仓库 https://github.com/abdelfattah-lab/BitMoD-HPCA-25 及镜像 https://github.com/yc2367/BitMoD-HPCA-25，Zenodo artifact https://zenodo.org/records/14251941），把 post-synthesis RTL 导出的 timing/energy 模型注入模拟器评估系统级 prefill/decode 性能与能耗。
  - 片上 SRAM 用 CACTI（https://github.com/HewlettPackard/cacti，论文 ref [32]，CACTI 6.0/Muralimanohar MICRO'07）建模 512KB activation buffer + 512KB weight buffer。
  - 片外访存能耗用 DRAMsim3（https://github.com/UMD-MEMSYS/DRAMsim3，论文 ref [23]，Li et al. IEEE CAL 2020）：prefill 阶段 DDR4 配置 25.6 GB/s；decode 阶段额外加 HBM2 配置 256 GB/s。
  - RTL 用 SpinalHDL 编写（https://github.com/SpinalHDL/SpinalHDL，论文 ref [10]），Synopsys Design Compiler 在 TSMC 28nm 工艺、1 GHz 时钟下综合。
- 模拟器模拟什么的性能，修改了什么。
  - 模拟器模拟 UNICORE 加速器执行 LLM GEMM 工作负载的端到端行为：prefill（序列长 8192，Llama-2-7B/Llama-3-8B）与 decode（batch=128，DDR4 25.6GB/s 与 HBM2 256GB/s 两种内存配置），输出归一化加速比（图 17、19、20）、能耗分解与 TOPS/W（图 18），覆盖 W4A4/W4A8/W8A8/W16A16。修改点：在 BitMoD cycle-accurate 模拟器基础上，注入 UNICORE post-synthesis RTL 的 timing/energy 模型（S-FPMA 加法 slice 阵列、双链累加、格式转换/补偿管线、Rescale），并把五个 baseline（OliVe/Tender/M-ANT 可组合乘法器 + BitMoD/AxCore 定宽混合精度）在相同面积约束与相同 buffer 配置下归一化实现进统一评估框架；把 Tender 扩展支持 W16A16 以评估 16-bit 扩展；将 M-ANT 与 BitMoD 的量化方案扩展到不同位宽的整数激活量化（扩展 BitMoD、M-ANT 支持整数激活量化）。DRAMsim3 提供 DDR4/HBM2 片外能耗，CACTI 提供片上 buffer 面积与能耗。
  - 模拟输出：归一化 prefill 加速比（与 OliVe/Tender/M-ANT 对比）、decode 加速比（DDR4/HBM2 两套）、能耗分解与归一化 TOPS/W、PE/GEMM 归一化面积（图 14）、计算密度 TOPS/mm²（图 15、16）。

  - 使用例子（模拟器输入到性能输出的全过程）：① 输入——量化后的权重/激活（W4A4/W4A8/W8A8/W16A16 格式，DynFP 或 INT）、UNICORE 架构配置（PE/Tile/Group 阵列规模、512KB activation + 512KB weight buffer、DDR4 25.6GB/s 或 HBM2 256GB/s 内存）、post-synthesis RTL 的 timing/energy 模型（TSMC 28nm@1GHz）、工作负载（Llama-2-7B/Llama-3-8B，序列 8192 的 prefill 或 batch=128 的 decode）；② 模拟器按 cycle 推进：Weight Buffer 经 Unified Format Converter 把低比特权重解码/归一化到 E3M2 内部格式并按 Group 预加载驻留在 PE 列；Unified Buffer 流出激活，经 PreAdd 做指数偏置校正（T=A−B）后沿列方向复用广播；每个 S-FPMA slice 对 (W,T) 做 T+W 整数加法得到近似乘积，FG/CG 补偿经 LUT/进位链注入恢复低位与高位误差；乘积经 shifter 转 sign-magnitude 后与传入部分和 S 经专用加法器混合格式累加，双链部分和在 W4A4 模式求和、W8A8 模式拼接，行内传播；完成后 Rescale 用 group scale 反量化，各 Group 输出在全局 Accumulator 合并；③ 片外访存由 DRAMsim3（DDR4/HBM2）计时计能耗，片上 buffer 能耗/面积由 CACTI 建模；④ 输出——端到端 cycle 数换算归一化加速比（相对 OliVe/Tender/M-ANT 同面积归一化配置）、能耗分解（计算/片上/片外）与 TOPS/W，得图 17-20。作用原理：在真实硅片不可得的条件下，把"位宽可扩展 S-FPMA 加法型数据通路 vs 乘法器型可组合数据通路的 O(n) vs O(n²) 资源缩放差异"量化为面积归一化后的吞吐、加速比与能耗，验证同一套硬件在 W4A4/W4A8/W8A8/W16A16 下都能保持高利用率，而乘法器型 baseline 在高位宽发生吞吐塌缩。
