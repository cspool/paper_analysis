## ELSA: An ELastic SNN Inference Architecture for Efficient Neuromorphic Computing

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现为 ELSA 近 SRAM（near-SRAM）数据流 SNN 推理加速器 RTL：6×6 神经核（neural core）经定制 2D-mesh NoC 互连，每核 = 1 个定制路由器 + 4 个 PE。PE 内含 128 个 ST-BIF（双极积分-激发-脉冲追踪）神经元电路（16 输入加法树 + fire 组件 + update 组件）、N 路权重 SRAM（4×102.4 KB）、膜电位 buffer（4×307.2 KB）、spike tracer buffer（4×102.4 KB），每 PE 每周期可执行 1024 次加法（addition-only，无乘法）。路由器含 SSoftmax/SLayerNorm 单元（router 侧执行 SNN 杂项算子）、im2col 单元、Local Input Reducer、Flit Generator/Decoder、FIFO Queue（作为核间 pipeline register）、ELSA Output Scheduler、Routing Engine，实现 bundled AER（BAER）协议。硬件层面三大创新：(1) 细粒度 spine/token 级流水线——每个完成的 spine（CNN 的 Z^{1×1×C}）/token（Transformer 的 Z^{1×D}）立即前传下一层，替代层间同步屏障；(2) BAER 打包协议——同行 spike 捆绑进一个 flit（256-bit 替代 17 spike × 25-bit = 425 bits）；(3) mini-batch spiking Gustavson-product 数据流——BAER 行对齐提供 mini-batch，每 batch 只读/写一次膜电位行、并行累加多权重行。映射优化：贪心分区（Algorithm 2，按通信量排序合并层）+ Hilbert 曲线放置 + 多路径路由（遗传算法优化各路径传输概率）。
  - 实验比较：弹性 SNN 加速器 TrueNorth / Darwin / MorphIC / PAICORE（TBT）；非弹性 SNN 加速器 C-DNN / SpinalFlow / SASAP / Prosperity / Phi（LBL）；QANN 加速器 Eyeriss / Eyeriss v2 / ANT / S-CONV / AIOQAB / Sanger / ViTALiTy / AEC-CIM / LLH-CIM；商用大芯片 Jetson AGX Orin / A100 / TPU v4 / Groq。指标：吞吐（GOPS）、能效（TOPS/W）、pJ/Sop、面积效率（GOPS/mm²）、首响应（FCR）延迟、早停 cycle 缩减、NoC traffic/energy（表 VIII）、消融（Gustavson / spine-token 流水 / BAER / 多路径路由 / SRAM vs eDRAM 存储）、scaling（ResNet18→101）。主要结果：vs ANT 3.4× 吞吐 + 13.6× 能效（4-bit ResNet50），vs PAICORE 2.9× 吞吐 + 22.1× 能效（27.4× geomean 能量来自 Gustavson 数据流、1.65× 来自 spine/token 流水），4135.4 GOPS / 25.55 TOPS/W / 0.032 pJ/Sop / 100.23 mm²。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 无现成开源模拟器修改：ELSA 自建 cycle-level 模拟器，各组件参数（面积/功率/延迟）提取自 RTL 综合结果。评估工具链：Synopsys Design Compiler（28nm 商业工艺综合）、Synopsys VCS（post-synthesis 仿真验证）、Synopsys PrimeTime PX（门级 netlist 翻转率标注 → 能量估计）、商业 memory compiler（SRAM 面积/能量）、DRAMSim3（https://github.com/CMU-SAFARI/DRAMSim3，HBM3.0 片外访存成本）、DSENT（https://github.com/bachtlab/DSENT，NoC 能量/延迟）。SNN 模型按 SpikeZIP-TF 生成。
- 模拟器模拟什么的性能，修改了什么。
  - cycle-level 模拟器模拟端到端 SNN 推理性能：每帧周期/吞吐、早停 cycle 缩减、不同数据注入率下的 NoC 拥塞行为（图 21）、技术分解（图 22）；DSENT 模拟 NoC 能量与延迟（6×6 2D mesh，与 MorphIC/TrueNorth 同带宽与 flit buffer 配置公平对比，表 VIII）；DRAMSim3 评估 HBM3.0 片外访问（ELSA 因 near-memory 设计片外访问可忽略，仅输入 spike 从 DRAM 载入）。RTL 本体（PE/路由器/BAER/scheduler/多路径路由）为自研设计，非修改开源模拟器。

  - 开源：是。GitHub https://github.com/Intelligent-Computing-Research-Group/ELSA（官方实现，ISCA 2026 artifact），Zenodo 归档 https://zenodo.org/records/19449728。目录分两部分：ELSA_Algorithm（PyTorch 2.4.1 框架，SNN 模型精度与弹性推理评估，硬件依赖 8× NVIDIA 4090，软件 Ubuntu 22.04.3 LTS / CUDA 12.2 / GCC 11.4.0 / Anaconda 24.5.0）；ELSA_Simulator（性能与能量评估，硬件依赖 AMD EPYC 9334 32 核服务器）。完整 PPA 评估约 8 小时，用预生成 tracer 文件可在 1 分钟内快速复现图 16/17。
  - 模拟原理与输入→输出：ELSA_Algorithm 将 QANN 权重经 SpikeZIP-TF 式无损转换生成 ST-BIF SNN（4-bit 权重量化），在 ImageNet/CIFAR10/CIFAR100/CIFAR10-DVS/COCO2017/VOC2007 上逐时间步推理并记录 spike trace 与早停置信度；ELSA_Simulator 输入 = 模型结构 + spike trace + RTL 综合参数（各组件面积/功率/延迟、SRAM 容量与带宽）。cycle-level 模拟器逐周期推进：spike 经 Local Input Reducer 收集 → Flit Generator 捆绑为 BAER flit（6-bit 路由 hop 计数 (m,n) + 2-bit type（begin/body/end）+ 12-bit spine/token ID + 12-bit spike 位置 + 1-bit 极性 + 15-bit ECC）→ 按静态多路径路由（Routing Engine 存各端口传输概率，遗传算法优化）经 2D-mesh NoC 转发 → 远端 Flit Decoder 解包入 FIFO Queue → Output Scheduler 按 spine/token 数据依赖立即调度下一层 PE 计算（mini-batch Gustavson：读出对应权重行 + 单次膜行读、16 输入加法树并行累加、fire 组件判激发、update 写回膜与 tracer）→ 置信度达阈值即早停。输出 = 每帧周期/吞吐（GOPS）、能量（PrimeTime PX 翻转率 + DSENT NoC + DRAMSim3 HBM3.0）、面积（memory compiler + DC），归一化对比 Eyeriss 等基线。
