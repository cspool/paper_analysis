## Accelerator Polymorphism: Transcending Domain-Specific Architectures with Robotics

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现为 Morphatron：Verilog RTL 实现的多核多态加速器，单一物理衬底在五种执行形态（morpha）间运行时切换——queue-centric SIMD、multi-core graph、single-core tree、vector、systolic。核心 Morpha Core 为无寄存器文件的 queue-centric SIMD 深流水处理器：每个执行 stage 耦合 1 个 ALU + 8 KB scratchpad sub-bank + 1 个 Queue Manager（纯组合逻辑，维护 sub-queue 的 head/tail/size/empty），指令以 queue ID 为操作数直接在 sub-queue 上 pop/peek/push，消除寄存器文件与 load/store 地址计算；第三流水级内置 in-pipeline 动态内存分配：每 stage 一棵 buddy-tree 分配器（深度 6、32 叶、32-to-5 priority encoder，以 256 B slice 为粒度，单周期确定分配），slice 末字复用为下一 slice 指针实现链表式动态管理，队列超出片上容量时按 FIFO 顺序 spill 到 off-chip（仅保留 head slice 片上、末字作 off-chip 指针）。多核组织：评估配置为 32×4 的 Morpha Core 网格（Table II 记 1056 cores、16 MB on-chip），全部核经 32 B 宽的 circuit-switched 互连（每 switch 5 端口 N/S/W/E/Local + 5×5 crossbar，仅 2 个配置位编码 4 种路由模式；graph/tree 走地址比较器动态路由），Data Movement Engine 提供多 DMA（BROADCAST/COLUMN_REDUCE 两种 collective）与 2 个 Global Buffer，Morphatron Controller 经 32-bit 控制网络管 morpha 切换与同步（切换时 power-gate 未用逻辑）。五 morphas：systolic——核的执行 stage 行即 systolic 行、垂直列核成 systolic 阵列（Global Buffer 2/1 为输入/输出缓冲）；vector——Static Addressing Unit 迭代表（SET_ITER/SET_STRIDE/SET_BASE_ADDR）硬件生成仿射地址；graph——MIMD-over-SIMD 顶点中心模型（共享队列 + REMOTE_STORE/READ 跨核更新）；tree——单核计算、其余核仅留存储 sub-bank 与 switch 组成"单核可见的大内存"；queue/vector 可横向链核加宽（4 核一行 = 32-wide SIMD）。RTL 覆盖：取指前端、各 stage Queue Manager、buddy-tree 分配器、迭代表、off-chip spill 逻辑、circuit switch。
  - 实验比较 4 个真实平台 baseline（ARM Cortex-A78AE 10 W、Intel Xeon Gold 6226R 150 W、NVIDIA Jetson Orin Nano GPU 12 W、NVIDIA RTX 3090 350 W）+ 理想化 Jetson（CPU/GPU 按 phase 最优分配且忽略数据搬运）+ 5 种固定分区变体（均分 / 各 50% 偏向 systolic、vector+queue、tree、graph）+ 仅开 Systolic/Vector 的 TPU-like 配置 + 神经网络推理对比（Orin Nano + TensorRT，含 BERT/GPT-2 共 4 模型）。指标：端到端 latency 加速比、performance-per-watt（PPW）、能耗分解、面积分解、形状切换延迟（Table III：Systolic/Queue 重配 165 cycle、Graph/Tree 288、collective 配置 129、队列分配 3、释放 2）、消融（vector vs 传统向量处理器、queue predication vs 传统 predication、off-chip spill vs 理想 cache+prefetch）。
- 硬件平台是什么，配置是什么。
  - Morphatron：Synopsys Design Compiler + ASAP7 7 nm PDK 综合，625 MHz，TDP 10 W，DRAM 带宽 68 GB/s（与 Jetson 同级），片上存储 16 MB；逻辑能量/面积用综合网表结果 + CACTI 估算。baseline 平台：ARM A78AE 6 核 1.5 GHz（NEON + OpenMP）、Xeon 6226R 32 核 3.9 GHz（AVX512 + OpenMP）、Jetson Orin Nano 1024 核 625 MHz（CUDA 12.1）、RTX 3090 10496 核 1.395 GHz（CUDA 12.1）。

  - 模拟原理与全过程：输入 = 六端到端机器人应用按 Morphatron ISA（32-bit 指令：MORPHA_STATIC/DYN_CONFIG、INIT_Q/PUSH_Q/POP_Q/Q_LOOP_UNTIL_EMPTY/Q_CONDITIONAL_PUSH、REMOTE_STORE/READ、Namespace-ID 统一操作数、DMA/collective 配置、SYNC 屏障）编译出的指令流 + 综合/CACTI 能量面积参数 + morpha 切换延迟表。前端取指译码后，INIT_Q 在分配级触发 8 棵 buddy tree 并行分配 256 B slice 并把 slice 索引随指令下传登记到各 stage Queue Manager；计算指令按 queue ID 由 Queue Manager 直接以 scratchpad sub-bank 头/尾元素作操作数喂 ALU（无 RF、无地址计算），空 sub-queue 自动 skip；Q_LOOP_UNTIL_EMPTY 由前端硬件循环直到全部 sub-queue 空；跨核数据经 circuit-switched 互连按 4 种路由模式转发（graph/tree 经地址比较器按地址范围选向）；DMA 引擎执行 off-chip 搬运与 spill（queue 超片上容量时 FIFO 顺序换出、保留 head slice、末字指针指向 off-chip）；Controller 按 SYNC 边界切换 morpha 并 power-gate 未用端口/逻辑。输出 = 逐周期执行时间与各 morpha/组件能耗 → 端到端 speedup（vs ARM 平均 7.7×、vs Orin Nano 5.5×、vs 理想化 Jetson 3.4×、vs Xeon 1.9×、vs RTX 3090 0.9×）与 PPW（vs ARM 7.7×、vs Orin 6.6×、vs Xeon 28.9×、vs 3090 39.6×）；能耗分解（片上存储 33%、ALU 28%、互连 switch 7%、队列控制+分配器 5%、前端+vector 控制 8%）、面积分解（存储 59%、计算 22%、互连+控制器 11%、前端 6%）、morpha 运行时占比（Vector 38.6%、Queue 19.8%、Tree 17.0%、Systolic 15.6%、Graph 7.7%、切换 1.3%）。
