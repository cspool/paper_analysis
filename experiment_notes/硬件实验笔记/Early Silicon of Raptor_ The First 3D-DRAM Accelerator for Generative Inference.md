## Early Silicon of Raptor: The First 3D-DRAM Accelerator for Generative Inference

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现：Raptor——d-Matrix 首个面向生成式推理的 3D-stacked DRAM (3D-DRAM) 商用加速器（silicon 论文）。XPU 逻辑 die（TSMC N4P）通过 face-to-face (F2F) 36µm-pitch µbump 阵列与 3D-DRAM die 垂直堆叠。逻辑层级：card（2-4 个 MCM）→ MCM（4 个 1.2GHz chiplet）→ chiplet（4 gang × 4 slice，840 个 3D-DRAM bank、256 个 channel）→ slice（4×4 tensor engine 阵列 + SIMD 核 + 16 个 weight buffer + 16 个独立 DRAM channel），D2D 32Gbps/lane、PCIe Gen7/ESUN 组网。四个核心硬件机制：(1) stream blocking——权重/KV cache 按 per-channel block 近单位步长 128B flit 流式映射，每 flit 拆成 96B aligned（3 bank 同列各 32B）+ 32B partial（相邻 flit partial 打包进共享 partial region），固定两步访问（先 partial region 缓存 96B、再取 aligned region 合并），彻底消除 overfetch 并最大化 row-buffer 局部性；(2) stream flipping——无 pin DBI，控制器逐 flit 与前一个 flit 比较、选择性翻转以最小化 µbump 位翻转，每 flit 存 1 bit metadata，读时取 metadata 条件翻转，IO 能耗降 18%；(3) topology-preserving redundancy（bank chaining）——N 功能 bank + M 冗余 bank 链式排列，逻辑 die 上轻量 mux 选任意连续 N-bank 窗口，保持全宽对称 channel；(4) thermal-aware refresh（105°C 下 4ms 刷新间隔）+ 交错 [144,140] Reed-Solomon ECC（每 bank 最后 8 列，与 DBI metadata 共置）+ 周期背景 scrub。
  - 实验比较：tok/s/card vs interactivity (1/TPOT) 曲线（batch=32），对比同一 XPU 逻辑搭配三种内存基板：XPU+SRAM（150 TB/s、4GB）、XPU+HBM（18 TB/s、192GB）、RP+3D-DRAM（100 TB/s、32GB），外加 3D-DRAM 缩放消融（2×BW=200TB/s/32GB、4×BW=400TB/s/32GB、2×Full=200TB/s/64GB、4×Full=400TB/s/128GB）；网络延迟/带宽敏感性（延迟 0.01-10µs、带宽 32GB/s-4TB/s，网络 0.5µs/1TB/s 为现实点）；batch 分析（Poisson 110 req/s 到达）；与 H2-LLM（混合键合 PIM，0.4TB/s/0.28PFLOPS）和 Stratum（Mono3D 分层 DRAM，有效 10-35TB/s）的架构对比；silicon 表征（flit 延迟、每卡带宽、I/O 能量、refresh 开销、RowHammer）。主要结果：700MHz 下 2.5ns 平均 flit 延迟、105TB/s/card（12.5× HBM3）；对 Llama-3.1-70B/DeepSeek-V3/Kimi K2/GPT-OSS/Whisper/Canary 平均 throughput 比 HBM 高 4.71×、比 SRAM 高 2.44×，TPOT 比 HBM 低 9.96×；4K 上下文现实网络下 4.38× vs HBM、3.15× vs SRAM；因并行度更低（如 Llama-70B TP=4 vs SRAM TP=8）对网络延迟/带宽不敏感。

  - 非模拟器评估：真实 silicon 芯片测量（stream blocking/stream flipping/refresh 的实测数据）+ 自研解析性系统级性能模型（事件驱动流量生成器 + batched compute engine + 统一扁平网络模型，参数化为单向延迟与聚合带宽）+ 解析热阻网络模型。论文未提供/修改任何公开模拟器；联网确认该论文为 d-Matrix 商用产品（ISCA 2026，IEEE Xplore pp.2632-2647），无公开模拟器或代码链接。
- 模拟器模拟什么的性能，修改了什么。
  - silicon 测量表征：DRAM 频率（500MHz-1GHz）× bank-per-channel（2/3/4）下的 flit 延迟与每卡 3D-DRAM 带宽（3-bank@700MHz 达 2.5ns/105TB/s）；stream flipping 的 I/O 能量（8 bank 时 0.455→0.376 pJ/bit，18% 降低，比 HBM3 低 ~6×）；refresh 间隔（1/2/4ms）的带宽开销（0.0546/0.0270/0.0137，对应 99.26/102.13/103.57 TB/s）；bank chaining 冗余数量对故障 channel 恢复能力。系统级性能模型：输入模型并行配置（TP/PP/EP/SE、unified/disaggregated 部署，Table II 最小卡配置）+ 内存基板（带宽/容量）+ batch + 网络参数（延迟/带宽）→ 输出 tok/s/card 与 interactivity（1/TPOT）曲线；流量生成器按 Poisson 到达率（110 req/s，即 ~9.5M req/day）模拟请求排队与 batch 形成（engine 空闲时从队列取 q 个请求成 batch b，处理时间 T·q/b），输出 max/avg batch 与稳态队列深度。修改了什么：全部为 d-Matrix 自研设计/自建模型（XPU 逻辑、3D-DRAM、流量生成器），非修改第三方模拟器。

  - 开源情况：论文未提供开源模拟器/代码/基准，联网无法确认（商业产品，d-Matrix Raptor，含 AndesCore AX46MPV RISC-V 编排核）；对比工作 H2-LLM/Stratum 为仿真论文，无可用 artifact。评估使用的模型（Llama-3.1-70B、DeepSeek-V3、GPT-OSS、Kimi K2、Whisper、Canary-1B）均公开。
  - 输入→输出全过程（一次 decode token，系统级模型）：调度器按 batch=32 形成 batch → 事件驱动流量生成器把请求按 Poisson 到达排入队列 → engine 空闲时抽取成 batch → 每个 slice 的 tensor engine 通过专属 3D-DRAM channel 以 128B flit 流式读取权重 tile 与 KV cache tile（stream blocking：先读 partial region 缓存 96B 32B 碎片、再读 96B aligned 列访问合并成 128B flit；stream flipping 读 metadata 决定是否翻转）→ TE 做 GEMV/注意力 MAC → 跨 gang/chiplet 做局部 reduce-scatter、跨 MCM/卡做 D2D/PCIe all-reduce（collective 数据量由 TP/PP 度决定）→ 输出每 token 延迟（TPOT）与每卡吞吐（tok/s/card）。作用：证明 3D-DRAM 在 decode 内存受限域相对 SRAM/HBM 的吞吐-交互性优势、低并行度带来的网络不敏感性，以及各消融点（带宽/容量缩放）对性能的影响。
