## TDMSim: Enabling High-Density and Energy-Efficient GPU DRAM Caches with 2D-Materials for Data-Intensive Applications

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现是跨层仿真工具包 TDMSim（Two-Dimensional Material Simulator）+ 2D-material DRAM cache 的 CPU-GPU 系统集成 + retention-aware 刷新策略：(1) TDMSim 由 TDM-Transistor（基于 2DFETs/BSIM-CMG 的 2D 晶体管解析模型，扩展 trapped charge 模型与 self-heating 模型）和 TDM-Memory（基于修改版 CACTI 的 cell/array 模型，扩展 gate capacitance/quantum capacitance 模型、无结电容的 drain capacitance 模型、Schottky contact resistance 模型与 variability 模型，实现 1T1C 和 3T0C DRAM cell）组成，输出访问延迟、动态/静态能量与面积参数；(2) 在 gem5 的 AMD MI300X GPU 模型上扩展 DRAM cache 组件，表征 2D-material cache 的周期 refresh 行为；(3) retention-aware policy 含三个机制——refresh scheduling（按径向 retention 梯度把边缘行设为 0.5s 刷新、中心行延长到 1.5s，边缘 tier 保留为 clean ways）、cyclic replacement（把行最左/最右弱 retention tier 合并为循环 cache way，减少 clean ways 开销，tag 严格映射到非循环 way）、hot-page remapping（PHT 表 + Index Location Judge + Range Scalar 把 hot page 从 HighRef sets 重映射到 LowRef sets，PHT 计数器每 10K 次访问减半老化）。
  - 实验比较：在单 XCD（40 CU）MI300X CPU-GPU 异构系统上评估 9 种 LLC 配置——Si SRAM 32（baseline）、Si SRAM 128/512（超出面积预算、仅作性能参照）、Si 1T1C 128、2D 3T0C 32、2D 1T1C 128（基准 2D cache）、2D 1T1C 512、2D 1T1C 128 RA（retention-aware）、2D 1T1C 128 RF（refresh-free 上下界）；比较指标为 workload speedup、access interference rate（映射到正在刷新 bank 而无法服务的请求比例）、总 cache 能量（静态+刷新+动态）。12 个 workload 来自 Pannotia、Rodinia、AMDSDK、Llama、MLPerf。关键结果：2D 1T1C 128 平均 speedup 28.8%、能耗较 Si SRAM 32 降 77.8%；retention-aware policy 使系统性能再 +13.3%（refresh scheduling +8.7%、cyclic replacement +0.9%、hot-page remapping +3.7%）、refresh energy 降 65.4%、访问干扰率降 75.6%；相对 Si SRAM baseline 最终性能 +42.1%、总能耗 -79.4%；与 TDRAM [63] 结合再 +5% 性能、-15.6% 能耗。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - gem5（https://www.gem5.org/，https://github.com/gem5/gem5）：周期精确全系统模拟器，论文在 KVM 模式下运行 CPU 以加速、挂接详细 GPU 模型（AMD MI300X 架构）经 PCIe 互连；系统启动 OS 并运行真实 GPU workload。
  - CACTI（https://github.com/HewlettPackard/cacti）：TDM-Memory 的 baseline，被修改以支持 2D-material cell/array 建模。
  - 2DFETs/BSIM-CMG（https://bsim.berkeley.edu/models/bsimcmg/）：TDM-Transistor 的 baseline 解析模型。
  - Hspice（Synopsys 商业工具）：大容量阵列参考验证。
  - TDMSim 本身：论文声明"will be released as open source"，但论文未给链接；联网搜索（2026-08）未找到公开仓库（仅有无关的 hansemandse/tdmsim TDM 网络模拟器），无法确认开源地址。
- 模拟器模拟什么的性能，修改了什么。
  - gem5 模拟 CPU-GPU 异构系统的全系统性能（含 OS 启动、真实 workload 执行到完成），统计访问与 refresh 行为，并组合 TDMSim 提供的访问延迟/动态能量/静态能量参数推导系统级性能与 cache 能耗。修改点：在 gem5 MI300X 模型中新增 DRAM cache 组件，准确表征 2D-material cache 的运行行为（含周期 refresh 操作）；系统按单 XCD 配置（40 CU、1 GHz、L1 32KiB/55 周期、L2 4MiB/100 周期、LLC 32MiB/200 周期、2 HBM3 stack 660GB/s）并把 HBM stack 数与 cache 容量按比例缩放。
  - TDM-Memory（修改版 CACTI）：按指定 memory type 与 TDM-Transistor 参数做电路级设计空间探索，选 cell 技术并输出能耗/访问延迟/面积。修改点：(1) 新增 gate capacitance 模型（oxide+quantum 串联 + fringing + overlap + poly 线电容，式 4）；(2) 新增 bitline drain capacitance 模型（排除 junction 电容，仅 fringing/overlap/metal，式 5）；(3) 新增 Schottky contact resistance 模型（R_sch ∝ exp(-V_gs)+exp(-V_gd)，式 6）集成进 bitline RC 网络；(4) 新增 variability 模型（按 cell 在阵列中的位置配置不同晶体管参数，边缘访问延迟更长，静态功率按配置分布加权）；(5) 更新 3T0C 与 1T1C 的 decoder/driver 设计（3T0C 的 decoder 多一个输入、driver 数量翻倍，因读写晶体管分离）。
  - TDM-Transistor：输入 process/temperature/voltage 参数，输出 2D 晶体管固有特性（I-V 特性、off-current 等）。修改点：加入 trapped charge 模型（Q_t 项，式 1-2，表征 e-beam 蒸发 seed layer 引入的界面陷阱对电容/Vth/亚阈值摆幅的扰动）与 self-heating 模型（R_TH = R_TH0/W + R_TH1/√W，式 3）。

  - 使用例子（输入到性能输出的全过程）：① 输入 TDMSim：process/device 参数（CVD MoS2/sapphire、30nm 沟道、130nm CGP、top-gate、HfO2 栅介质、Au 电极）→ TDM-Transistor 输出 Id-Vg/Id-Vd 特性与 off-current（~10^-17 A/μm @330K）；② 该参数传入 TDM-Memory：按 32MB SRAM 面积预算做 cell/array DSE（1T1C vs 3T0C vs 6T-SRAM），构建最优 cache 组织（LHcache 结构 [51]、16-way、16 bank、单 DRAM row 为一组、部分 way 存 tag）并输出访问延迟/动态能量/静态功率/面积（如 2D-1T1C 在 32MB SRAM 面积下可达 512MB，128MB 时延迟仍与 SRAM baseline 相当）；③ 把延迟/能量参数与 retention 特征（径向 retention 梯度，cell retention 10s-700s，baseline 刷新周期 0.5s≈20× 安全裕量）传入 gem5 MI300X 单 XCD 模型：加载 OS + 12 个 GPU workload（Pannotia/Rodinia/AMDSDK/Llama/MLPerf），gem5 按 DRAM cache 组件统计访问/刷新事件与行缓冲行为（tag 访问先 activate+read 载入整行到 row buffer，命中则保留 row buffer 防关闭）；④ 输出：workload speedup、access interference rate、cache 总能量（静态+刷新+动态，用 TDMSim 参数折算）→ 得 9 配置对比（Fig.10/11）与 retention-aware 消融（Fig.14）与 TDRAM 结合分析（Fig.15）。原理：TDM-Transistor/TDM-Memory 把 2D 器件物理（量子电容、Schottky 接触、低泄漏、径向 retention 非均匀）折算成 CACTI 式电路级延迟/功率参数，gem5 再把 refresh 调度与 cache 管理行为放大到系统级性能与能耗，实现 device→circuit→system 三层联动。
