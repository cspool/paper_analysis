## EVA: Accelerating LLM Decoding via an Efficient Vector Quantization Architecture

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现为面向 VQ LLM decoding 的专用加速器 EVA（systolic-array based，算法-硬件协同设计）：①混合精度可重构脉动阵列——32×32 INT8 PE（prefill/attention）可动态重配为 32×8 FP16 阵列（VQ-decoding）：FP16 乘法分解成 4 个 INT8 乘法（1 符号位+5 指数位+10 尾数位），加 6-bit 加法器与若干 XOR 处理指数/符号，FP16 加法前插 alignment 单元并复用 INT32 累加器，避免独立 FP16 乘法器；②Epilogue Unit（EU）——每 EU 32 个加法器，做冲突无关查找（从 OC 按 WI 取 FP16）+ add-only 归约：垂直 32 输入加法树（单码本）或对角累加（多码本 C0-C3 输出级并行），无乘法器；③tiling 策略——input（v×d=32×8）与 WI（v×N）从 DRAM 流式载入，WC 与 output 片上静止复用（WC 只读，output 渐进更新）；④片上 buffer 528KB（16KB WC + 256KB weight + 32KB input + 192KB OC + 32KB output），4 个 EU，DDR4 8Gb×8 2133R 4 通道×16GB/s=64GB/s；⑤GEMM-EU 流水重叠（VQ-GEMM 256 cycles vs EU 4096 cycles，EU 是关键路径），多 batch 复用同一 weight tile。实验比较：与 SA、ANT、FIGNA、FIGLUT 四个 baseline 在 LLaMA/MoE 模型上对比延迟、能量、面积、功耗、吞吐（Table VIII：EVA 1.414mm²/3.117W/498.49 GOPs=31.64×SA/352.54 GOPs/mm²/159.94 GOPs/W）；单 batch FC decoding EVA-A16W2 相对 SA/ANT/FIGNA/FIGLUT 分别 31.56×/32.53×/33.50×/11.17× 加速、能效 12.48×/15.96×/14.96×/7.17×（Fig. 10）；EU 数量 DSE（4 个最优，再增仅增能耗，EU 面积开销 3.5%，Fig. 8）；batch scaling（bs>32 后 EVA-A8W8 反超 A16W2，Fig. 11）；端到端 Dolly（decode-heavy，平均 8.20×-24.49× 端到端，Fig. 12）、Arxiv/GSM8K MoE（Fig. 13）；冲突消除与 OC 维度折叠分析（Table X：EU-32×4 达 64.84× speedup）。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 自研仿真器，基于已验证的开源 ANT 模拟器（https://github.com/SJTU-ReArch-Group/ANT_MICRO22，Apache-2.0）构建；所有 baseline（SA/ANT/FIGNA/FIGLUT）集成进同一模拟器对比。硬件设计（EVA 与全部 baseline）用 Verilog HDL 实现，Cadence Genus + TSMC 28nm @ 500MHz 综合测面积/功耗；SRAM buffer 用 Cacti 7.0（https://github.com/HewlettPackard/cacti，28nm）建模；DRAM 功耗用 DRAMsim3（https://github.com/CMU-SAFARI/DRAMsim3）模拟。
- 模拟器模拟什么的性能，修改了什么。
  - 模拟 EVA 与 baseline 在 dense（LLaMA-1/2/3）与 MoE（Mixtral-8x7B、Qwen3-30B-A3B）LLM 上的 latency（cycles/s）、energy（J）、power（W）、area（mm²）、throughput（GOPs）、speedup；覆盖解码 FC 层（batch=1 起）、prefill、attention、special function 层与端到端场景（Dolly/Arxiv/GSM8K，各 100 samples），输出 CSV 到 simulator/output/。修改：在 ANT 模拟器上实现 EVA 的混合精度 PE、EU 查找/归约、tiling、多 EU 扩展与 batch reuse，并集成四个 baseline 架构与 VQ 配置（d/n/C/EU 数 DSE），DRAM 带宽固定 64GB/s @500MHz。

  - 开源：是。https://github.com/dbw6/Eva.git（MIT）、Zenodo DOI 10.5281/zenodo.19433707、HF collection dbw6/eva。模拟器输入→输出：输入 = YAML study 配置（simulator/configs/studies/，指定 models/methods/sequence lengths/batch sizes/study 参数，CLI 可 --models/--methods/--scenarios 覆盖）+ 预处理 trace（模型结构、量化配置、访问模式）→ 模拟器按 500MHz/64GB/s 配置逐阶段建模：DRAM 流式读 input tile（v×d=32×8）与 WI（v×N）→ 32×8 FP16 PE 阵列做 VQ-GEMM（256 cycles）产出 OC → OC 直接片内送入 4 个 EU 做冲突无关查找 + 加法树归约（每 EU 32 加法器处理 32×8/C=128 权重元素）→ 与下一 GEMM tile 重叠（GEMM-EU 流水）→ output tile 写回 DRAM → 输出 latency/energy/throughput 等 CSV → notebook（notebooks/hardware_results.ipynb）渲染成论文 Fig.8-14/Tables III,VIII-X。作用：验证 EVA 相对四个 baseline 的延迟/能量/面积/吞吐优势，以及 EU 数量、VQ 参数（n/C/d）、batch 大小对性能的影响；Table X 显示冲突消除+OC 查找使 SRAM 存储/带宽需求降 8×（d=8→1），EVA EU-32×4 配置 64.84× speedup，归一化阵列面积仅 1.18×。
