## Shining Light on Silicon Photonic DNN Accelerators

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现：对三类 SiPh DNN 加速器拓扑——MRM 微环调制器型 [6][15][18]（向量×矩阵：操作数-I 向量经 TX 高速编码广播到 Ny 条输出 lane，操作数-II 矩阵由各微环低速调制器编码，每个微环内做乘法、光电二极管跨 λ 做加法）、MZM 马赫-曾德尔调制器型（Albireo [10]：MZM 高速调制跨所有 λ 做乘法，特定 λ 经微环滤波后在 PD 相加）、DC 定向耦合器交叉阵列型（Lightening [13]：矩阵×矩阵，激光 2N-way 分裂后双操作数高速编码，交叉点 DC+PD 做点积）——做全链路模拟信号完整性分析：E/O 与 O/E 非线性、ISI、光域 MAC 眼高损失（新机制）、系统级光损耗预算、激光功率与波导功率上限，并在 iso-throughput/iso-accuracy 下与数字 DNN 加速器对比能量。实验比较：(1) 眼图（眼高/眼宽）vs TX 驱动带宽（5~40 GHz）与时钟频率（5/10 GHz）；(2) DNN 精度 vs 阵列尺寸（32×32~256×256）在 ISI（5/10 GHz 驱动）与噪声下；(3) 光损耗预算 vs 阵列尺寸（4×4~128×128：MRM 型 >21dB、MZM 型 >22dB、DC 型 27dB(4×4)→44dB(128×128)）；(4) 能量/MAC vs 阵列尺寸（5 GHz、4-bit：16×16 MRM ≈3pJ、128×128 ≈900fJ）并与数字 5×(16×16) MAC 阵列（<150fJ/MAC）对比；能量计算与 DEAP/Albireo/LT/OC 先前工作的 6.5% 内验证。
- 硬件平台是什么，配置是什么。
  - 无真实硅光芯片：Cadence Spectre 光电瞬态仿真 + 光功率追踪（loss budget）+ 自建解析能量模型。配置（'Ours' 列 Table-IV/Table-V）：时钟 5/10 GHz，MAC 精度 3/4-bit，波长 8-128，MRM Cmod 40fF（器件 20fF + 封装 20fF）、MZM Cmod 415fF，Vswing 2V，激光 WPE 10-20%（乐观假设 15% 跨 λ 维持），激光功率 <20 mW/λ，SiN 波导损耗 0.03 dB/cm、功率上限 200 mW，调制器偏置损耗 3dB + 2dB 裕量，光电二极管响应度 1.2 A/W，heater 2.8 mW（undercut 衬底 + 行共享，比需 heater 的先前工作省 >9×），4-bit 线性 TIA 85.2 mW [58]、ADC 5.5 mW（5GHz [87] / 10GHz [88]）、线性 TX 4.16 mW，非线性补偿 k=3 位（16nm CMOS 综合），ISI 用 1-tap FFE 均衡（10GHz）。器件损耗取最低：Y-branch 0.05dB、edge coupler 0.6dB、MRM 1dB、MZM 2.8dB、DC 0.06dB、微环谐振器 0.01dB。
  - 数字 baseline（Table-V）：16nm CMOS 综合 5×(16×16) 4-bit MAC 阵列 @1GHz，输出驻留（output-stationary）数据流，multicast 互联（Eyeriss [90]）+ partial-sum 归约互联，面积 0.25mm²，<150fJ/MAC（外推 7nm 与 77fJ [105] 一致），SRAM/DRAM 带宽 720 GB/s 匹配 2.56 TOPS 吞吐；SRAM/DRAM 能量不计以隔离计算能量。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - Cadence Spectre：商用模拟电路仿真器（EDA，非开源），用于光电瞬态仿真生成眼图；调制器模型来自 45nm 光电一体化 CMOS PDK（GF 45CLO，[72]，经 CMC 微系统/Intel 大学计划提供，受控访问）。瞬态仿真 >10^5 时钟周期捕获 ISI，调制器本征带宽 >35GHz。
  - 光功率追踪器（optical power tracker [18]，Al-Qadasi et al., "Scaling up silicon photonic-based accelerators"）：论文采用其 loss budget 方法，未给出工具链接，论文未明确说明是否开源。
  - 能量模型：自建解析模型——TX 驱动功率 Pdrv = ½(α·f·Cmod·Vswing²)（Eq.5，toggle rate α 按多比特修正 [98]），非线性补偿逻辑 16nm 合成（5GHz，10GHz 时双块时间复用），激光功率由损耗预算 + 眼高损失 + 目标 SNR 反推。
  - 综合工具：16nm CMOS 标准单元综合非线性补偿逻辑与数字 baseline MAC 阵列（论文未指明具体 EDA 工具名称）。
- 模拟器模拟什么的性能，修改了什么。
  - Spectre 瞬态仿真模拟电光链路的时域波形：数字串行器 → 调制器驱动（带宽受限；理想线性或带非线性）→ MRM/MZM 调制 → 波导传输 → 光电二极管 → 线性 TIA → 采样，叠加 UI 窗口生成眼图（眼高/眼宽）。据此量化：非线性导致的不等距光平与 '0'/'1' 光平合并（Fig.9）；ISI 导致的眼宽收窄（t_width = 2×Qerror-rate×t_n,rms，2ps rms 时序噪声 @10^-12 需 >28ps 眼宽；5GHz 时钟需 TX 带宽 >12.5GHz、10GHz 4-bit MAC 需 >40GHz）；光域 MAC 眼高压缩（新机制：多组输入-权重组合同一输出值，如 4-bit 输出 '2' 可由 14 组 (input,weight) 组合产生，压缩 '2'/'3' 判决裕量；眼高损失 3-bit 8.45dB / 4-bit 11.76dB）。修改点：无既有加速器模拟器被修改——整条链路为论文组合的商用 EDA + 解析模型，无 RTL/性能模拟器。
  - 输出到性能的转换：眼宽不足时提取输出条件分布（高斯拟合，Fig.13/14）作 ISI 噪声模型 → 注入 DNN 评估精度（Fig.15：5GHz 驱动 >5% 精度损失、32×32 阵列 >50%；10GHz 驱动仍有至 9% 损失）；眼高损失 + 损耗预算输入光功率追踪器 → 求所需激光功率/λ（MobileNetV2 >35mW/λ、ResNet50 ≥20mW/λ 达 1% 内精度；受 SiN 波导 200mW 上限约束仅 16×16 MRM / 8×8 MZM 达标、32×32 允许 5% 损失）→ 汇总激光/TX/RX/heater/ADC 得能量/MAC。

  - 开源情况：论文未声明开源其评估流程；Spectre 与 45CLO PDK 为商业/受控访问（CMC、Intel 大学计划），无法公开复现。复现需要：Cadence Spectre + 45nm 光电 PDK 瞬态仿真（输入：时钟频率、驱动带宽、调制器偏置/ER、量化电平分布——仿真假设量化值均匀分布，因为 DNN 量化把集中零附近的激活搬移到各量化电平均匀分布；输出：眼图/输出分布），光损耗预算表（Y-branch 0.05dB、edge coupler 0.6dB、MRM 1dB、MZM 2.8dB、DC 0.06dB、波导 0.03dB/cm + 偏置 3dB + 裕量 2dB），DNN 评估脚本（PyTorch + hook 注入，见 算法pipeline 层条目）。
  - 原理与输入到输出全过程：① 输入 SiPh 拓扑（MRM/MZM/DC）+ 时钟/带宽/精度参数 → Spectre 逐周期跑 >10^5 周期瞬态仿真（量化值均匀分布激励）→ 输出眼图与眼高/眼宽；② 眼宽 vs 2×Q×t_n,rms 阈值判 ISI 是否可接受，不可接受则提取输出条件分布（高斯拟合）；③ MAC 眼高损失（photonic MAC + ISI，Fig.17）；④ 光功率追踪器：从激光经 splitter（MRM 广播 Nx-λ、DC 2N-way 分裂）→ 各调制器 → PD→RX 逐器件 dB 损耗累加 + 眼高损失 + 裕量 → 输出总损耗（MRM >21dB 等）→ 由 Pmin=2·SNR·In,rms/R（SNR 取 DNN 精度所需值，4-bit 线性 TIA 噪声 1.3μA）反推激光功率/λ；⑤ 总能量/MAC = (激光/WPE + TX(Pdrv+非线性补偿+FFE) + RX(线性 TIA+ADC) + heater)/(阵列吞吐)，先按不含补偿能量与 DEAP(92.9W vs 95W)/Albireo(22.8W vs 22.7W)/LT(14.1W vs 14.75W)/OC(3.4W vs 3.65W) 验证（<6.5%）→ 结论：纳入全部信号完整性补偿后，SiPh 加速器能量/MAC 比数字加速器高 >5×（iso-accuracy/iso-throughput：16×16 MRM ≈3pJ vs 数字 <150fJ，128×128 ≈900fJ 仍 6×）；16×16 达 <1% 精度损失的配置相对理想 baseline 能量 >100×；2GHz 时钟因激光摊薄减少能量/MAC 反而 2.4× 于 5GHz。
