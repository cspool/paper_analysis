## Transpiler-Architecture Co-Design to Curb Clifford Costs in Fault-Tolerant Quantum Computing

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现是 TACO 的资源-局部性驱动 FTQC 架构（Section IV-D/IV-E），把逻辑量子比特划分为 compute block 与 memory block 两类区域（同一 surface-code 衬底，仅逻辑角色不同）：compute block 托管频繁执行 π/4 旋转的量子比特，每个 π/4 site 同时暴露 X 与 Z 边（经 ancilla tile 连到 state distillation block），按旋转轴选择性激活，支持 Rz(π/4)/Rx(π/4) 及其逆 4 种旋转（magic state 注入符号概率性时用廉价 Clifford correction 恢复），每 compute block 用 4 个逻辑 qubit tile（2 个 π/4-site 量子比特 + 2 个 ancilla）；memory block 采用三行紧凑布局（第 1/3 行逻辑量子比特、中间行 ancilla，来自 [51] 的布局，n 个逻辑量子比特只需 1.5n tile），经共享 ancilla 层支持任意两比特 CNOT 与本地 Hadamard；patch rotation 3 code cycles（1 扩 1 转 1 缩），qubit 在 memory↔compute 间转移 1 个 code cycle。distillation 侧：compute block 与多个 distillation unit 组成 super-block，围绕中央 memory qubits 分布（图 16），目标每 compute block 每 cycle 一个 magic state；通过模拟扫描 magic state 吞吐做 space-time volume 最小化（图 15：18 比特 QFT 最优 4 个 magic-state block，比单 block 体积降 57%）。
  - 实验比较：与两个 PBC 架构（[51] 的 Compact 1.5n+3 tile、Fast 2n+√(8n)+1 tile）做完整 FTQC 资源估计对比（Table II，20 比特 QFT）：TACO 29 data + 12 compute + 363 distillation = 404 tiles（MSD 协议；4 个 magic state/cycle 时）vs PBC Compact 41 / PBC Fast 170 tiles；QEC cycles 760,901（MSD）/595,604（MSC）vs 28,783,535 / 2,382,355；code distance 19 vs 21/19；物理量子比特/逻辑 tile 722 vs 882/722；总 qubit-cycle volume 2.2×10^11 vs 1.0×10^12 / 2.9×10^11，即相对 Compact/Fast 降 79%/24%（MSD）、95%/63%（MSC）。magic-state 吞吐灵敏度（Table III）：4/3/2 个每 round → 64.5k/47.6k/30.8k 物理量子比特、595k/760k/1.14M cycles，体积仍比 PBC Fast 低 2.7×/2.9×/2.99×。与 LSQECC 结合（Table IV/V）：greedy 路由 2.2×10^11 → LSQECC(EDPC) 1.33×10^11（再降 1.7×）；TACO 电路使 LSQECC lattice-surgery slices 从 123,139 减到 62,503（近 2×）。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 论文自研 cycle-accurate 模拟器（无独立名称/链接，Section V-B、VI-C-3）：逐层处理电路，本地操作直接执行，非本地门（CNOT）与 state-injection（T、S）路由到可用 compute block；默认 greedy routing（FCFS 先到先服务），并集成 LSQECC（https://github.com/latticesurgery-com/liblsqecc，其 EDPC edge-disjoint path compilation 流水线，因当前不支持 TACO 的 compute-site 布局故用默认 EDPC 布局）作为高级路由案例。资源估计方法遵循 [32,34,51]：物理量子比特 = 2*d² per 逻辑量子比特；逻辑错误率 p_L = 0.1(100p)^((d+1)/2)；code distance 由 total_tiles × total_cycles × d × p_L < 0.01 确定（物理错误率 p=10^-3）。
- 模拟器模拟什么的性能，修改了什么。
  - 模拟器模拟 FTQC 电路在 proposed compute/memory 架构上的执行：以 QEC cycle 为单位逐层推进，按逻辑门延迟计 cycle（Pauli 0 cost、CNOT/Hadamard 3d+4、S 1.5d+3、T 2.5d+4，基于 [7] 资源估计），跟踪 magic state 消耗/供应（15-to-1 distillation：11 个逻辑 tile、每 11 cycles 产一个 magic state、错误率 35p³=3.5×10^-8 @p=10^-3；MSC 为 magic state cultivation）、路由（greedy 或 LSQECC）、qubit 转移（1 cycle）与 patch rotation（3 cycles），最终输出 QEC cycles 与 tiles 数，两者相乘得 qubit-cycle volume。修改/配置：定义 compute block（X/Z 双边暴露、4-tile）、memory block（三行 1.5n 布局）、super-block（distillation 分组与分布）、magic state 吞吐参数（1-10 个/cycle 扫描求 volume 最优）、以及 PBC Compact/Fast 两个对比架构的资源模型。架构模拟器本身未开源，复现需按论文 IV-D/IV-E 自建；artifact 只覆盖转译侧。

  - 使用例子（模拟器输入到性能输出的全过程）：输入 = TACO 优化后的 Clifford+T 电路（QASM，含长 Rz(π/4)/Rx(π/4) 旋转序列）+ 架构参数（compute block 数量、magic state 吞吐、code distance、tile 布局）→ ① 电路逐层扫描，每层就绪门按逻辑门延迟计 QEC cycles（CNOT/Hadamard 3d+4、T 2.5d+4 等），本地操作直接执行；② CNOT 与 state-injection 经 greedy（FCFS）或 LSQECC（EDPC）路由分配 compute block 与 magic state，量子比特移入 compute block 1 cycle、patch rotation 3 cycles；③ 统计总 QEC cycles 与所需 tiles（data + compute + distillation），magic state 由 distillation 工厂（15-to-1：11 tiles/11 cycles/state，或 MSC cultivation）按吞吐模型供给；④ 按 p_L=0.1(100p)^((d+1)/2) 与 total_tiles×total_cycles×d×p_L<0.01 校核 code distance（TACO 因执行短只需 d=19，PBC Compact 需 21），物理量子比特 = 2d²/逻辑 qubit；⑤ 输出 qubit-cycle volume（QEC cycles × 物理量子比特）与逐吞吐配置的体积，对比 PBC Compact/Fast 得 79%/24%（MSD）、95%/63%（MSC）体积降幅。作用：在无真实量子硬件条件下把"电路层优化能否转化为端到端 FTQC 加速"量化为空间-时间体积，用于确定 distillation 工厂数量/吞吐（volume 最优配置）与 compute/memory 分区布局。
