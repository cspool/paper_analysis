## WaferBRAIN: Whole-Brain Scale Neuromorphic Architecture Based on Wafer-Scale Integration

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现是 WaferBRAIN 的 3D-WSI 神经形态计算架构（ISCA 2026，澳门大学 + 广东省智能科学与技术研究院），核心是 Neuron-Axon Hybrid Processing (NAHP) 通信范式 + NoC 路由器 + 存储层次的协同设计：
    - **NAHP 通信范式**：本地区域内神经元驱动广播（neuron-driven broadcast，mode=0，包只携带 LNid=<LNode, Neuron>，区域内路径复用）+ 跨区域轴突驱动单播（axon-driven unicast，mode=1，包携带 <POD, Wafer, Node> 目标物理 ID 与 GAid，无冗余远场投递）。路由器按 0/1 模式位分类（Fig.7）：广播包用 router-local SRAM 中按 LNode 索引的 5-bit {N,E,S,W,L} 端口掩码路由表（even/odd 源分别走列扩展/行扩展广播以平衡两维链路、单周期查表、无逐包在线路由决策、无死锁）；单播包同 wafer 走无表 mesh-XY（坐标比较器逐跳比较目标坐标），跨 wafer/POD 走 egress WC 选择 + 预规划确定性路由表。
    - **Region-Level Boundary Triggering**：跨区域单播只在区域边界节点发起（Algorithm 1：源节点 (i,j) 在 N×M 区域的 4 个边界候选 {(i,0),(i,M-1),(0,j),(N-1,j)} 中按到路由锚点 (i_a,j_a)（同 wafer 目标=目标节点、跨 wafer=所选 WC egress 节点）的最小曼哈顿距离选出唯一 owner，平局按字典序）。源节点只发区域内广播，边界 owner 持有该神经元的 axon-out 元数据并触发远程单播，两阶段（区域内广播 + 边界触发单播）共享区域路径、避免源附近单播热点；每个边界节点神经元放置减少 20% 并在区域内均匀重分布以容纳额外 axon-out 元数据。
    - **存储层次（wafer-native）**：热神经元状态（膜电位、refractory 标志、临时累加器）与每步事件队列放片上 SRAM；突触权重与 fan-in/out 元数据放 3D-stacked DRAM，按 NAHP 双寻址模式组织：本地（neuron-driven）布局按 LNid 索引 (L.Syn.Pointer, Fanout)、突触为连续 <DstNeuron, Weight> 邻接表；全局（axon-driven）布局为 Global Axon-out Index（源神经元 LNid → Axon-out.Pointer/Fanout）→ Global Axon-out 记录 <DstNode, GAid> → Global Axon-in 按 GAid 索引 (G.Syn.Pointer, Fanout) → Global Synapse 连续 <DstNeuron, Weight> 列表；每个 block 用紧凑 pointer/length 头 + 连续邻接表支持 coalesced DMA。
    - **BPU 节点**：4×4 BPU 阵列（每 die），每 BPU 含轻量 NoC 路由器 + 四模块——axon-in（摄取 AER spike 并做 3D-DRAM pointer/fan-out 查表）、dendrite（DMA 引擎拉取邻接表格式突触数据、按目标神经元 ID 分发到不同 FIFO、事件驱动异步并行累加突触电流）、soma（SRAM 神经元状态、膜电位更新、阈值触发 spike）、axon-out（查 axon-pointer/fan-out 表打包分发 spike、驱动 NoC unicast/broadcast）。
  - 实验比较：处理范式维度——NAHP vs neuron-centric（SpiNNaker/Darwin 风格，FNid 37bit 广播/组播）vs axon-centric（Loihi/Darwin3 风格，NodeID&FAid 46bit 单播）；互连维度——switchless dragonfly vs 2D mesh；集成维度——WSI vs PCB（PCB 按 Loihi：D2D 100ns、router 100Gbps）。指标：平均/峰值 router load（packet/s）、平均/峰值 traffic（bits/s，含 local/global 分解）、每步通信时延（1ms real-time 红线）、每节点存储与索引开销。
  - 结果：NAHP 平均流量降 2.6–300×、峰值流量降 2.5–140×（100B dragonfly 下相对 neuron-centric 300×、axon-centric 6.9×）；本地流量降 1.4–32×、全局流量降 1.3–360×；100B 下 1ms 界内可持续 firing rate 比 neuron-centric 高 14×、比 axon-centric 高 4.7×（NAHP 在 100B dragonfly 下最高 3.8% firing rate，两 baseline 在 ~1% 即破 1ms 界）；索引开销降 1.2–7,400×（扣除共享的 1.54GB/node 基线后）；dragonfly 比 mesh 峰值 inter-wafer 流量降 3.4–3.7×、峰值节点负载降 1.3–2.8×、可持续 firing rate 高 2.9×（3.8% vs 1.3%）；WSI 比 PCB 可持续 firing rate 高 13×（PCB 连 0.5% firing rate 都撑不住）。

- 模拟器模拟什么的性能，修改了什么。
  - 模拟器把神经形态系统建模为图 G=(V,E)（v_i=处理节点、e<v_i,v_j>=物理链路），在 1ms step 粒度评估三部分指标：
    - **Communication**：广播成本 L_b=|V_b|-1（neuron-centric 的 V_b=全部节点、NAHP 的 V_b=区域节点，故 NAHP 广播成本低）；单播成本 L_u=源到各目标节点跳距之和（axon-centric 由源节点注入、NAHP 由 Algorithm 1 选出的边界节点注入，减少跳数）；平均每节点路由负载 R=R_Local+R_Global（式 3-5，λ=firing rate）；流量 T=R_Local×W_L+R_Global×W_G（式 6，W_L/W_G 为本地/全局包宽——NAHP 用 LNid 27bit 比 FNid 37bit 少 10bit、GAid 33bit 比 NodeID&FAid 46bit 少 4bit）。
    - **Storage**：S_total=S_neuron+S_synapse+S_index（式 7-8），N=1.3–1.49×10^6 neurons/node（21bit）、F=256 fanout、B_n=64bit、B_s=16bit 权重+21bit 目标 ID=37bit → S_neuron=10.4MB、S_synapse=1.54GB/node；索引开销按范式不同——neuron-centric 每节点复制全局神经元目录（~2^37 条目、100B 下 TB 级）、axon-centric 存 fan-in 对应条目、NAHP 本地 2^27 LNid + 全局 2^23 GAid 分离。
    - **Latency**：Latency=T_max/Θ_router+δ_max（式 9：最拥塞路由器服务时间 + 最长路径传播延迟）；δ_max=L_n·H_n+L_d·H_d+L_w·H_w+t_r·(H_n+H_d+H_w)（式 10），L 与 t_r 用 Lyra X 原型实测值标定。
  - 修改/配置：实现三种范式（neuron-centric/axon-centric/NAHP）的数据结构与路由规则、mesh 与 switchless dragonfly 拓扑（WC/PC 通道、WC-to-NC sharding、预规划确定性路由、egress WC 选择）、WSI 与 PCB（D2D 100ns、router 100Gbps）两套集成参数、1B/16B/100B 三种脑模型映射（Table II：单 wafer / 4×4 mesh 与 14×1 dragonfly / 10×10 mesh 与 14×7 dragonfly），firing rate 从 0.1% 扫到 4.9%（0.2% 步进）。
