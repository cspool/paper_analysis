## ATX: Accelerator Task Extensions

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现为 Near-Core Accelerator (NCA) 范式 + ATX 指令集 + Unified Transfer Engine (UTE)，微架构/ISA 级设计（模拟器建模，无 RTL）。NCA 置于核 L2 旁（"goldilocks zone"），拥有独立内存读接口（专用访存硬件高 MLP 取数），只写核寄存器、任务无状态，可被推测/乱序调用；ATX 指令对核表现为"长延迟 load"，输入寄存器携带 VAccId 与运行时常量元数据、输出写回核物理寄存器文件（PRF）；UTE 每核一个，由 VAcc→PAcc 映射与 VAcc→Streams 映射两块 CAM、InTaskQ、Stream Units（Repetition Initializer 用 Bounds ALU 计算 bexp、Mem/NCA Address Generator、Access Queue 做同缓存行合并）、LDQ、Stream Scheduler（age-based + round-robin）、Common Bus（128B data + 32B addr）、PAcc Port、PDQ、OutQ 及 Task Predictor/Prefetcher（stride 预测未来任务的运行时常量，Assisted 与 Predicted 两种任务预取）组成。双缓冲：每 NCA 2×32KB 输入 scratchpad；输出最多 2 个 1KB tile 寄存器（任务输出上限 2KB）。核流水线新增 ATX 执行端口、16-entry ATX Queue 与 ATX Reservation Stations。
  - 实验比较 4 种对照：(1) 纯 CPU（Core，MKL/TACO/libxsmm + AVX512/AMX）；(2) perfect ICA（计算零延迟、数据经核通用访存硬件供给）；(3) L2-attached OCA（RoCC 式指令控制、不可推测执行、带 UTE 流支持的优化 out-of-core 访存接口）；(4) LLC-attached OCA（load/store 控制、同带 UTE 流支持）。指标：各 kernel 加速比、周期 memory-bound/core-bound 分解、roofline（Giga Vector Ops/s）、任务尺寸敏感性（scratchpad 8–128KB）、预取机制与预取距离消融、UTE 设计空间探索（#Stream Units / LDQ entries / CB 宽度 / PDQ 大小）+ CACTI 面积/功耗、解压用例压缩因子扫描。
- 硬件平台是什么，配置是什么。
  - 模拟平台：Sapphire Rapids-like（SPR / Xeon Max with HBM）服务器——1 socket、64 核、2.5GHz、AVX/AMX 支持；缓存 48KB L1、2MB L2、1.875MB LLC/core；内存 DDR 1TB@270GB/s + HBM 64GB，HBM 带宽放大到 4TB/s 对齐 H200 等解耦加速器平台；L2 MSHR 放大到 128 消除 MLP 限制；L1/L2 空间预取器为硅片验证过的行业级实现。UTE：每核 2×32KB/buffer 双缓冲、32 个 Stream Units、128-entry LDQ、每 Stream Unit 1KB PDQ，默认只开 Predicted Task Prefetching。加速器模型：SpMM/SDDMM（SPADE-like 算术单元，64 个合计 5.1 DP TFLOPS）、GeMM（8×8 µtile 双精度单元，64 个合计 20.5 DP TFLOPS）、ML 权重解压（DECA-like，W=64, L=16）。
- 模拟器名，模拟器链接（web search），或论文修改的模拟器。
  - 内部 silicon-validated 多核 CPU 模拟器，基于开源 Sniper（https://github.com/sniper-sim/sniper）扩展；论文扩展 NCA/ICA/OCA/ATX/UTE 模型部分未给出开源链接，论文未明确说明是否公开。
- 模拟器模拟什么的性能，修改了什么。
  - 模拟 SPR 服务器上 SpMM/SDDDMM/GeMM/ML 解压四种 kernel 在 Core/ICA/L2 OCA/LLC OCA/ATX NCA 五种配置下的执行周期与加速比、memory-bound vs core-bound 周期分解、roofline 位置；CACTI + 缩放方程估 UTE 面积/功耗（64 UTE <1% SPR die 面积、4.37% SPR 350W TDP）。修改点：在 Sniper 基座上新增 NCA/ICA/OCA 与 ATX 指令/UTE 模型（InTaskQ、Stream Units、LDQ、Common Bus、PDQ、Task Predictor 等）、核内 ATX 执行端口与 ATX Queue；L1/L2 预取器用硅片验证的行业级模型；HBM 带宽与 L2 MSHR 数量做了放大。
- 开源情况。基于开源文档和论文，使用例子解释模拟器如何使用？作用是什么？至少具体到模拟器模拟性能的原理和模拟器输入到性能输出的全过程。
  - 基座 Sniper 模拟器开源（interval 仿真 + 微架构细节模型）；ATX/UTE/NCA 模型为 Intel 内部 silicon-validated 扩展，未给开源链接。软件栈全部公开：MKL、TACO（http://tensor-compiler.org）、libxsmm（https://github.com/libxsmm/libxsmm）、OpenMP、SuiteSparse。
  - 模拟原理与全过程：输入 = kernel 二进制（SpMM/SDDDMM/GeMM/解压；ATX 侧为 C/C++ 小库 + 内联汇编手写 kernel，如 ATXV1V1）跑在 Sniper interval 核心模型上。ATX 指令在核内按普通 load 一样 rename/issue（ATX Queue + Reservation Station + ATX Port，输入寄存器就绪即可乱序发出，无需到 ROB 头）→ 进入 UTE InTaskQ → PAcc/Stream Unit 分配（VAcc→PAcc、VAcc→Streams CAM 查表）→ Stream Units 按 bexp 生成内存地址（父流数据经 PDQ 驱动子流边界，支持 CSR 式间接寻址/指针追逐）→ Stream Scheduler 仲裁 → LDQ 向共享 L2 发读（复用核 L2 TLB/MMU 虚拟地址翻译，L1 dirty 线由现有一致性机制供数，L2 miss 走现有访存路径）→ Common Bus 把数据写入 NCA 32KB scratchpad 双缓冲 → 数据齐后启动 NCA 计算 → 输出进 OutQ → 经 ATX Port 写回核 PRF 寄存器 → 指令在 ROB 头提交；错预测时核通知 UTE 中断任务、清 scratchpad、释放 PAcc/Stream Unit。Task Predictor 用 stride 算法从相邻两任务的运行时常量提取步长、按预取距离 N 预测第 N 个未来任务并以 prefetch mode 提前派发（仅取 leaf 流数据到 L2）。输出 = 加速比（ATX NCA vs Core 2.7–4.0×、vs ICA 1.3–2.3×、vs L2 OCA 1.4–3.9×、vs LLC OCA 2.6–18×；解压用例 vs Core 4.0×/ICA 1.8×/L2 OCA 3.9×/LLC OCA 18×）、周期分解、roofline 点、UTE 设计点性能/面积/功耗（默认 UTE {32,128,128B,1KB} = Inf UTE 80% 性能、0.90% die / 4.37% TDP；Small {8,32,64B,256B} = 0.53%/3.64%；Inf {64,512,512B,4KB} = 2.71%/9.17%）。
