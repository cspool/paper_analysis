## Unlocking Pipeline Parallelism for Bootstrapping: A Pipelined Multi-Chiplet TFHE Accelerator

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现是 CASCADE，一个多芯粒流水线 TFHE 加速器（ISCA 2026，中科院计算所）。核心硬件实现：把 TFHE 可编程自举（BSP）中 n 次串行 HMUX（盲旋转，Algorithm 1 第 4-6 行）迭代改为跨 HMUX 的流水线并行执行。每个 HMUX Chiplet（HC）实现一个流式 HMUX 数据通路，由 Rotation Unit（negacyclic rotation + 多项式减法）、Decomposition Unit（位分解，(k+1) 个多项式 → (k+1)×l 个多项式）、FFT Unit（log2N 级 butterfly，BU 个并行 butterfly 单元，基于 [26] 的 conflict-free 地址生成）、VMA Unit（FFT 域逐系数乘加实现外积）、IFFT Unit 组成，全部深度流水，一次完整遍历 = 一个 HMUX。两级细粒度流水：Intra-HC PCG pipeline（多项式系数粒度流式传输，系数算完即送下一单元）与 Inter-HC PCG pipeline（上游 HC 算完一个多项式系数即经 D2D 送给下游，不等整个 RLWE 完成）。BSK-stationary、RLWE-flowing 数据流：每个 HC 私有 SRAM 驻留部分 BSK，中间 RLWE 密文在 HC 环形拓扑中流动。HC0 额外集成 VPU（Vector Processing Unit）做 key-switching、sample extraction、同态加法等轻量操作。每 HC 集成 11.5 MB SRAM（10.5 MB BSK buffer + 768 KB 局部 buffer + 128 KB 输入 + 128 KB 输出 double buffer，HC0 为 12 MB 加存 KSK），double buffer 隐藏 D2D 时延。评估：实现一个 HC 的 RTL，用 Synopsys Design Compiler + TSMC 28nm 库综合，时钟 1.2 GHz，得面积 92.5 mm²、TDP 29.91 W（HC0 加 VPU 额外 60.1 mm²/13.8 W），12 HC 全系统 1170.1 mm²/372.72 W。
  - 实验比较：微基准 bootstrapping 稳态吞吐/时延对比 CPU（Concrete，Intel Xeon Platinum 8275 3.0GHz）、GPU（NVIDIA A100 2.4TB/s，nuFHE/cuFHE）、FPGA（FPT）、TFHE ASIC（MATCHA/Strix/Morphling，均配 HBM，按相同工艺节点/频率归一化）。参数集 I/II/III（Table I：n=500/N=1024、n=600/N=1024、n=592/N=2048，128-bit 安全级）下 CASCADE 时延 0.01/0.02/0.04 ms，吞吐 2,133,624/1,235,248/416,408 BSP/s（Morphling 为 147,615/78,692/41,850）。应用基准（DeepCNN-20/50/100、XG-Classifier、Encrypted-AES、VGG-9 CIFAR-10）上平均 2201.5×/770.6×/229.2×/129.4×/48.5× 相对 CPU/GPU/MATCHA/Strix/Morphling 加速；Speedup/Area 30.5×/15.6×/3.1×，Speedup/Power 22.3×/16.4×/5.2×。硬件利用率 91.03%-97.18%（XG-Classifier/AES/VGG-9）。消融：Monolithic Design（单 chiplet + HBM3、无流水/无 intra-HC batching、串行）→ CASCADE w/o OIFS（细粒度流水，naive 交错）13.2× → 加 OIFS 再 4.1×，总 53.5×。DSE：C=12、IP=256（VMA 单元硬件并行度 = 内部 BSK SRAM 带宽）最优。

- 模拟器模拟什么的性能，修改了什么。
  - 模拟器建模每个 HC 内各功能单元（Rotation/Decomposition/FFT/VMA/IFFT）的微架构行为与 D2D 通信，以 cycle 为单位测量执行时间。模拟器集成了提出的 Offline Interleaved-Fusion Scheduler（OIFS）：从输入 TFHE 应用构建 BSP 级计算图（同层 BSP 可并行、跨层不可并行），用 Interleaved-Fusion Cost Model（IFCM：T_task = T_run + T_bubble，T_run = ⌈B/bs⌉·Σ_t Σ_c T_exe(t,c)，T_exe(t,c) = max(T_comp×|f(t,c)|, T_comm)）与 DP 算法（状态 DP[j][r] = 前 j 个 HMUX 用恰好 r 个融合组的最小 T_run；剪枝：最大融合粒度 S_max、最小组数 k_min=C）求最优二维时空映射矩阵 f(t,c)，跟踪 BSP 间数据依赖与通信，输出总执行时间（Pipeline Run Time + Bubble Time）、HC 资源利用率、D2D 带宽利用率。
  - 修改/配置：实现 HMUX 流水线微架构（PCG 粒度、BU 并行 butterfly、FFT 控制器 conflict-free 地址生成）、12 HC 环形拓扑、UCIe 16 GT/s D2D 时序、双缓冲、BSK-distributed SRAM 层次；对比三种映射策略（OIFS / Segmented HMUX Mapping SHM / Fixed-Fusion Mapping FFM）；模拟输出 Table III（吞吐/时延）、Table IV（利用率）、Table V（时延分解）、Fig.12-18。

  - 使用例子（模拟器输入到性能输出的全过程）：输入 = TFHE 应用（DeepCNN/XG-Classifier/AES/VGG-9，参数集 I-IV：n/N/L/k 配置）+ CASCADE 架构配置（C=12 HC、IP=256、每 HC 11.5 MB SRAM、UCIe 16 GT/s 1024 Gbps D2D）+ BSK/KSK 密钥。① OIFS 解析应用构造 BSP 计算图，统计可并行 BSP 数 B 与系统 batch size bs = C×intra-HC batch；② 用 IFCM+DP 求最优 f(t,c)：把 n 个 HMUX 划分为可变大小融合组、按 t mod C 循环交错映射到 C 个 chiplet，T_exe(t,c)=max(T_comp×|f(t,c)|, T_comm) 权衡本地计算时间与 D2D 时延，最小化 T_task；③ 模拟器按 cycle 推进：每 HC 的 Rotation→Decomposition→FFT→VMA→IFFT 流水线处理系数流，HMUX_i 的 ACC 输出经 128 KB 输出 double buffer 由 D2D（环形拓扑）传给下游 HC（同 chiplet 融合组内则回馈本地输入再执行下一 HMUX），BSK 从本地 SRAM 读取、无片外流量；④ 统计 Pipeline Run Time/Bubble Time，输出总执行时间、HC 利用率与 D2D 带宽利用率。作用：在无真实流片条件下，把"跨 HMUX 流水线并行 + BSK 分布式 SRAM + Interleaved-Fusion 映射"三项设计对吞吐的贡献量化为 cycle 级时延与利用率，验证 CASCADE 相对集中式 HBM 架构（Morphling）在面积/功耗归一化下的优势，并指导 C/IP/BSK SRAM 容量的设计空间探索。
