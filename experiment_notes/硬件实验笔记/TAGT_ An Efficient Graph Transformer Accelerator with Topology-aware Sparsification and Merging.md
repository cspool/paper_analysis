## TAGT: An Efficient Graph Transformer Accelerator with Topology-aware Sparsification and Merging

- 属于硬件架构的实现是什么？实验比较什么？
  - 实现为 TAGT 加速器（Xilinx Alveo U280 FPGA 上 RTL 实现），面向图 Transformer 推理的拓扑感知加速器，由 Topology Data Loader (TDL)、TDS Construction Unit (TCU)、Task Dispatcher、Graph Transformer Processing Unit (GTPU) 与 Specific Computing Unit (SCU) 及多组片上 buffer 组成。核心硬件创新：(1) 数据驱动的加载与合并引擎（DDLM）——TDL 的 Memory Access Pipeline Engine (MAPE) 用多个 6 级硬件流水线分阶段取数（Fetch_Root/Fetch_Offsets/Fetch_Neighbors 从 CSR 结构定位目标顶点邻域，Fetch_Features/Fetch_Weight/Fetch_Coding 取特征向量/模型权重/结构嵌入），复制 Fetch_Neighbors 与 Fetch_Features 单元掩盖 HBM 延迟；TCU 内含 Feature Update Unit（FUU：同步取原始特征与编码向量、轻量拼接、线性投影生成基层级叶子嵌入，对 SE/PE 语义无关、只按输入维度适配）与 Merge Operation Unit（MOU：多级并行加法树做高扇入聚合计算全部 fusion/associated 顶点嵌入，并内置硬件去重——查 TDS-CSR Table 跳过已算过的共享 fusion 祖先，只算一次）；Task Dispatcher 检查多个 pending task 的 Associated ID 列表，合并共享 Associated ID 的任务打包成单一数据请求发往 GTPU 实现一次 dispatch 服务多次注意力计算；(2) TDS 快速注意力单元（TBFA）——每个 Fast Attention Unit (FAU) 含 Update Processing Element（UPE，MM 运算：FFN 与原始注意力分数）与 Vector Processing Element（VPE，VM 运算：softmax 归一化后的 value 聚合）；UPE 算出的原始注意力分数流式送 SCU 而不物化中间注意力矩阵，SCU 做块级 softmax 归一化并把归一化部分贡献送 VPE 完成 value 聚合；可配置 Switch 在 FFN 阶段切换到 Reconfigured MM 模式把 VPE 的 MAC 资源并入 UPE 形成更大的 MM 引擎。(3) SCU 的块级异步 softmax——Block Partition Module (BPM) 把分数流切成固定大小块入 Input Queue，Element-wise Computing Unit (ECU) 并行算局部分子 O_j=Σ_{i∈S_j} e^{s_i-φ}·v_i 与局部分母 l_j=Σ_{i∈S_j} e^{s_i-φ}，带 {TID, IsFirstBlock, IsLastBlock, O_i, l_i} 标签发往 Reduction Unit（64 个 Core Reduction Unit 按 TID 标签 Comparator 并行匹配、Merge ALU 异步累加 O_accum/l_accum，IsLastBlock 时请求 Shared Divider Pool 做最终归一化 Output=O_final/l_final），消除全局 softmax 数据依赖导致的同步开销；Activation Unit 支持 ReLU 等非线性。片上缓冲（Feature/Weight/Partial/Output/TDS-CSR/Task FIFO）采用 ping-pong buffering 解耦不同操作隐藏访存延迟。
  - 实验比较：vs 软件 baseline——DGL-CPU（32 核 Xeon Platinum 8357B）175.4×（103.8×–282.6×）平均加速、217.2× 平均节能；TorchGT（A100）18.6×（9.4×–34.2×）平均加速、24.8× 平均节能。vs GNN 加速器——FlowGNN、MEGA、BingoGCN（把其框架改造成执行 O(N²) 全对注意力作为 worst-case dense baseline，保留各自原生优化如 MEGA 的 degree-aware 混合精度量化）：平均 8.2× / 6.9× / 4.7× 加速与 9.3× / 7.5× / 5.2× 节能。TDS 硬件协同设计使 off-chip 内存流量降 42.1%–81.6%（vs FlowGNN 78.3%–81.5%）。消融（Fig.14）：w/o DDLM → 平均 4.41× 加速（贡献 71.38% 总性能收益），w/o TBFA → 平均 2.48×（贡献 28.62%）。敏感性（Fig.15）：batch size 正相关（主实验固定 32）、序列长度在 512K 达峰后带宽瓶颈、FAU 数增加到带宽瓶颈后收益递减、超参 m 以 m=2 准确率最高。
- 硬件平台是什么，配置是什么。
  - Xilinx Alveo U280 FPGA 加速卡：XCU280 芯片，108 万 LUT、9MB 片上 BRAM、30MB UltraRAM、9,024 DSP slice、两个 4GB HBM2 stack（总带宽 460GB/s）；Xilinx Vivado 2019.1 综合，保守工作频率 280MHz。TAGT 片内存储：1MB Feature Mem + 1MB Weight Mem + 512KB Partial Buffer + 512KB TDS-CSR Table + 128KB Task FIFO + 128KB Output Buffer；计算资源（Table V）：16 FAU（每 FAU 256 UPE + 128 VPE）、8 FUU、8 MOU、1 SCU、共 4,096 MACs。资源利用率（Table IV，按 4 个模型）：DSP 73.6%–80.2%、LUT 40.1%–49.5%、FF 30.4%–35.2%、BRAM 59.3%–69.7%、UltraRAM 80.3%–89.7%。baseline 加速器配置（Table V）：FlowGNN 300MHz/747 DSPs/8 NT+16 MP units/5MB 片上/460GB/s HBM2；MEGA 1GHz/4,096 MACs/4×8×32 BSEs + 256 aggregation units/5MB/460GB/s；BingoGCN 300MHz/1,539 DSP-equivalent/1 combination+1 aggregation+1 CMO unit/4.5MB/460GB/s。

  - 使用例子（按论文描述的数据流全过程）：① 输入：CSR 格式图结构（顶点 offsets/neighbors）、顶点特征（D_feat=100–1000）、模型权重矩阵、SE/PE 结构编码向量，按序列 partition（如 D_0）送入 TDL；② TDL 的 MAPE 6 级流水线从 HBM/片上 buffer 取邻域/特征/权重/编码 → Construction FIFO Buffer；③ TCU：FUU 拼接特征+结构编码并线性投影生成叶子嵌入（写入 TDS-CSR Table 并流式送 MOU），MOU 多级并行加法树自底向上聚合全部 fusion 顶点（查 TDS-CSR 去重共享祖先、只算一次），TCU 控制逻辑组装 TDS 稀疏图结构（original/fusion/association 边）存入 TDS-CSR Table，并向 Task FIFO 填入紧凑任务描述符（Partition ID、Target ID、Associated List Pointer、Count）；④ Task Dispatcher 取描述符、按共享 Associated ID 合并打包成单个数据请求发往 GTPU；⑤ 16 个 FAU 仲裁分配子任务并行执行：UPE 算原始注意力分数流式送 SCU（UPE Private Registers 本地部分和累加），SCU 的 BPM 分段入队 → ECU 并行算局部分子/分母 → 64 CRU 按 TID 异步累加 → Divider Pool 归一化 → Activation Unit（如 ReLU）→ VPE 聚合 value 得目标顶点最终嵌入；FFN 阶段 Switch 切到 Reconfigured MM 模式（VPE MAC 并入 UPE）；⑥ 结果写回 HBM 或缓存到 Structure and Feature Buffer 供下一注意力层（跨 partition 的结果存 Partial Buffer、目标顶点特征留 Feature Buffer 防重复取）。全程注意力分数不物化矩阵，TDS-CSR 紧凑元数据+去重+ping-pong 缓冲最小化 off-chip 访问。输出到性能：端到端执行时间/带宽利用/off-chip 流量/能耗 → 归一化相对各 baseline 得加速比与节能（Fig.9-13）、消融（Fig.14）、敏感性（Fig.15）。
