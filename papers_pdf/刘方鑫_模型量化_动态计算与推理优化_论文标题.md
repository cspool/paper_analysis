# 刘方鑫：模型量化、动态计算与推理优化相关论文标题

来源：从 [`CCF CHIP2026纪要.md`](../human_notes/CCF%20CHIP2026/CCF%20CHIP2026纪要.md) 的“模型量化、动态计算与推理优化”部分提取论文简称，并通过[刘方鑫个人主页的 Publications 页面](https://mxhx7199.github.io/publications/)查询完整题名。查询日期：2026-07-22。

1. **ASTER** — *ASTER: Adaptive Dynamic Layer-Skipping for Efficient Transformer Inference via Markov Decision Process*（ACM MM 2025）
2. **MILLION** — *MILLION: Mastering Long-Context LLM Inference Via Outlier-Immunized KV Product Quantization*（DAC 2025）
3. **CSD** — *Calibrated Speculative Decoding: Frequency-Guided Candidate Selection for Efficient Inference*（ACL 2026 Main Conference）
4. **EARTH** — *EARTH: An Efficient MoE Accelerator with Entropy-Aware Speculative Prefetch and Result Reuse*（ASPLOS 2026）

6. **BEEMS** — *BEEMS: Boosting Machine Vision Efficiency via Computation Graph-Based Memory Smoothing*（PPoPP 2026）

## 题名核对说明

- ASTER 在作者主页中写作“via MDP”；ACM Multimedia 2025 官方获奖名单给出了展开后的完整题名“via Markov Decision Process”，此处采用完整写法。
- MILLION 在作者主页中以“MasterIng”突出缩写字母；arXiv 论文记录使用标准写法“Mastering”，此处采用 arXiv 写法。
