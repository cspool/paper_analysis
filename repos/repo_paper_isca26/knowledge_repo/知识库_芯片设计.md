# 知识库_芯片设计

## NVLink / NVSwitch

术语是什么？
NVLink 是 NVIDIA 开发的高带宽 GPU-to-GPU 互联技术，提供远超 PCIe 的带宽和更低的延迟。NVSwitch 是配套的交换机芯片，将多个 GPU 通过 NVLink 全连接互联，使任意两 GPU 间可以以 full NVLink 带宽通信。从 H100 (Hopper) 起，NVSwitch 集成 in-switch computing 能力（NVLink SHARP），支持在交换机内进行集体通信操作的多播和归约。最新的 NVLink 4.0 提供 900 GB/s 双向带宽，NVLink 5.0 (Blackwell) 进一步提升。

从芯片设计角度拆解：
NVIDIA GH200 NVL32 的芯片级互联组织：

```
GH200 NVL32 (32-GPU 单节点):
  GPU: 每个 GH200 Superchip 包含 1 Grace CPU + 1 H200 GPU
  NVSwitch: 9 个 NVSwitch 芯片
  拓扑: 全连接 fat-tree
    每个 GPU 有 18 个 NVLink 端口
    每个 NVSwitch 有 32 个端口 (连接 32 GPU)
    9 个 NVSwitch 提供 9 × 32 = 288 端口，足够 32 GPU × 18 端口 = 576 端口的一半
    (实际为 fat-tree，两级交换)
  
  NVLink 4.0 物理参数:
    双向带宽: 900 GB/s
    单向延迟: 250ns (往返 1μs)
    Flit 大小: 16B
    NVSwitch 每端口: 16 个 256-depth VC (8 request + 8 response)
    Reduction buffer: 64KB

NVSwitch 芯片内部 (简化):
  Input Port [0..31] -> Route Computation -> Crossbar -> Output Port [0..31]
  Route: 按 target GPU ID 计算输出端口
  (NVLS/DySHARP) Reduction Logic: 在 Crossbar 前/旁路做归约累加
  (NVLS/DySHARP) Multicast: Crossbar 支持单端口入多端口出的复制转发

多节点扩展:
  Intra-node: NVLink + NVSwitch
  Inter-node: InfiniBand (IB) + Quantum IB Switch (支持 IB SHARP in-switch reduction)
  Hierarchical: intra-node NVSwitch 通信 + inter-node IB 通信
```

术语一般如何实现？如何使用？
- DGX H100: 8 × H100 GPU，4 × NVSwitch，NVLink 4.0。
- GH200 NVL32: 32 × GH200 Superchip，9 × NVSwitch。
- GB200 NVL72 (Blackwell): 72 × B200 GPU，NVLink 5.0。
- 编程接口：NCCL（集体通信）、NVSHMEM（单边 PGAS）、CUDA Multicast API（`cuMulticastCreate` 等）。
- In-switch computing 能力随 NVSwitch 代际增强：Hopper 引入 NVLS（静态 collective 的 multimem 指令），Blackwell 进一步增强。
- 交换机内 buffer 和 VC 深度影响可支持的 concurrent in-switch 操作数量。

涉及论文标题：
- Accelerating MoE with Dynamic In-Switch

## GH200 NVL32

术语是什么？
NVIDIA GH200 NVL32 是 NVIDIA 的 32-GPU 单节点超级计算平台，将 32 个 GH200 Grace Hopper Superchip（每 chip 包含 1 个 Grace CPU + 1 个 H200 GPU）通过 9 个 NVSwitch 全连接互联，实现任意两 GPU 间的 full NVLink 4.0 带宽（900 GB/s 双向）通信。该平台支持 NVLink SHARP (NVLS) in-switch computing，是 DySHARP 论文的主要评估平台。

从芯片设计角度拆解：
GH200 NVL32 的层次化芯片组织：
```
Level 1: GH200 Superchip (单个)
  Grace CPU (72 核 ARM Neoverse V2) + H200 GPU (141 GB HBM3e)
  片内互联: NVLink-C2C (900 GB/s 双向)
  
Level 2: NVL32 节点 (32 Superchips)
  互联: 9 × NVSwitch 4.0 (fat-tree)
  每 GPU: 18 NVLink 端口
  每 NVSwitch: 32 端口 (连接 32 GPU)
  物理布局: 单机架，共享电源和散热

Level 3: NVL32 多节点集群 (论文扩展到 16 × NVL32)
  节点间: InfiniBand (IB) + Quantum IB Switch
  Pipeline Parallelism: 16-way PP 跨 16 NVL32 节点
  Expert Parallelism: 在每 NVL32 内
```

关键规格：
- GPU: H200，141 GB HBM3e，FP8 张量核
- GPU 间带宽: 900 GB/s 双向 NVLink 4.0
- 互联延迟: 250ns 单向，1μs 往返
- NVSwitch 端口数: 32/switch
- NVSwitch 总数: 9（32 GPU 节点）

术语一般如何实现？如何使用？
- 面向最大规模单节点 MoE 训练/推理，适合 expert parallelism 场景（expert 分布在同一 NVL32 内的不同 GPU 上）。
- 编程模型与 DGX H100 相同（CUDA + NCCL），但可利用更多 GPU 的 NVLink 全互联带宽。
- NVL32 内 EP 可使 MoE 通信发生在超高带宽 NVLink 域内，避免跨节点 IB 网络瓶颈。
- NVIDIA 下一代产品：GB200 NVL72 (72 B200 GPU + NVLink 5.0)、Rubin NVL144。

- Accelerating MoE with Dynamic In-Switch
