# Cross-layer interface and conflict review criteria

> Archived with the legacy `learning-direction-reviewer` Skill.

Validate edges between exact entries. State what data, control decision, shape, schedule, buffer or hardware primitive crosses the interface and in which direction. Preserve conditional, substitute, conflict and incompatible relations. A multi-entry Direction needs a connected causal subgraph, but may cover only one or two layers. Measure each entry alone and the combination; check cache, bandwidth, occupancy, synchronization and scheduling conflicts that can erase nominal overlap.
