# Baseline and fairness review criteria

> Archived with the legacy `learning-direction-reviewer` Skill.

Retain current-practice, strong-comparison, measurement/tool and reusable-implementation baselines when evidence exists. Compare the same inputs, output quality or precision, hardware/resource budget, batching/SLO regime and measurement boundary. Separate a baseline's algorithm from its execution path. Include each selected entry alone and the full combination so that synergy is not confused with an already strong single-layer optimization.
