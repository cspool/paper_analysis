# Scenario and acceleration review criteria

> Archived with the legacy `learning-direction-reviewer` Skill.

Fix workload, phase, request/shape regime, backend, bottleneck and target metrics before judging an opportunity. Ask whether the claimed work is independent, dynamically variable, or mapped to genuinely orthogonal resources. Account for scheduling, synchronization, conversion, padding, compilation and data-movement overhead. Require a degradation boundary and a falsifiable measurement; paper-level speedup in a different regime is not direct evidence.
