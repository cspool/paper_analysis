# Experiment and measurement review criteria

> Archived with the legacy `learning-direction-reviewer` Skill.

Define a minimum implementation, current and strong baselines, single-entry ablations, the combined configuration and quality/correctness controls. Match metrics to the proposed causal effect: latency distribution, throughput, SLO attainment, utilization, occupancy, bandwidth/traffic, launch/synchronization overhead, memory footprint and compilation cost as applicable. Specify profiler/tool, warmup, repetition, variance/error, measurement granularity, confounders and explicit failure or stop thresholds.
