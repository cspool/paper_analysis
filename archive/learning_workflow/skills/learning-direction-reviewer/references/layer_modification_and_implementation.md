# Layer modification and implementation review criteria

> Archived with the legacy `learning-direction-reviewer` Skill.

For every selected entry, identify one concrete modifiable object and its implementation boundary. Distinguish algorithm, runtime, compiler, kernel, architecture and chip/system responsibility without requiring all six layers. Check code or tool availability, compile-time versus runtime work, shape guards, data layout, synchronization, resource occupancy, fallback path and portability. A named paper method without a reachable modification point is only a method reference.
