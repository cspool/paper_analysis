### [Quant-LLM: Accelerating the Serving of Large Language Models via FP6-Centric Algorithm-System Co-Design on Modern GPUs](https://www.usenix.org/conference/atc24/presentation/xia)

- **更新证据**：2026-09-11T11:59:01.000Z，`e2d844a4`，Update README.md
- **相关层次**：算法层 / 系统层
- **性能问题**：现有 GPU 上对非标准比特宽度（如 FP6）权重的高效反量化与矩阵乘法支持不足，导致低比特量化模型难以在保持精度的同时获得端到端的 LLM 服务加速。
- **方法与贡献**：提出 Quant-LLM，通过 FP6 为中心的算法-系统协同设计，包括高效的 GPU kernel 实现（支持任意比特宽度浮点权重的高效反量化与矩阵乘法），在现代 GPU 上加速大语言模型的服务/推理，兼顾精度与吞吐。
- **兴趣匹配**：USENIX ATC 2024 论文，FP6 量化格式与 GPU kernel 的算法-系统协同设计，直接目标是加速 LLM 推理服务，有官方开源实现，符合算法层+系统层性能加速工作定位。
- **开源情况**：[代码](https://github.com/usyd-fsalab/fp6_llm)
- **优先级**：高；USENIX ATC 2024 正式发表工作，官方开源代码仓库地址在候选条目 codeUrls 中明确给出（usyd-fsalab/fp6_llm），可直接确认。

- **性能问题**：移动设备 CPU 普遍采用非对称多核（性能核/能效核不同频率与吞吐），现有 DNN 推理框架难以充分利用所有异构核心的算力，导致端上推理吞吐和延迟受限。

- **兴趣匹配**：OSDI 2026 系统层论文，针对移动 CPU 非对称多核（big.LITTLE 类架构）上的 DNN 推理调度，直接解决推理执行性能问题，属于系统层性能加速工作且非常新。

### [DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression](https://www.alphaxiv.org/abs/2609.deepseek-v4-1-flash)

- **更新证据**：2026-09-11T06:17:56.000Z，`100ce201`，Add DeepSeek-V4.1-Flash paper
- **相关层次**：算法层 / 系统层
- **性能问题**：Large KV cache footprint in HBM during decode/prefill for long-context agentic workloads drives up memory usage and serving cost, especially at million-token context lengths.
- **方法与贡献**：Introduces Compressed Sparse Attention 2 (CSA2), which assigns each layer a Full/Reindex/Reuse mode to share KV and indexer data across layers, combined with FP4 KV caching, cutting the global per-token KV cache footprint to 890 bytes — roughly 1/4 of DeepSeek-V4-Flash's footprint — while improving agentic benchmark scores.
- **兴趣匹配**：Targets the inference-time KV cache memory bottleneck for long-context (up to 1M token) MoE serving, combining a new attention/cache-reuse algorithm with system-level HBM footprint reduction — directly a performance-acceleration (not training-only) contribution, and very recent (Sept 2026).
- **开源情况**：未知
- **优先级**：高；New DeepSeek-AI tech report/model release (Sept 2026) introducing the CSA2 technique; not previously covered and distinct from prior DeepSeek-V4-Flash work.
- **更新来源**：[github.com/byungsoo-oh/ml-systems-papers](https://github.com/byungsoo-oh/ml-systems-papers)

### [TurboQuant: Online Vector Quantization with Near-optimal Distortion Rate](https://arxiv.org/abs/2504.19874)

- **更新证据**：2026-09-15T10:52:26.000Z，`b22a8e05`，Add TurboQuant arXiv paper
- **相关层次**：算法层
- **性能问题**：现有在线（data-oblivious）向量量化方法在低比特（1-4 bit）场景下距离最优失真率仍有较大差距，导致流式场景（如 LLM KV-cache、向量数据库）压缩效率与检索精度难以兼顾。
- **方法与贡献**：提出 TurboQuant，通过随机旋转输入向量使各坐标近似独立并服从集中的 Beta 分布，再对每个坐标施加最优标量量化器，在 MSE 与内积失真度量下于所有比特宽度和维度上达到常数因子内的近最优失真率，且算法为 data-oblivious，适用于流式 KV-cache 与数据库场景。
- **兴趣匹配**：面向流式 KV-cache 与向量数据库的在线向量量化算法，属于压缩/量化算法层的性能加速工作，直接服务于降低内存带宽与存储开销以加速检索/推理。
- **开源情况**：未知
- **优先级**：中；2025年4月 arXiv 论文，近期（2026-09-15）被 ml-systems-papers 仓库新增收录；已知仅有第三方非官方 Python 实现（yashkc2025/turboquant），未确认作者官方开源库，故不猜测代码链接。
- **更新来源**：[github.com/byungsoo-oh/ml-systems-papers](https://github.com/byungsoo-oh/ml-systems-papers)
