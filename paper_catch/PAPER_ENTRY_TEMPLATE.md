# Paper Catch 条目模板

> 本模板定义每个筛选后论文条目的固定展示结构。Codex batch 只负责填写语义字段；
> 最终 Markdown 由脚本按此顺序确定性渲染。

### [论文标题](论文链接)

- **更新证据**：来源仓库、commit 时间与 commit 摘要
- **相关层次**：算法层 / 框架层 / 系统层 / 硬件层（可多选）
- **性能问题**：该工作针对的性能瓶颈或可量化优化对象
- **方法与贡献**：一句话说明相对 baseline 的关键改变及预期/报告效果
- **兴趣匹配**：为什么符合 `Catch_Paper_Urls.md` 中的兴趣主题；训练-only 工作不得入选
- **开源情况**：代码链接；若未确认则明确写“未知”，不得猜测
- **优先级**：高 / 中 / 低，并简述新颖性、开源性或可复现性依据
- **更新来源**：原始监控 URL
