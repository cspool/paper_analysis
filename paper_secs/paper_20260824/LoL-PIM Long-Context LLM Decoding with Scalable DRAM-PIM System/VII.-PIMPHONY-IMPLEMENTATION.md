# VII. PIMPHONY IMPLEMENTATION

PIMphony integrates TCP, DCS, and DPA through compiler and runtime techniques. To demonstrate its benefit, we apply our MLIR-based implementation to existing simulators for NeuPIMs [\[21\]](#page-18-4) (NPU+PIM) and CENT [\[16\]](#page-18-1) (PIM-only), enabling evaluation across different types of PIM systems.
