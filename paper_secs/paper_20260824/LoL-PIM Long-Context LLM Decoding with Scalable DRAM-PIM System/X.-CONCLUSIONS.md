# X. CONCLUSIONS

We propose PIMphony, a multi-node PIM acceleration system featuring an MLIR-based compiler and novel techniques for partitioning, scheduling, and memory management. By systematically resolving key bottlenecks, PIMphony significantly enhances throughput for long-context LLM inference up to 11.3× and 8.4× on PIM-only and xPU+PIM systems, respectively.
