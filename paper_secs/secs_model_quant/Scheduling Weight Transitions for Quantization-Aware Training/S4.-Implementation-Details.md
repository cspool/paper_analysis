# S4. Implementation Details

## S4.1. Experimental settings

Following the experimental protocol in [\[21,](#page-8-5) [26,](#page-8-11) [32,](#page-9-2) [46,](#page-9-4) [49\]](#page-9-6), we initialize network weights from pretrained full-precision models for MobileNetV2, ResNets, DeiTs and RetinaNet. Similarly, the weights in ReActNet-18 are initialized using the pretrained activation-only binarized model. We do not quantize the first and last layers. We use either plain optimizers using a LR (SGD, Adam, and AdamW), or their variants using our TR scheduling technique (SGDT, AdamT, and AdamWT), whose gradient terms are the same as SGD, Adam, and AdamW, respectively. Note that we use a TR scheduler to the latent weights only (*i.e*., full-precision weights coupled with quantizers). Other parameters that are not quantized (*e.g*., the weights in the first and last layers) are updated with the plain optimizers using a LR. We adopt the cosine scheduler [\[33\]](#page-9-13) for both the LR and the target TR, decaying them to zero gradually. For ReActNet-18 on ImageNet, we use the linear scheduler, following the training scheme in [\[32\]](#page-9-2). We exploit STE [\[2\]](#page-8-17) to propagate gradients in discretization functions. To set an initial value of the learnable scale parameter s in Eq. (13) of the main paper, we follow the initialization technique in [\[26\]](#page-8-11). For an initial TALR, we use the same value as an initial LR for fullprecision parameters. We also set η in Eq. (11) of the main paper to the same value as an initial TALR (*i.e*., η = U 0 ), adjusting the TALR according to its initial value, *e.g*., updating the TALR more finely when the initial value is small. Note that the number of transition points increases as bitwidths of weights get larger, suggesting that a larger target TR is desirable for larger bit-widths. Accordingly, motivated by [\[10\]](#page-8-4) that uses different gradient scales according to bit-widths, we set the initial target TR to λ √ bw, where λ is a TR factor, a hyperparameter to set, and b<sup>w</sup> is the bitwidth of weights.

We summarize in Table [S8](#page-17-0) hyperparameter settings for our experiments. If available, we follow the previous works [\[10,](#page-8-4) [26,](#page-8-11) [30,](#page-9-8) [32,](#page-9-2) [35\]](#page-9-14) to set hyperparameters (*e.g*., number of training epochs/iterations, batch size, LR, weight decay, and decay scheduler). Different from the original work of RetinaNet [\[30\]](#page-9-8), we do not freeze the ResNet [\[12\]](#page-8-0) backbones to optimize quantized weights via QAT, and adopt the cosine decay scheduler [\[33\]](#page-9-13). For the models exploiting our TR scheduling technique, we fix the TR momentum constant m to 0.99 for simplicity. We choose the TR factor λ in a set of {5e-3, 1e-3, 5e-4, 1e-4}. When we train a scale parameter s in Eq. (13) of the main paper, we set the LR to the value ten times smaller than the one for weight parameters (*i.e*., the LR in Table [S8\)](#page-17-0), similar to the works of [\[21,](#page-8-5) [26\]](#page-8-11), for simplicity, instead of using the heuristic gradient scaling in LSQ [\[10\]](#page-8-4). Note that when we apply our TR scheduling technique, we do not train the scale parameters s for weight quantizers and fix the initial values, since training them makes it difficult to control a TR of quantized weights. We will discuss this in more detail in the following section.
