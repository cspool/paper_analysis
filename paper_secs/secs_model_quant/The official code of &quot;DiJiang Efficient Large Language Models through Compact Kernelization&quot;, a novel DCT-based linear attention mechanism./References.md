### A. Theoretical Proof.

Theorem A.1. *The Positive Fixed Features (PFF) is formulated as:*

$$\varphi_{PFF}(x) := \frac{e^{-\|x\|^2}}{\sqrt{m}} [e^{\Phi^{-1}(t_1)x^{\mathsf{T}}v_1}, ..., e^{\Phi^{-1}(t_m)x^{\mathsf{T}}v_m}]^{\mathsf{T}}, \tag{14}$$

*where* V = [v1, ..., vm] ∈ S <sup>d</sup>×<sup>m</sup> *is asymptotically uniformly distributed and* t<sup>i</sup> ∼ U(0, 1)*. Then,* φ*PFF*(x) <sup>⊺</sup>φ*PFF*(z) *is an unbiased estimate of Gaussian kernel* KG(x, y)*.*

*Proof.* The proof is motivated by [\(Lyu,](#page-9-22) [2017\)](#page-9-22). We also use spherical coordinate changes to get the following proof. The Gaussian kernel is real-valued and therefore the imaginary part in Eq.[\(6\)](#page-3-1) can be discarded.

$$K_{G}(x,y) = e^{-\frac{\|x-y\|^{2}}{2}} = \int_{\mathbb{R}^{d}} e^{i(x-y)^{\mathsf{T}}w} \mu(w) dw = \int_{\mathbb{R}^{d}} \cos((x-y)^{\mathsf{T}}w) \mu(w) dw = e^{-\|x\|^{2} - \|y\|^{2}} \int_{\mathbb{R}^{d}} e^{i(x+y)^{\mathsf{T}}w} \mu(w) dw,$$
(15)

where µ(·) is the probability density function of d-dimensional standard normal distribution.

The Gaussian kernel is a shift and rotation invariant kernel. Given any rotation R ∈ SO(d), where SO(d) denotes rotation groups, the corresponding probability density is also Gaussian according to Bochner's theorem. For shift and rotation invariant kernels, we can convert the integral to spherical coordinates. r = ||w||<sup>2</sup> and p(r) be the density function of r, and w = rv. Because of the rotation invariant property of KG(x, y), we achieve:

$$K_G(x,y) = \int_{\mathbb{R}^d} e^{i(x-y)^{\mathsf{T}} w} p(w) dw = \int_{R_+} \int_{\mathbb{S}^{d-1}} e^{i(x-y)^{\mathsf{T}} r v} p(r) dr d\sigma(v) = \int_{[0,1]} \int_{\mathbb{S}^{d-1}} e^{i(x-y)^{\mathsf{T}} \Phi^{-1}(t) v} dt d\sigma(v), \quad (16)$$

where σ denotes the normalized surface area measure on S d := {x ∈ R d |∥x∥<sup>2</sup> = 1} and Φ −1 (t) denotes the inverse cumulative distribution function w.r.t is a non-negative radial scale.

For real valued continuous shift and rotation invariant scaled kernel KG(x, y), the imaginary parts of the integral vanish. We can achieve:

$$K_G(x,y) = \int_{\mathbb{R}^d} e^{i(x-z)^{\mathsf{T}} w} p(w) dw = \int_{\mathbb{R}^d} \cos((x-z)^{\mathsf{T}} w) p(w) dw = \int_{[0,1]} \int_{\mathbb{S}^{d-1}} \cos((x-z)^{\mathsf{T}} \Phi^{-1}(t) v) dt d\sigma(v). \tag{17}$$

For Gaussian kernel, we can get another medium integral form:

$$K_{G}(x,y) = \int_{\mathbb{R}^{d}} e^{i(x-y)^{\mathsf{T}}w} \mu(w) dw = e^{-\|x\|^{2} - \|y\|^{2}} \int_{\mathbb{R}^{d}} e^{((x+y)^{\mathsf{T}}w)} \mu(w) dw = e^{-\|x\|^{2} - \|y\|^{2}} \int_{[0,1]} \int_{\mathbb{S}^{d-1}} e^{(x+y)^{\mathsf{T}}\Phi^{-1}(t)v} dt d\sigma(v).$$

$$\tag{18}$$

According to [\(Brauchart & Grabner,](#page-8-15) [2015\)](#page-8-15), if the point set V = [v1, ..., vm] ∈ S <sup>d</sup>×<sup>m</sup> is asymptotically uniformly distributed, the following equation holds true:

$$\lim_{m \to \infty} \frac{1}{m} \sum_{i=1}^{m} f(v_i) = \int_{\mathbb{S}^d} f(v) d\sigma(v).$$
 (19)

Then, we have:

$$\lim_{m \to \infty} E_{t_i \sim U(0,1)} [\varphi_{\text{PFF}}(x)^{\mathsf{T}} \varphi_{\text{PFF}}(y)] = E_{t_i \sim U(0,1)} [\lim_{m \to \infty} \frac{e^{-\|x\|^2 - \|y\|^2}}{m} \sum_{i=1}^m e^{\Phi^{-1}(t_j)(x+y)^{\mathsf{T}} v_i}]$$

$$= e^{-\|x\|^2 - \|y\|^2} \int_{[0,1]} \int_{\mathbb{S}^{d-1}} e^{(x+y)^{\mathsf{T}} \Phi^{-1}(t) v} dt d\sigma(v)$$

$$= e^{-\|x\|^2 - \|y\|^2} (2\pi)^{-\frac{d}{2}} \int_{\mathbb{R}^d} e^{(x+y)^{\mathsf{T}} w} e^{-\frac{\|w\|^2}{2}} dw$$

$$= e^{-\|x\|^2 - \|y\|^2} (2\pi)^{-\frac{d}{2}} \int_{\mathbb{R}^d} e^{\frac{\|x+y\|^2}{2}} e^{-\frac{\|w-(x+y)\|^2}{2}} dw$$

$$= e^{-\|x\|^2 - \|y\|^2} e^{\frac{\|x+y\|^2}{2}}$$

$$= e^{-\frac{\|x-y\|^2}{2}}$$

$$= K_G(x, y).$$
(20)

Therefore,  $\varphi_{PFF}(x)^{\mathsf{T}}\varphi_{PFF}(z)$  is an unbiased estimate of Gaussian kernel  $K_G(x,y)$ .

**Theorem A.2.** The Weighted Positive Fixed Features (WPFF) is formulated as:

$$\varphi_{WPFF}(x) := \frac{De^{-\|x\|^2}}{\sqrt{m}} [e^{\Phi^{-1}(t_1)x^{\mathsf{T}}v_1}, ..., e^{\Phi^{-1}(t_m)x^{\mathsf{T}}v_m}]^{\mathsf{T}}, \tag{21}$$

where D is a learnable parameter which can be optimized by the input x. Then the upper bound of the integral estimation error of the objective function by WPFF (Weighted Positive Fixed Features) method is not greater than the upper bound of the integral estimation error of the objective function by PFF (Positive Fixed Features) method.

*Proof.* The proof is motivated by (Yang et al., 2014). We use some of the same mathematical definitions and similar proofs from this paper to show that the WPFF method has a smaller upper bound on the overall estimation error of the objective function. Theorem A.2 Lemma A.3 and Lemma A.4 are all relevant to this paper.

Consider the task of computing an approximation of the following integral  $I_{d,p}[f] = \int_{\mathbb{R}^d} f(x)p(x)dx$ , because of  $I_{d,p}[f] = \int_{\mathbb{R}^d} f(x)p(x)dx$  $E_{x \sim p(\mathbb{R}^d)}[f(x)]$ , an empirical approximation called Monte Carlo (MC) to the integral can be computed by drawing a random point set  $S = \{w_1, ..., w_s\}$  independently from  $p(\mathbb{R}^d)$ . When S is a set of fixed points, the empirical approximation is a quasi-Monte Carlo (QMC) method. The purpose of the QMC method is to improve convergence speed by constructing Susing deterministic low-differential sequences instead of random sampling points. We have  $I_S[f] = \frac{1}{e} \sum_{w \in S} f(w)$ .

We define the integration error with respect to the point set S as  $\epsilon_S[f] = |I_{d,p}(f) - I_S(f)|$ . The integration error for PFF is as follows:

$$\epsilon_{S,p}[f] = |\int_{\mathbb{R}^d} f(x)p(x)dx - \frac{1}{s} \sum_{i=1}^s f(w_i)|,$$
 (22)

where S is a set of fixed points.

The classical Monte Carlo and quasi-Monte Carlo approximations of integrals have consistent weights. However, it makes sense to weight the approximations, approximate  $I_{d,p}[f] = \int_{\mathbb{R}^d} f(x)p(x)dx$  using  $I_{S,\Xi}[f] = \sum_{j=1}^s \xi_j f(w_j)$ , where  $\Xi = \{\xi_1, \xi_2, ..., \xi_s\}$ ,  $\xi_i \geq 0$  for  $i \in \{1, 2, ..., s\}$ , we do not need to normalize the weights, that is it is possible that  $\sum_{i=1}^{s} \xi_i \neq 1.$ 

$$\int_{\mathbb{R}^d} e^{i(x-z)^T w} p(w) dw \approx \sum_{j=1}^s \zeta_j(x) \zeta_j(z) f(w_j)$$

$$= \sum_{j=1}^s \zeta_j(x) \zeta_j(z) e^{ix^T w_j} e^{-iz^T w_j}$$
(23)

$$= \!\! \varphi_{\mathrm{WPFF},S}(x)^T \varphi_{\mathrm{WPFF},S}(z),$$

where  $\zeta_j(x)\zeta_j(z) = \xi_j, \ \zeta_j(x), \zeta_j(z) \geq 0, \ e^{ix^Tw_j}e^{-iz^Tw_j} = f(w_j) \ \text{for} \ j \in \{1,2,...,s\}, \ \text{and} \ \Psi_S(x) = [\zeta_1(x)e^{ix^Tw_1},...,\zeta_s(x)e^{ix^Tw_s}]^T.$ 

The integration error for WPFF is as follows:

$$\epsilon_{S,p,\Xi}[f] = |\int_{\mathbb{R}^d} f(x)p(x)dx - \sum_{j=1}^s \xi_j f(w_j)|.$$
 (24)

For a vector  $b \in R_d$ , let us define  $\Box b = \{u \in \mathbb{R}^d | |u_i| \leq |b_i|\}$ . Let

$$F_{\Box b} = \{ f_u(x) = e^{ix^T u} | u \in \Box b \}, \tag{25}$$

and consider the space of functions that admit an integral representation over  $F_{\square b}$  of the form

<span id="page-12-0"></span>
$$f(x) = \int_{u \in \Box b} \hat{f}(u)e^{ix^T u} du, \tag{26}$$

where  $f(u) \in \ell_2(\square b)$ . This space is associated with the functions with compactly-supported inverse Fourier transforms called bandlimited functions, which play an important role in Shannon-Nyquist sampling theory. Under a natural choice of inner product, these spaces are called Paley-Wiener spaces and they constitute an RKHS.

Lemma A.3. *(The Kernel of Paley-Wiener RKHS) According to [\(Peloso,](#page-9-24) [2011\)](#page-9-24),* PW<sup>b</sup> *denotes the space of functions which are represented in the form of Eq[.26,](#page-12-0) with the inner product* < f, g >PWb= (2π) <sup>2</sup><sup>d</sup> <sup>&</sup>lt; <sup>ˆ</sup>f, g ><sup>ˆ</sup> <sup>L</sup>2(□b) *.* PW<sup>b</sup> *is an RKHS with kernel function,*

$$\sin c_b(u, v) = \pi^{-d} \prod_{i=1}^d \frac{\sin(b_j(u_j - v_j))}{u_j - v_j}$$
(27)

Lemma A.4. *According to [\(Yang et al.,](#page-9-23) [2014\)](#page-9-23), for* f ∈ PW<sup>b</sup> *(Paley-Wiener spaces), we have*

$$\epsilon_{S,p}[f] \le ||f||_{PW_b} D_p^{\square b}(S) \tag{28}$$

*where*

$$D_p^{\Box b}(S)^2 = \pi^{-d} \int_{\beta \in \Box b} |\Psi(\beta)|^2 d\beta - \frac{2(2\pi)^{-d}}{s} \sum_{j=1}^s \xi_j \int_{\beta \in \Box b} \Psi(\beta) e^{i\beta^T w_j} d\beta + \frac{1}{s^2} \sum_{l=1}^s \sum_{j=1}^s sinc_b(w_l, w_j). \tag{29}$$

*Suppose that* p(·) *is a probability density function. Let* Ψ(·) *be the characteristic function associated with* p(·)*.*

Following [\(Yang et al.,](#page-9-23) [2014\)](#page-9-23), we can derive the following discrepancy measure that takes into account the weights:

$$D_{p}^{\Box b}(S,\Xi)^{2} = \pi^{-d} \int_{\beta \in \Box b} |\Psi(\beta)|^{2} d\beta - 2(2\pi)^{-d} \sum_{j=1}^{s} \xi_{j} \int_{\beta \in \Box b} \Psi(\beta) e^{i\beta^{T} w_{j}} d\beta + \sum_{l=1}^{s} \sum_{j=1}^{s} \xi_{l} \xi_{j} \sin c_{b}(w_{l}, w_{j})$$

$$= \pi^{-d} \int_{\beta \in \Box b} |\Psi(\beta)|^{2} d\beta - 2(2\pi)^{-d} \sum_{j=1}^{s} \zeta_{j}(x) \zeta_{j}(z) \int_{\beta \in \Box b} \Psi(\beta) e^{i\beta^{T} w_{j}} d\beta + \sum_{l=1}^{s} \sum_{j=1}^{s} \zeta_{l}(x) \zeta_{l}(z) \zeta_{j}(z) \sin c_{b}(w_{l}, w_{j}).$$

$$(30)$$

We note that if we fix the points, then optimizing just the weights is a optimization problem. The discrepancy measure can be written as

$$D_p^{\Box b}(S,\xi)^2 = \pi^{-d} \int_{\beta \in \Box b} |\Psi(\beta)|^2 d\beta - 2v^T \xi + \xi^T H \xi$$

$$= \pi^{-d} \int_{\beta \in \Box b} |\Psi(\beta)|^2 d\beta - 2v^T (\zeta(x) \otimes \zeta(z)) + (\zeta(x) \otimes \zeta(z))^T H(\zeta(x) \otimes \zeta(z)),$$
(31)

where ξ = (ξ1, ..., ξs) T , ζ(x) = (ζ1(x), ..., ζs(x))<sup>T</sup> , and ξ = ζ(x) ⊗ ζ(z) = (ζ1(x)ζ1(z), ..., ζs(x)ζs(z))<sup>T</sup> . ⊗ is the Hadamard product. v ∈ R<sup>s</sup> , v<sup>j</sup> = (2π) −d R <sup>β</sup>∈□<sup>b</sup> Ψ(β)e iβ<sup>T</sup> <sup>w</sup><sup>j</sup> dβ and H ∈ R<sup>s</sup>×<sup>s</sup> , Hlj = sincb(w<sup>l</sup> , w<sup>j</sup> ).

Thus, the optimal weights can be found by solving the following convex optimization problem

$$\arg \min_{\zeta(x),\zeta(z)\in R^s} -2v^T(\zeta(x)\otimes \zeta(z)) + (\zeta(x)\otimes \zeta(z))^T H(\zeta(x)\otimes \zeta(z))$$
s.t. $\zeta(x) \leq 0, \zeta(z) \leq 0.$  (32)

So obviously for a fixed sampling point, there is D□<sup>b</sup> p (S, ξ) ≤ D□<sup>b</sup> p (S). Then the upper bound of the integral estimation error of the objective function by WPFF (Weighted Positive Fixed Features) method is not greater than the upper bound of the integral estimation error of the objective function by PFF (Positive Fixed Features) method.
