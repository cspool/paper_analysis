# *C. Optimization on Quantized Computation Flow*

Quantization Granularity. The quantization granularity has a direct impact on the computation flow. For query and KVcache, we employ per-head quantization, where a group of D<sup>h</sup> elements are quantized together and D<sup>h</sup> is the head size. This allows immediate quantization of each newly generated token and eliminates the need to buffer a window of FP16 KV-cache as done in prior works [\[29\]](#page-13-12), [\[61\]](#page-14-17). Additionally, weights are quantized per-group with a group size of 128 following BitMoD [\[6\]](#page-13-13). Activations are quantized per-token using FP8-E4M3. Finally, attention-score quantization does not need scaling since FP8-S0E4M4 already covers the required numerical range. Instead, we directly round the least significant bits of every FP16 attention-score and keep its highest 4 mantissa bits.

Quantized Computation Flow. As shown in Fig. [6\(](#page-6-2)c), P 3 -LLM performs quantized matrix multiplication on the lowprecision PCU, and implements operator fusion to minimize the runtime overhead of dequantization, which needs to be executed on NPU using high-precision arithmetic. For linear layers, the dequantization scaling is performed after matrix multiplication. For Q · K<sup>T</sup> , since the post-RoPE key cache contains per-channel smoothing factors (SSF), we fuse SSF into query via element-wise multiplication prior to FP8 quantization. Similarly, for P · V , we fuse the per-value-head scaling factors (S<sup>V</sup> ) into attention-scores before FP8 quantization. One potential issue of fusing S<sup>V</sup> is that it may cause the resulting attention-scores' magnitude to become larger than one, which is outside the range of FP8-S0E4M4. To prevent this, we apply a second-level scaling that divides S<sup>V</sup> with its maximum S<sup>V</sup> max, resulting in S<sup>V</sup> ∈ [0, 1]. Note that the quantization scaling factor is always positive by definition in Eq. [1,](#page-2-2) so fusing S<sup>V</sup> still produces unsigned attention-scores. This second-level scaling factor S<sup>V</sup> max is later multiplied back into the result of P · V .
