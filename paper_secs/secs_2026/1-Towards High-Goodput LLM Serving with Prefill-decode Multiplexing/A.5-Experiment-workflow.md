# A.5 Experiment workflow

Our experiments focus on comparison between MuxWise and chunked-prefill.

- Download the required LLM model(CodeLlama-34b-Instruct-hf) to /workspace/data.
- Start MuxWise or chunked-prefill server. You can change the environment virable \$CHUNK\_SIZE to start chunked-prefill server with different token budgets.

```
# 1. Start MuxWise Server
./start_pdmux.sh

# 2. Start Chunked-prefill Server
./start_chunk.sh
```

- 3. Start evaluating in another terminal.
  - # 1. Evaluate MuxWise on ShareGPT and LooGLE
    ./bench\_pdmux.sh
  - # 2. Evaluate Chunked-prefill on ShareGPT and LooGLE ./bench\_chunk.sh

#### A.6 Evaluation and expected results

When all experiments done, you will obtain jsonl files containing detailed metrics under /workspace/sglang. To visualize the results, run plot.ipynb; this will generate figures similar to the reference plot provided at /workspace/sglang/H200\_result.png. Please note that results may vary depending on the specific hardware used. You can refer to https://github.com/ykcombat/sglang/blob/slo\_config/README.md for more information.

#### A.7 Notes

When serving different workloads, different configurations are used, which can be found in our repository.
