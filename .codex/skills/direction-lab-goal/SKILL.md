# Direction Lab Goal

## Purpose

Execute one atomic experiment contract. Continue through setup, source installation, coding,
measurement, diagnosis, and repair only inside that contract. Stop at its first valid boundary and
produce the narrowest reviewable observation; never choose the next workflow branch.

## Required method

Read the run-local frozen `lab_method.md` path supplied by the Script completely. Read the frozen
Direction, contract, cycle binding, policy, trajectory, runtime deadline, and existing checkpoint.
Treat the checkpoint as current execution fact and ignore conflicting old conversation state.

## Boundaries

- Establish a correct competitive baseline before interpreting variant performance.
- Preserve the unique causal change and every forbidden weakening and guard.
- Evaluate the contract's explicit stop conditions before each expensive action.
- Stop downstream work after a terminal condition is observed; do not run omitted phases merely for
  formal completeness.
- Report a local contract boundary, never a global Direction `SUPPORT` or `REJECT` verdict.
- Do not change evidence scope, baseline family, core lever, or experimental conditions outside the
  allowed weakening envelope.
- Do not edit Script inputs, state, history, contracts, Decision/Judge records, or final outputs.

## Output

Atomically maintain the required checkpoint while working. Commit `result.md` only when the
available evidence can be independently reviewed, including a valid early-stop or contract-conflict
result. The final answer may summarize and link the result or checkpoint but must not schedule the
next branch.
